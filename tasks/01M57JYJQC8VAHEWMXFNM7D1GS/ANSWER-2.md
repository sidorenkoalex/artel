## Ответ Оператора (замечания аудита SPEC, визит 3)

1. Сбой записи в общий `info/exclude` клона (нет прав, ошибка ввода-вывода, неразобранный путь `git rev-parse --git-path`) — отказ прогона планки с именованной причиной ДО создания выкладки (fail-closed); выкладка не создаётся, pytest не запускается. Покрой своим тестом.
2. Дописывание `info/exclude` — под блокировкой файла (`fcntl.flock` на сам файл или на соседний файл замка в каталоге git клона) с проверкой «шаблон уже есть» внутри блокировки; две задачи одновременно оставляют ровно одну строку шаблона. Покрой своим тестом с двумя процессами или потоками.
3. Риск: под конфигом проекта `--import-mode=importlib` импорт `_pult` из планки может не работать — назови это в «Предложения системе» PLAN; отдельной правки не требуется.
