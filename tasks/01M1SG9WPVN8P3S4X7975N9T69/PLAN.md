# PLAN: сторож Bash роли — возврат запрета полного прогона tests/ до таймаута на тест

## Подход

Откатываем снятие хука `bash_guard.py`, сделанное коммитом dea8016b, до
редакции коммита 80c38245 — точечно, без переноса остальных изменений
того коммита (role_env/doctor уже сделаны отдельно и остаются как есть).
Правим три места:

1. `docs/reference/role-home/claude/hooks/bash_guard.py` — восстановить
   файл байт-в-байт по редакции 80c38245, но обновить упоминание условия
   снятия в докстринге (SPEC требование 5/AC-6: снимается задачей P1,
   не руками Оператора) и добавить абзац о резолвинге `python3` через
   PATH роли (`orchestrator/runner.py::role_env`/`_venv_interpreter_bin`,
   AC-4).
2. `docs/reference/role-home/claude/settings.json` — вернуть
   `hooks.PreToolUse` (matcher `Bash` → `hooks/bash_guard.py`, timeout
   10), сохранив текущий `permissions.deny` (8 записей) без изменений.
3. `tests/test_role_bash_guard.py` — восстановить байт-в-байт по
   редакции 80c38245 (без кейса «пять прогонов подряд» — SPEC явно
   запрещает его добавлять).

Дополнительно:
- `docs/reference/role-home.md` — вернуть строку структуры про
  `hooks/bash_guard.py` и абзац про хук в `settings.json` (откат части
  диффа dea8016b), плюс то же условие снятия (P1, не руками Оператора),
  что и в докстринге хука (AC-6).
- `orchestrator/doctor.py` — код не трогаем (SPEC/AC-5: обход
  `_role_home_diff` уже идёт по `reference.rglob("*")`, значит каталог
  `hooks/` уже покрыт сверкой; это выясняем тестом, а не предположением).
- `tests/test_doctor.py` — добавить тест-регресс: расхождение
  развёрнутого `hooks/bash_guard.py` с референсом даёт `warn` с
  упоминанием `hooks/bash_guard.py` (AC-5), используя существующий
  фикстур-класс `_RoleHomeReferenceTmpRootTest`.
- `scripts/codebase_map.py` — перегенерировать после восстановления
  `tests/test_role_bash_guard.py` (правится `*.py` в `tests/` —
  конвенция `conventions-core`).

Случай «пять полных прогонов подряд» из инцидента-триггера этой задачи
(01M1REVEZ1HESMJ7AFD5A9MEJ8) в тест не добавляется — явный запрет
SPEC (требование 2/АС-3/«Не входит»): хук отклоняет каждый прогон
независимо, повторный отказ не даёт нового покрытия.

## Влияние на систему

Восстанавливаемый хук — временная мера (SPEC, «Не входит»), уже
проверенная историей: редакция 80c38245 работала в проде до dea8016b и
не расширяется. Единственный новый код — тест в `test_doctor.py`,
чисто аддитивный (регресс-гвардия на уже существующее поведение
`_role_home_diff`, которое проходит по вложенным каталогам референса —
`orchestrator/doctor.py` не меняется). Откат — обратный коммит (снять
хук и тест), как и раньше делала задача 01M1RDCEF0JZ4AVQRE43JFH8TN.
Гейты/лимиты/инварианты не ослабляются — наоборот, восстанавливается
ранее снятая проверка.

Раскатка восстановленного референса в `.artel/home/.claude/` на уже
работающем пульте — операторское действие после мержа (деплой
`_deploy_role_home_reference` копирует референс только на холодном
старте); эта задача правит только референс в репозитории, не
`.artel/home/` данного worktree.
