## Проверяемость критериев
| Критерий | Проверяем | Ловимая мутация |
|---|---|---|
| AC-1 | да | разбор не тронут (путь = точечное имя); точка выброшена (`tests/artel-plank/…`); имя с префиксом модуля; сопоставление гейтом при неверном пути |
| AC-2 | да | правка только в `_junit_location`, `_forge_location` не тронут — путь `None` |
| AC-3 | да | обработан только пустой сегмент в середине, ведущая точка — нет |
| AC-4 | да | остаток класса не отделён или отделён с точкой; длинный префикс выбран неверно |
| AC-5 | да (зелёный с рождения) | новое правило ломает `classname` без пустых сегментов, путь через `/` или ветку с `file` |

Красная фаза. AC-1…AC-4 красны по причине (см. «Факты»). AC-5 зелёный до
кода — нужна метка «Зелёный с рождения:» (`scripts/guard.py:940-946`).
Рекурсии, хуков, меняющих git-команд и сети в критериях нет: настоящий
pytest на минимальном файле во временном каталоге, остальное — прямой
вызов функций на словаре и множестве путей.

Отклонения:
1. **Требование без критерия.** Правило «две и более точек в начале имени
   (`..x`) — последовательно» (SPEC.md:39-41) не проверяет ни один AC.
   Все критерии несут ровно одну точку. Мутация «присоединять к сегменту
   одну точку» (например, `re.sub(r"\.\.", "/.", …)` один раз, или
   склейка только одного пустого сегмента) проходит AC-1…AC-5, а
   `tests...x.test_y` даёт неверный путь.
2. **Буквальное имя каталога.** Во всех AC (SPEC.md:47-73) скрытый
   каталог называется `.artel-plank`. Реализация с жёстко заданной
   строкой (`classname.replace("..artel-plank", "/.artel-plank")`, проверка
   `startswith(".artel-plank")`) проходит все критерии. При этом
   `plank_layout` — любое имя с точки
   (`orchestrator/plank_layout.py:151`), а требование 1 общее. Критерий
   должен задавать хотя бы одно другое (случайное) имя скрытого каталога.

Замечания автору тестов (форма, не отклонения):
- Два файла `test_x.py` в одной песочнице без `__init__.py` дают ошибку
  сбора pytest (import file mismatch; опыт: пустой отчёт `classname=""
  name=""`). Для AC-1 и AC-3 нужны отдельные песочницы или
  `--import-mode=importlib`.
- Нужен путь песочницы через `resolve()` (macOS: `/var` → `/private/var`).
  При `--rootdir` с нерезолвленным путём опыт xunit1 дал
  `file="../../…/test_x.py"` и `classname=".TestK"`.
- Каталог аргументом не годится: `norecursedirs` по умолчанию `.*`, и
  pytest не заходит в `.artel-plank` (опыт: 0 тестов). Нужен путь к файлу.
- Дочернему pytest — `timeout`, очищенный `PYTEST_ADDOPTS` и
  `-p no:cacheprovider`.
