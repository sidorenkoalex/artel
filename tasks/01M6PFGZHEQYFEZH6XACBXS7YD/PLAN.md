# PLAN: reject --decision: отказ на нецифровом номере решения и форма --decision=<файл>

## Подход
Две точечные правки.

- `orchestrator/spec_gate_decision.py` (`parse`): проверка номера подраздела
  `number.isdigit()` заменена на `number.isascii() and number.isdigit()` —
  надстрочные, полноширинные и арабско-индийские цифры дают прежний
  `DecisionError` «… — не целое» до `int()`; трассировки и отказа «не по
  порядку» для них больше нет.
- `orchestrator/artel.py` (`_cmd_reject`): ключом считается аргумент, равный
  `DECISION_FLAG`, или начинающийся с `DECISION_FLAG + "="`. Порядок отказов
  (требование 4): два и более ключа → «ключ --decision повторён»; значение
  пустое (`--decision=`, `--decision ""`, ключ последним) или начинающееся с
  `--` → «без значения»; остаток аргументов → прежний «не сочетается с
  позиционной причиной». Значение формы с «=» — всё после первого «=»
  (`--decision=a=b.md` → `a=b.md`). Без ключа (в т.ч. `--decisions`) —
  прежний вызов `fsm.cmd_reject(task_id, args[0])`. Все отказы — `sys.exit`
  до `fsm.cmd_reject`, то есть до lease и журнала.
- Строка справки `reject` не менялась (требование 6 — «можно»): прежняя форма
  остаётся, `test_ac8_help_names_decision_form` не затронут.

Оценка SPEC (25 USD) не пересматривается.
