Односторонность — не формальность: она и есть то, чего требует SPEC

Отдельно сверил, не осталось ли НЕПОКРЫТЫМ ещё одно свойство боевого
файла из прежнего случайного покрытия. Кандидат был один — `token_slot:`:
его не проверяет ни один из двух методов. Замечанием он не становится:
`orchestrator/roles.py:35 token_slots` документирует «роль без слота
(`token_slot: null`) или неописанная роль просто не добавляет своего
элемента — это не ошибка», то есть сверять значение не с чем. Остальное
закрыто: формат файла и `token_fallback` — `tests/test_yaml_parsing.py`,
ярус/провайдер/скилы — первый метод, состав и `executor` — второй.
