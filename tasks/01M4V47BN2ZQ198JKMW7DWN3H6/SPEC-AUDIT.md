## Зоны
- Меняются `orchestrator/runner.py` (`role_cwd`, `_prepare_step`, `_place_harvested_docs`), `orchestrator/artifact_branch.py` (`materialize_task_dir`), `tests/` — всё в зонах SPEC. `docs/codebase-map.md` — общая зона (`orchestrator/config.py:799` `COMMON_ZONES`).
- `checkpoint.py`, `brief.py`, `doctor/isolation.py` менять не требуется (бриф уже не несёт чужих записок проверяющим; вызов `role_cwd(None, None, …)` совместим при необязательной роли).
- Защищённые пути не затрагиваются. Песочница ролей не расширяется — выкладка сужается.

## Пути обхода гейтов
- Фильтр как отдельная функция без передачи роли из настоящего запуска — закрыт AC-1/AC-2 (мутация «запуск не передаёт роль»).
- Очистка только обычной материализации — закрыто AC-3 (запасной путь и сбой чтения).
- Тихий запуск при ошибке удаления — закрыт AC-4.
- Фильтрация через удаление из ссылки — закрыта требованием 5 / AC-5.
- Чтение записок git'ом из рабочего каталога (`refs/artifacts/<id>`, `artel.py docs`) остаётся — вынесено Оператором в «Не входит» (решение №1, п.5), отклонением не считается.
