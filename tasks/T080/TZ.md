# ТЗ: П1: макет панели — артефакт UX

# ТЗ: П1 — макет панели (артефакт, утверждение UX)

Источник: роадмап §3 «Панель», этап 1 без демона; ADR-0004 п.7;
design.md §7 (дизайн панели).

Сделать статический макет панели Оператора — артефакт для
утверждения UX, БЕЗ демона, БЕЗ API, БЕЗ кода панели:

1. Один самодостаточный HTML-файл (или набор скетчей) в артефактах
   задачи: борд задач по состояниям FSM, карточка задачи (статус,
   бюджет/расход, итерации ревью, lease), блок алертов, очередь
   гейтов Оператора (spec_gate/merge_gate с кнопками
   approve/reject), кнопка pause (механика T070/T074 уже в строю).
2. Данные — статические примеры, списанные с реального status/ретро
   (анонимизировать не нужно, репо приватный).
3. Выход — утверждение UX Оператором на гейте; макет становится
   опорой для П2′ (`artel report`) и этапа 2 (Г0+).

Границы: никакого демона, БД-доступа, JS-фреймворков и сборки;
только разметка/стили. Оценка рамки: в границах класса макета.
