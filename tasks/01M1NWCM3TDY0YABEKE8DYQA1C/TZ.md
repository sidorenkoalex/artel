# ТЗ: стоимость частичного шага при таймауте — курс токенов вместо тишины

Источник: наблюдение 03.09 (стройка A7): при таймауте шага поток
событий агента не несёт итоговой стоимости, механика T040 печатает
«курс в доллары не задан» и в `spent_usd` списывается ноль; два среза
по ~47 млн токенов прошли мимо бюджета задачи; сегодня таймауты
случаются регулярно (test_author канарейки, developer оценки объёма).

Требуется:
1. Именованные константы курса в config: цена входных и выходных
   токенов по моделям ролей (из roles.yaml), с датой калибровки;
   при таймауте частичная стоимость считается по счётчикам токенов
   потока и курсу и списывается в `spent_usd` задачи с записью в
   журнал «частичная стоимость по курсу».
2. Если курс для модели не задан — не тишина: алерт kind=threshold
   «стоимость шага не учтена» с числом токенов; бюджетный гейт
   считает такой шаг по верхней оценке (константа), чтобы задача не
   ушла за потолок незамеченной.
3. `artel report` показывает долю стоимости, посчитанной по курсу,
   отдельно от точной.
4. Тесты: таймаут с известным курсом списывает частичную сумму;
   без курса — алерт и верхняя оценка; существующие тесты бюджета
   (T007/T012/T040) зелёные без ослабления.

Зоны: orchestrator/config.py, orchestrator/budget.py,
orchestrator/agent_log.py (счётчики потока), orchestrator/alerts.py,
orchestrator/report.py, tests/. Зоны свободны.

Не входит: точная тарификация с кэшем токенов; пересчёт истории.
