# ANSWER-2: ответ Оператора

## Ответы

Вопрос 1 — вариант A. Курс токенов заводится для всех четырёх ролей,
включая developer. Два юнит-теста T040 в tests/test_step_cost.py
(ChargeMissingResultTest.test_partial_tokens_are_journaled_without_
touching_spent и CmdRunPartialCostTest.test_timeout_with_usage_events_
charges_a_partial_token_sum) описывают поведение, которое эта задача
меняет по принятому SPEC: их ожидание переписывается разработчиком
под новое поведение (частичная сумма по курсу списана в spent_usd,
запись «частичная стоимость по курсу» в журнале), с заявкой «Ловит
мутацию» в докстринге; ослаблением это не является — проверка
становится строже (ненулевая сумма, а не ноль). Основание — это
решение Оператора (ANSWER, ADR-0002: изменение существующих тестов
только решением Оператора). AC-8 читать как «существующие тесты
зелёные, кроме двух названных, чьё ожидание меняется этим решением;
без удаления кейсов». test_author: написать тест AC-1 на таблицу по
четырём ролям; тесты T040 сам не трогать — их правит developer в
in_dev.
