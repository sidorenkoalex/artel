# ТЗ: Автогейт приёмки видит долгоживущие файлы планки

Источник: решение Оператора 30.09.2026; строка копилки 30.09 (П1) «Автогейт
приёмки отказывает задаче, чья планка целиком долгоживущая (ADR-0020)».
Пробная задача рабочей связки codex (замер моделей канарейкой 30.09).

Факты (пин fd7b74a3):
- ADR-0020 разрешает test_author класть долгоживущие приёмочные тесты в
  `tests/` ветки задачи; их перечень с суммами —
  `tasks/<id>/acceptance_tests/long_lived.sha256.txt`, читается
  `orchestrator/advance_gates/acceptance.py::long_lived_manifest` (им же
  пользуется прогон планки на переходе `in_dev`).
- Автогейт приёмки (`orchestrator/fsm_autogate.py::_autogate_conditions`,
  стр. ~199–219) собирает каталог планки только из
  `tasks/<id>/acceptance_tests/*.py` артефактной ветки. Если разовых
  файлов нет (планка целиком долгоживущая), он отказывает «каталог
  приёмочных тестов пуст или отсутствует», и задача ждёт Оператора, хотя
  планка есть и зелёная. Пометки manual/skip/ci в долгоживущих файлах он
  при этом не читает вовсе — и при непустом каталоге разовых файлов.
- Тот же сбор повторяет перечень пометок записи «приёмка: что проверит
  approve» (`fsm_autogate.py`, функция над `_acceptance_checklist_detail`,
  стр. ~70–90).
- В канарейке 30.09 на пине fd7b74a3 так отказал автогейт в 7 прогонах
  из 17 (шаблоны `canary-budget-percent-ambiguous`, `canary-log-tail`).

Требуется:
1. Каталог планки для автогейта приёмки и для перечня пометок записи
   «приёмка: что проверит approve» — разовые файлы
   `tasks/<id>/acceptance_tests/*.py` артефактной ветки ПЛЮС файлы из
   перечня долгоживущих, прочитанные с кодовой ветки задачи (тем же
   источником, что прогон планки на переходе `in_dev`). Пометки
   manual/skip/ci/escalate ищутся во всех этих файлах.
2. Отказ «каталог пуст» остаётся только когда нет ни разовых файлов, ни
   записей перечня. Перечень есть, но файл из него не читается с ветки
   задачи — именованный отказ автогейта, называющий файл (не «каталог
   пуст» и не молчаливый пропуск).
3. Поведение для задачи без перечня долгоживущих не меняется: прежние
   тесты автогейта зелёные без правок.
4. Тесты в `tests/`: планка целиком долгоживущая и зелёная — автогейт
   проходит («Ловит мутацию: каталог только из acceptance_tests/»);
   пометка manual в долгоживущем файле — отказ с номером AC; файл
   перечня не читается — именованный отказ; запись «приёмка: что
   проверит approve» перечисляет пометки долгоживущих файлов.

Зоны: orchestrator/fsm_autogate.py, tests/.

Только чтение (не менять): orchestrator/advance_gates/,
orchestrator/acceptance.py, orchestrator/gitcmd.py,
orchestrator/artifact_source.py, orchestrator/fsm.py,
orchestrator/fsm_advance.py, orchestrator/canary.py, orchestrator/config.py,
scripts/guard.py, skills/, templates/, docs/adr/, docs/invariants.md,
tests/test_invariants.py, docs/backlog.md, tasks/.

Не входит: критерий «полный tests/ зелёный» с пометкой skip/manual (строка
копилки 30.09, П2); критерий ci в канарейке (строка копилки 30.09, П2);
сохранение причины отказа автогейта в канарейке.
