# ТЗ: Канарейка v2 (часть 2): привязка пина, триггер doctor, откат пина

# ТЗ: Канарейка v2 (часть 2): привязка пина к зелёной канарейке, триггер doctor, откат пина

Родитель: 01M1NEEWH5K1XPFRDGRMPYSBXJ (часть 1 — механика прогона,
метрики, бейзлайн, изоляция пула). Деление принято Оператором 04.09.
Источник: ADR-0013, роадмап §3 К3, ТЗ канарейки v2 (.artel/tz/
tz-canary-v2-pin-gate.md, пп. 6–7).

Требуется:
1. Команда обновления пина (`pin-update`) отказывает, если на целевом
   sha main артели нет зелёного прогона канарейки (журнал прогонов
   части 1) не старше N мержей main; N — именованная константа
   config; отказ именован и приводит команду запуска канарейки.
2. `doctor` поднимает алерт kind=trigger, когда число мержей main с
   последнего зелёного прогона канарейки достигает той же N.
3. Откат пина: `pin --to <sha>` возвращает запущенную версию на
   указанный коммит; без `<sha>` — на предыдущий зелёный по журналу
   канарейки; каждый откат журналируется с прежним и новым sha и
   причиной; main не изменяется (ADR-0013 ч.3).
4. Тесты: отказ обновления без зелёной канарейки и проход с ней;
   триггер doctor на N мержей; откат по умолчанию и по sha с
   журналом; main не тронут; существующие тесты зелёные.

Зоны: orchestrator/pin.py, orchestrator/doctor.py, tests/. Старт —
после мержа части 1 (нужен её журнал прогонов); до мержа — только SPEC.

Не входит: механика прогона и пул (часть 1); авто-обновление пина.

Рамка: $15.
