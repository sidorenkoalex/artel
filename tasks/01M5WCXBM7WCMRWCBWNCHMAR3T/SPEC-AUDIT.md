- Ручное обязательное задание как «зелёное» — закрыто AC-19/AC-23 через загрузчик записи, не словарь в обход.
- Остаточное наблюдение (не отклонение): внешние входы `ci` принимают `repo`, а не имя проекта; SPEC не называет, как `ci` получает имя для `forge.<функция>(target)` — по коду это `ci._project_context` (`orchestrator/ci.py:135-157`) через `repo_context`.
