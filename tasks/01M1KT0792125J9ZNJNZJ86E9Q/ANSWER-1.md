# ANSWER-1: ответ Оператора

## Ответы

Вопрос 1 (AC-5, «задача прежнего флоу» для требования 2) — вариант A.

`answer` всегда пишет `ANSWER-n.md` в артефактную ветку задачи —
тем же приёмом, которым возврат из эскалации её читает
(`artifact_source.resolve` → `fsm._answer_file_count`); нумерация `n`
считается по содержимому артефактной ветки. Отдельной ветки «прежнего
флоу» в `answer.py` не заводить: после A7 у каждой задачи есть
артефактная ветка, а эскалация без неё невозможна, — сценарий AC-5
недостижим не из-за неполноты поиска, а по устройству системы.
Разработчик закрывает AC-5 пометкой `skip` с этим обоснованием
(по образцу AC-20 задачи 01M1GCN1FPSC1A6WK9WD1Q1V8X); файл
test_ac5 остаётся escalate-пометкой до его решения. AC-2 (маршрут
analyst, `runner.py`) не меняется: его сценарий самодостаточен
и тест написан. Требование 5 SPEC («поведение задач прежнего флоу не
меняется») читать как: поведение задач, у которых `TZ.md` лежит только
в кодовой ветке (AC-2), не меняется; для `answer` такого случая нет.
