# ТЗ: Единый коммит результата роли через пульт для всех провайдеров

# Единое завершение шага: коммит делает пульт

Проблема: разработчик Codex в workspace-write меняет код worktree, но git add получает отказ на внешнем git index. Роль эскалирует обязательный коммит, затем пульт успешно делает автокоммит и всё равно останавливается по PLAN escalate. Повторилось в 01M3SX69E8P64D77J1XTHMHE40 и 01M3V4ZPB6HFDJ36MTDAQG5VNT. Claude имеет иной режим разрешений. Закрытые задачи 01M283NC4JJXK7QS68Y9ET8TBK и 01M290PVYG2VJK6442H5BAX9MA уже реализовали аварийный автокоммит и зонные ограничения; не создавать второй механизм.

Цель: штатный коммит кодового результата роли выполняет пульт одинаково для Codex и Claude. Роль сдаёт код, проверки и свой артефакт, не обязана самостоятельно писать Git-метаданные. Обновить контракт, брифы и диагностику. Пульт проверяет принадлежность изменений мандату и фиксирует результат до перехода состояния. Реальная ошибка коммита должна останавливать продвижение с точной причиной; содержательные эскалации роли не снимать автоматически.

Требования: сохранить зонные проверки, защиту main и залоченных тестов, ограничения ролей, разделение кодовой и артефактной веток, lease, checkpoint при ошибках/таймаутах и фиксацию SHA. Не расширять sandbox. Успешный штатный коммит пульта не считать дефектом роли. Повторное завершение не создаёт пустых/дублирующих коммитов. Не присваивать чужие изменения. Аналитик обязан определить поведение для external target, test_author и уже существующих коммитов, не расширяя права этих ролей. Регрессии: Codex с недоступным git index, Claude, отказ git пульта, посторонние файлы, повтор завершения, содержательная эскалация.

Не входит: исправление авторизации канарейки, миграция хуков, автоматические approve/merge/deploy и снятие содержательных эскалаций.

Зоны: orchestrator/checkpoint.py, orchestrator/runner.py, orchestrator/agent_prompt.py, orchestrator/brief.py, tests/, docs/operator-session.md, docs/stack.md

Аналитик уточняет минимальные зоны и бюджет в SPEC. Новую задачу пока только завести, реализацию не запускать.

Приложением: skills/, templates/ — необходимые изменения контрактов представить для отдельного внесения Оператором; защищённые файлы роль напрямую не правит.
