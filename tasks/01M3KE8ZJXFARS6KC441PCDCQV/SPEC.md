# SPEC: Каталог моделей — три новые модели, сверенные цены, снятие gpt-5.5; закреплённая версия клиента Claude

## Контекст

Каталог `models.yaml` несёт три модели раздела `claude` и пять моделей
раздела `codex`. Цены записей `claude-sonnet-5` и `claude-fable-5-1`
разошлись с действующим прейскурантом (у второй прямо в файле стоит
пометка «ЦЕНЫ НЕ СВЕРЕНЫ»), у всех записей раздела `codex` цена записи
в кэш равна цене входа, а модель `gpt-5.5` снимается в клиенте Codex
14.10.2026. Оператор сверил цены и идентификаторы по официальным
страницам производителей 28.09.2026 и решил добавить три модели
(`claude-opus-5-5`, `gpt-6-sol`, `gpt-6-luna`) — таблица ярусов для
замера канарейки на моделях двух провайдеров, ADR-0019 п.5 и п.7.

Командой `doc-commit` эта правка не проходит: состав каталога сверяет
литералом метод `tests/test_models.py` (перечень моделей по разделам,
около строк 136–146) — намеренно, «каталог решает, на чём вообще идут
роли». Добавление или снятие модели без правки литерала красит набор, а
`doc-commit models.yaml` гоняет полный набор `tests/` перед отправкой и
красный набор не пропускает. Поэтому правка идёт задачей: каталог —
приложением к PLAN (защищённый путь), литерал состава — кодовой веткой.

Той же задачей закрывается расхождение закреплённой версии клиента:
`config.CLI_VERSION_PIN` равен `2.1.267`, на пульте 28.09.2026 стоит
2.1.283 (Homebrew), и расхождение даёт предупреждение `doctor` и команды
`artel.py version` на каждом шаге.

Сверка ссылок на снимаемую модель (требование 2 ТЗ) выполнена при
написании этого SPEC на голове ветки задачи: строка `gpt-5.5`
встречается только в `models.yaml` (запись, строки 125–133) и в
`tests/test_models.py` (строки 141, 145 — тот самый литерал состава).
В коде `orchestrator/`, в `roles.yaml` и в образце локального слоя
`docs/reference/models-local.example.yaml` ссылок на неё нет — перевода
ссылок на другую модель каталога или на фикстуру не требуется. Ещё одно
упоминание — прозой в строке бэклога `docs/backlog.md` (перечень моделей
для будущего замера канарейки); `docs/backlog.md` ТЗ отнесло к путям
только на чтение, и эта задача его не трогает.

## Критерии приёмки

AC-1. `models.yaml` (приложением к PLAN) несёт три новые записи: в
разделе `claude` — `claude-opus-5-5` с ценами 4.00 / 20.00 / 5.00 / 0.20,

AC-3. Записи `gpt-5.5` в `models.yaml` нет, и строку `gpt-5.5` не несёт
ни один файл `orchestrator/`, `roles.yaml`, `docs/reference/models-local.example.yaml`

AC-4. Перечень моделей в `tests/test_models.py` — по разделу `claude`, по
разделу `codex` и общий — равен новому составу каталога из требования 3;

AC-5. Ни один тест `tests/` не утверждает литералом прежнюю цену или
прежнюю наименьшую версию клиента правленой записи каталога: значения

AC-6. Тесты `tests/`, которым нужна произвольная модель каталога (не сам

AC-7. `config.CLI_VERSION_PIN` равен версии клиента Claude, установленной
