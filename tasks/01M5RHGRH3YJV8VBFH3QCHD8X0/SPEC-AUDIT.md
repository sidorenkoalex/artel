## Пути обхода гейтов
1. «Только добавления» против правки перечня импорта (AC-7/AC-16 vs SPEC 8,
   `tests/test_merge_after_module.py:46–47`): чтобы буквально пройти AC-7,
   разработчик заведёт отдельную строку `from orchestrator import
   github_adapter, workspace` в обход «в перечень» SPEC 8 — или наоборот
   нарушит AC-7. Обход не опасен по существу, но проверка AC-7 по
   `git diff` тогда не отличит допустимую правку импорта от правки
   существующего кода модуля, если Оператор разрешит изменённые строки
   без адреса.
2. Признак «способный зациклить общий узел» (SPEC 2, AC-2) оставлен на
   суждение исполнителя и не фиксируется: можно сложить в одну часть
   несколько патчей `check`/`unique_prefix`/`_cycle_path` с ожиданием, что
   предел 1500 с части (`targets.yaml:53`) «не наступит», и формально AC-2
   выполнить.
3. Фраза «почему убийство не зависит от зерна» (SPEC 5, AC-5) — самоотчёт
   исполнителя; проверяется только независимой проверкой сессии (SPEC 17).
   Разрыв закрыт ТЗ 13 / SPEC 17 — отклонением не считаю.
4. Таблица «до» может быть получена до подтяжки main, «после» — после:
   закрыто SPEC 13 (деревья `orchestrator/`/`scripts/` обеих шапок равны,
   иначе «до» заново).
