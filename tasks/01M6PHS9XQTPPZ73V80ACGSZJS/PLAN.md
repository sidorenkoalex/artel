# PLAN: target-set — запись и снятие ключа поля-отображения локального слоя

## Подход
Всё в `orchestrator/projects.py`, в `cmd_target_set`:

- Новая форма распознаётся по третьему аргументу (`rest[2]` из
  `("--key", "--drop-key")`) сразу после `-h`/`--show`; неверное число
  аргументов (`--key` — ровно 5, `--drop-key` — ровно 4) — отказ с
  `TARGET_SET_USAGE`. Поле — из перечня `KEY_FIELDS = ("machine.submodule_tokens",)`
  (путь сравнивается целиком, поэтому `machine.submodule_tokens.<к>` тоже
  отказ с перечнем).
- Общий префикс прежней формы (проект артели, загрузка слоёв, запись в
  локальном слое, чтение и разбор файла, отказ на комментарии) выносится в
  `_target_set_load(name)` — тексты отказов побайтно прежние, прежняя форма
  зовёт тот же помощник. Хвост записи (журнал доступен → копия → атомарная
  запись → журнал → вывод) — в `_target_set_write`, тоже общий.
- `--key`: ключ проверяется пробным `_render({ключ: None})` — одно правило
  записываемости ключа, а не копия условий; значение — `_argument_value`,
  затем `targets._submodule_tokens_error({ключ: значение})` (текст проверки
  загрузчика в отказе). Ключи пути — `[machine, submodule_tokens, ключ]`,
  запись — прежний `_assign`, сверка — `_target_set_mismatches` по имени
  модуля (подмена атрибута доходит до вызова).
- `--drop-key`: ключа нет — отказ с именем ключа; снятие в копии данных,
  пустое поле снимается целиком; сверка — новая
  `_drop_key_mismatches(data, text, name, keys, path)`: изменился ровно
  лист `targets.<проект>.<раздел>.<поле>.<ключ>`, он был и его нет;
  сведение `merge_local` всех записей проходит, прочие записи сводятся как
  прежде. Общие части сверок (список изменённых листов, сведение записей)
  вынесены из `_target_set_mismatches` помощниками без смены её поведения.
- Строка журнала/вывода — `<раздел>.<поле>[<ключ>]: <было|(нет)> → <стало|(нет)>`;
  повтор значения — «без изменений» до копии и журнала.
- Справка: `TARGET_SET_USAGE` и строки `target-set` в докстринге
  `orchestrator/artel.py` — по одной альтернативе на строку, каждая с
  `target-set`.

## Влияние на систему
Затронута только команда Оператора `target-set`; прежняя форма идёт тем же
путём через вынесенные помощники с прежними текстами отказов (держат
`tests/test_projects_target_set.py`,
`tests/test_01m6kbd9fc36warwsy9z0jdmg5_target_set.py`, AC-11).
`_target_set_mismatches` сохраняет сигнатуру и поведение — вынесены лишь
куски тела. Загрузчик `targets.py` не меняется: значение проверяется его
же функцией `_submodule_tokens_error`. Гейты, лимиты, тесты не ослабляются.
Откат — revert коммита задачи.

## Риски
- Ключ, который `_render` пишет, а `yamlmini` читает иначе (например `a #b`),
  — ловит сверка (лист не тот), отказ до записи.
