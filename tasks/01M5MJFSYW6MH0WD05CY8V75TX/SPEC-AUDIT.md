## Проверяемость критериев

| Критерий | Проверяем | Ловимая мутация |
|---|---|---|
| AC-1 | да | разность с предыдущей строкой чужого процесса; отсчёт от `start` при наличии строки `N workers`; `1 worker [1 item]` не распознаётся; повтор id не суммируется или исход не худший; засчитаны строки после `_REPORT_SECTION` или строки не хода |
| AC-2 | да | поток не запущен; разбор после `proc.wait` (у спящего ≈ 0 с); отметка по приходу `\n` (у быстрого ≈ 3 с при пороге < 1,5 с); иное имя файла; запись в сам лог. Запас от квантования 0,5 с при 3 с и пороге 1,5 с есть |
| AC-3 | да | запись не по мере появления: нет `flush` или запись только в конце, тогда строки быстрого 1 до предела нет; хвост без `\n` не дочитан, тогда нет строки быстрого 2; поток стоит после снятия группы без дочитывания. При одном рабочем процессе строку быстрого 1 закрывает `\n` строки быстрого 2 — проверка до предела выполнима при соблюдении требования 1 |
| AC-4 | да, только планка | имя файла попало под `{prefix}*.log`, и номер следующего лога сдвинулся |
| AC-5 | да | блока нет или он стоит до `render`; срез не 30/15; порядок не по убыванию; время файла не сумма; повтор не суммирован; блок по базе, без файла или при пустом файле; блок в логе или в `output`; новый ключ `result.json`; в `--failed` взят файл не того прогона |
| AC-6 | да, зелёный на текущем коде | новый флаг argv или переменная окружения; файл времени при `log=None` или у `pytest-own` |
| AC-7 | да, только планка | исключение потока выходит наружу; `join` без таймаута; поток жив после снятия группы; `join` до `:2877`/`:2886` при `observe` (ожидание попадает в длительность для `_signal_near_limit`); добавка у базы больше 2 с |
