# ТЗ: verifying: auto-опрос CI и потолок по времени

# ТЗ: verifying — владелец опроса CI и потолок по времени

Источник и мандат: решение Оператора 31.08 по находкам MJ-3 и MJ-4
аудита v6 (docs/audits/roadmap-audit-2026-08-31-v6-complex.md);
контекст состояния — SPEC T079, ADR-0009.

Проблема: `auto` останавливается на входе в `verifying`, опрос CI
повешен на ручной `advance` Оператора — владельца опроса нет
(1–20 ручных касаний на задачу ДО автогейта acceptance). Потолок
`LIMIT_VERIFYING_ATTEMPTS = 20` считает попытки при незаданной
частоте: минутный цикл сжигает его за 20 минут при штатной
задержке CI-событий до ~40 минут (прецедент T040) — ложная
эскалация; редкие ручные вызовы растягивают его на недели. Повтор
класса «потолок в попытках без частоты», закрытого T082 для
агентных ретраев.

Требуется:

1. Владелец опроса — `auto`: из `verifying` цикл не выходит,
   а повторяет advance-опрос CI с паузой порядка 60–120 секунд
   (конфиг-константа). Опрос НЕ расходует AUTO_MAX_STEPS (это
   ожидание, не шаг конвейера). Исходы опроса не меняются
   (SPEC T079): зелёный → acceptance и цикл продолжается; красный
   завершённый → auto останавливается с подсказкой про reject
   (ADR-0009: verifying сам не возвращает); «проверок нет вовсе» —
   ждать тем же циклом.
2. Потолок ожидания — по ВРЕМЕНИ от входа в состояние
   (updated_at перехода уже в журнале/БД), конфиг-константа
   порядка 90 минут; исчерпание — эскалация, как сейчас.
   LIMIT_VERIFYING_ATTEMPTS упраздняется или переопределяется
   через время — решить в SPEC, счётчик попыток в журнале можно
   сохранить как информационный.
3. Ручной `advance` из `verifying` продолжает работать как раньше
   (разовый опрос без цикла) — auto не становится единственным
   путём.
4. Инвариант 18 не трогать: auto по-прежнему не проходит гейты —
   опрос CI гейтом не является, переход verifying → acceptance
   и сейчас автоматический при зелёном CI.

Не входит: автопуш головы ветки (M2); ре-ран красного CI
(механика T082 живёт на merge_gate); сторожевой doctor-прогон
(рекомендация T084 — отдельным решением); двойная CI-петля
merge_gate после подтяжки (отдельная находка Q-5).

Рамка: $15–25.
