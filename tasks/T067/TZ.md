# ТЗ: Авторазрешение конфликта карты при подтяжке

## Контекст

Строка P3 «Подтяжка: авторазрешение конфликта docs/codebase-map.md
регенерацией». Факт 28.08: шесть конфликтов подтяжки за день при
N>1 — все ТОЛЬКО в docs/codebase-map.md, все разрешены Оператором
одинаково: checkout --theirs → scripts/codebase_map.py → add → commit.
Причина: карта — генерируемый файл, функция от кода; каждая ветка
регенерирует свой снимок, main несёт снимок соседей — контентный
конфликт гарантирован, даже когда по коду конфликтов нет вообще.
Правильное разрешение не выбирается, а ВЫЧИСЛЯЕТСЯ: карта слитого
дерева. Прецедент уже в системе: T042 научила оркестратор чинить
карту при мерже в main тем же приёмом.

## Решение (Оператор 28.08)

1. В механике подтяжки (`fsm._pull_main_or_escalate`, T051) при
   конфликте merge: если конфликтующие файлы — ЭТО ТОЛЬКО
   docs/codebase-map.md, оркестратор не эскалирует, а разрешает сам:
   берёт любую сторону (checkout --theirs), регенерирует карту
   генератором scripts/codebase_map.py НА СЛИТОМ дереве worktree,
   git add + завершает merge-коммит; подтяжка считается успешной,
   дальше прежний путь (прогон приёмочных и т.д.). Журнал получает
   запись о авторазрешении (actor=orchestrator, файл, способ).
2. Конфликт затрагивает что-либо КРОМЕ карты — поведение прежнее:
   merge --abort, эскалация с перечнем файлов (T051/T052). Карта в
   списке вместе с другими файлами — тоже эскалация (авторазрешение
   только для чистого случая «одна карта»).
3. Тот же приём — в merge-окне merge_gate (T053, если подтяжка внутри
   окна упирается в конфликт карты) и в любом другом месте, где
   вызывается общая механика подтяжки: разрешение живёт в ОДНОЙ
   функции, вызываемой из обеих точек, не копипастой.
4. Отказ генератора карты (ненулевой код) при авторазрешении →
   merge --abort и эскалация как при обычном конфликте: полусмерженное
   состояние не остаётся (fail-closed).
5. Деградация без реального git (песочницы) — по существующим
   образцам T051.

## Границы

- orchestrator/ (fsm и смежные), тесты, карта.
- Не ослаблять существующие тесты/инварианты (ADR-0002); эскалационные
  пути T051/T052 для не-карточных конфликтов остаются байт-в-байт.
- main не трогается ничем (авторазрешение живёт в worktree ветки).

## Не входит

- Авторазрешение любых других файлов (только docs/codebase-map.md).
- patch-id-фиксация approve (отдельная строка P3).
- Изменение генератора карты.

## Приёмка (минимум)

- Подтяжка с конфликтом только в карте → разрешается автоматически:
  merge-коммит есть, карта соответствует слитому дереву (повторный
  прогон генератора не даёт диффа), журнал несёт запись, эскалации
  нет, подтяжка продолжается штатно.
- Конфликт в карте + любом другом файле → merge --abort, эскалация
  с перечнем, ветка чистая (поведение T051 байт-в-байт).
- Отказ генератора при авторазрешении → merge --abort, эскалация,
  ветка чистая.
- Существующие тесты зелёные без ослаблений.
