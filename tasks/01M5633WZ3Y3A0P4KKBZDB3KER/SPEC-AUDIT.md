## Пути обхода гейтов
- (Е1) Требование 2 говорит «у задачи внешнего проекта», AC-1 проверяет артель
  только без подполя. Буквальное исполнение «перечень берётся из профиля любого
  проекта» проходит все AC, и тогда подполе в записи артели молча расширит
  правило артели (требование 5 нарушится без правки кода). Нет критерия «у
  артели подполе не действует» либо явного решения, что действует.
- (Е2) Без определения «строка-имя» (AC-7) реализация может принять
  элементы-шаблоны (`*`) или пустую строку; с наивной проверкой по префиксу
  (`startswith`) перечень `["s"]` разрешил бы `sqlalchemy`, `subprocess`-подобные
  имена. Критерии AC-2/AC-5 на точное сравнение верхнего имени не настаивают.
  Риск низкий (перечень пишет только Оператор), но критерий его не держит.
- (Е3) Частичное покрытие мест рубежей (см. AC-2, AC-3, AC-6): буквальный
  тест по одному месту оставляет второе место без перечня/подсказки —
  preflight разойдётся с гейтом, ради совпадения с которым он существует.
