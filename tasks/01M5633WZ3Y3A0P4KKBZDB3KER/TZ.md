# Долгоживущие тесты внешнего проекта: правило импортов по профилю

## Факты

Строка бэклога 18.10 (П1), разбор «что прибито под артель». Правило импортов долгоживущих файлов (`scripts/guard.py:2604-2614` — `_LOCAL_PACKAGES = ("orchestrator", "scripts", "tests")`, `_allowed_import_tops` = stdlib + эти пакеты + `stack.THIRD_PARTY_EXCEPTIONS`; применение `:2709-2730`) — правило артели. У внешнего проекта (sled: Python/FastAPI в `backend/`, `workdir: backend`, код в `backend/src`) импорт `from src…`, `fastapi`, `httpx`, `sqlalchemy`, `pydantic` в долгоживущем файле `backend/tests/test_<id>_<имя>.py` — «импорт вне перечня»: отказ на выходе из `tests_writing` (`orchestrator/advance_gates/tests_writing.py:351, 470`), в `preflight` (`orchestrator/preflight.py:186, 203`), в `amend-tests` (`orchestrator/amend.py:512`). Долгоживущий тест sled, импортирующий код проекта, завести нельзя. Соседнее правило сетевых адресов уже закрыто `repo_context.is_artel` (`tests_writing.py:79`), это — нет. Пояснение признака (`guard.py:2596-2598`) — про «помощники из tests/sandbox.py» (артель).

## Требуется

1. У задачи внешнего проекта проверка импортов долгоживущих файлов разрешает пакеты кода проекта и его зависимостей. Источник перечня аналитик выбирает и обосновывает в SPEC (варианты: новое необязательное поле профиля `test_profile` со списком разрешённых верхних имён; верхние пакеты каталога `workdir` плюс зависимости из lock-файла проекта; либо отключение этого правила для внешнего проекта с записью журнала); правки `orchestrator/targets.py`/`project_profile.py` — если нужны — назвать в SPEC (сейчас вне зон, эскалация до SPEC).
2. Остальные признаки статического разбора долгоживущего файла (приватные атрибуты, подмена, `sys.path`) аналитик сверяет на применимость к внешнему проекту и перечисляет в SPEC; правки — в зонах.
3. У артели правило и тексты отказов не меняются; зафиксировать тестами до правки.
4. Тесты детерминированы, без сети: учебный внешний проект — долгоживущий файл с `from src.app import x` и импортом зависимости проекта проходит выход из `tests_writing`, `preflight`, `amend-tests`; импорт вне разрешённого перечня проекта — отказ, текст называет перечень проекта; у артели — прежние исходы.

Критерии приёмки:
- у артели правило импортов и тексты прежние;
- у учебного внешнего проекта импорт кода проекта и его зависимостей в долгоживущем файле разрешён на всех трёх рубежах, вне перечня — отказ.

Зоны: `scripts/guard.py`, `orchestrator/advance_gates/tests_writing.py`, `orchestrator/preflight.py`, `orchestrator/amend.py`, `tests/`.

Только чтение: `orchestrator/project_profile.py`, `orchestrator/targets.py`, `orchestrator/repo_context.py`, `orchestrator/stack.py`, `targets.yaml`, `docs/backlog.md`. Правка вне зон — эскалация до SPEC.

Не входит: гейты по тестам на чужом стеке (помощники, параметризация, async — отдельная строка); выкладка планки внутрь workdir (отдельная строка).

Рамка: $30. Набор моделей — по умолчанию.
