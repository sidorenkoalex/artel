«Оценка объёма и деление» для закрытой задачи отчёт берёт из новой
колонки `split_assessment` таблицы `tasks` (текст секции либо

report` читает колонку из БД без git; для задач, закрытых до появления
колонки, — прочерк. Остальное без изменений.
