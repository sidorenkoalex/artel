## Пути обхода гейтов
1. Подгонка предпосылки: оставить пуш и после него вернуть ссылку отслеживания `update-ref refs/remotes/origin/<MAIN> <tracking_before>` в git пульта — `:67-69` зелёная буквально. Закрыто AC-2 («не вызывает `git push` и иную отправку из git пульта»).

3. Перенос объектов: коммиты созданы в `self.root` и затянуты в bare `git --git-dir <origin> fetch <root>` — формально не «отправка из git пульта», но противоречит требованию 1 («коммиты создаются в самом bare-репозитории»); AC-2 это называет прямо. Закрыто.
4. Ослабление предпосылки (удалить `:67-69` как «больше не нужную») — закрыто AC-3/AC-5 и гейтом неослабления (`weakened_helpers` по `advance_origin`).
5. Детерминизм вместо `self.rng` (всегда 1 коммит) — AC-2 требует 1–3 из `self.rng`. Закрыто.
