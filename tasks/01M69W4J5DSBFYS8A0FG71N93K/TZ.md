# ТЗ: Предпосылка теста fetch базы рабочей копии не зависит от версии git (git 2.56 на раннере CI)

# Предпосылка теста fetch базы рабочей копии не зависит от версии git

## Факты

1. CI `main` красный на двух тестах `tests/test_01m42nbcadgsgtcbzb8nkbvdvh_workspace_fetch.py`: `LockedTrackingRefTest::test_ac3_ensure_succeeds_with_locked_tracking_ref` и `TrackingRefUntouchedTest::test_ac4_ensure_fetch_does_not_move_tracking_ref` (перезапуск CI main 2e3d25ae, прогон 40417365334, попытка 2, 31.10.2026). Тот же коммит был зелёным 26.10.
2. Между прогонами сменился образ раннера CI (ubuntu-24.04 от 25.10): git 2.55.0 → 2.56.0. Локально (git 2.50) файл зелёный.
3. Падение — в предпосылке `advance_origin` (`:57-72`), до кода пульта: голова `origin` сдвигается пушем по пути bare-репозитория, после чего проверяется, что ссылка отслеживания `refs/remotes/origin/<MAIN_BRANCH>` не сдвинулась. git 2.56 при пуше по пути, совпадающему с адресом `origin`, эту ссылку обновляет — предпосылка «пуш по пути сдвинул ссылку отслеживания» падает.
4. Красный CI `main` блокирует CI веток всех задач (задача 01M5XZ9Z68V75VXF5Z66C708T4 эскалирована по этой причине).

## Требуется

1. `advance_origin` сдвигает голову `origin` на 1–3 коммита, не используя git пульта для отправки: коммиты создаются и ссылка `refs/heads/<MAIN_BRANCH>` обновляется в самом bare-репозитории (`git --git-dir <origin> commit-tree` / `update-ref`). Предпосылки (голова `origin` сдвинута; ссылка отслеживания пульта на прежнем коммите) и все проверки AC-3, AC-4, AC-5 — без изменений; описание сценария в строке документации модуля и метода — по новому способу.
2. Код пульта не меняется.

Критерии приёмки:
- файл зелёный локально и в CI ветки задачи (раннер с git 2.56);
- мутация «fetch базы по имени `origin` с обновлением ссылок отслеживания» в `workspace._fetched_base` краснит AC-3 и AC-4, AC-5 остаётся зелёным — как до правки;
- число тестов и их проверки (`assert*`) в файле не уменьшились.

Зоны: `tests/test_01m42nbcadgsgtcbzb8nkbvdvh_workspace_fetch.py` (только `advance_origin` и строки документации).

Только чтение: `orchestrator/workspace.py`, `orchestrator/gitcmd.py`, `tests/sandbox.py`.

Существующие тесты: правка долгоживущего файла задачи 01M42NBCADGSGTCBZB8NKBVDVH — мандат Оператора 31.10.2026 («Заведи задачу» на правку предпосылки под git 2.56): без ослабления, сценарий и проверки прежние, с матрицей неослабления и проверкой мутацией. Новые долгоживущие тесты не ожидаются; если пульт требует свой тест задачи — эскалация.

Не входит: код пульта (`orchestrator/`); прочие тесты, пушащие по пути (`tests/test_gitcmd_fetch_ref_sha.py` и др.) — зелёные на git 2.56, не трогать.

Рамка: $15. Набор моделей — по умолчанию.
