# ТЗ: идемпотентность `workspace.ensure` не зависит от символических ссылок в пути

Источник: первый боевой прогон канарейки v2 05.09 (`canary --k 2`,
прогон 20260905T175403Z). Обе задачи набора убиты как «не сходятся»
после трёх холостых проходов, ни один шаг роли не стартовал, расход $0.
Воспроизведение Оператором в эфемерном клоне с видимым выводом `auto`:
`agent run SKIPPED — рабочий каталог роли не создан: … fatal:
'<клон>/.artel/worktrees/<id>' already exists`. Канарейка заводит
worktree явно (`workspace.ensure`), затем шаг роли зовёт `ensure`
повторно; идемпотентность `ensure` — по регистрации в `git worktree
list`, а сравнение путей идёт без нормализации: клон лежит в
`tempfile.mkdtemp()` под `/var/folders/...`, git отдаёт зарегистрированный
путь как `/private/var/folders/...` (символическая ссылка macOS) —
проверка не находит worktree и вызывает `git worktree add` на
существующий каталог.

Требуется:
1. `workspace.ensure` (и все места сравнения путей worktree с выводом
   `git worktree list`) сравнивают пути после `Path.resolve()` с обеих
   сторон; повторный вызов `ensure` для уже заведённого worktree под
   символической ссылкой возвращает тот же путь без ошибки.
2. Канарейка (`canary._drive_task`/`cmd_canary`) при
   `agent run SKIPPED` из-за рабочего каталога или окружения роли не
   крутит холостые проходы до стоп-крана, а завершает задачу набора как
   «не сошлась» сразу с причиной из журнала шага и печатает её в отчёт
   прогона (сейчас причина видна только внутри уничтоженного клона).
3. Отчёт прогона `canary` печатает для каждой задачи причину исхода
   `killed` (штатно на merge_gate/verifying / не сошлась: <причина>).
4. Тесты: `ensure` дважды на пути через символическую ссылку (фикстура
   с `os.symlink`) — второй вызов без ошибки; канарейка на песочнице с
   `SKIPPED` завершает задачу сразу с причиной; существующие тесты
   workspace и canary зелёные.

Зоны: orchestrator/workspace.py, orchestrator/canary.py, tests/.
Приоритет: высокий — без этого невозможен зелёный прогон канарейки,
бейзлайн К3 и мерж канарейки ч.2 (её AC-1 блокирует pin-update без
зелёного прогона). Пересечение: canary.py у канарейки ч.2 (на
merge_gate, код не меняется) — свободна.

Рамка: $15.
