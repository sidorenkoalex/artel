# ТЗ: Тестовые хелперы третьего поколения — свести в общую песочницу

Источник: ревизия кодовой базы 31.08
(docs/audits/code-revision-2026-08-31.md, находка CR-2).

После T037 (общая песочница) и T061 (FakeProc, claude-only моки)
выросло третье поколение дублей мимо tests/sandbox.py:
- `_ts_ago` — байт-в-байт в 4 файлах (4 места знают формат
  heartbeat lease);
- `FakeStream` — 4 копии;
- `SpyRun`, `RealGitSandbox`, `_dead_pid` и родственные — по 2 копии.

Требуется: свести перечисленные хелперы в `tests/sandbox.py`
(единственная точка знания формата/приёма), тестовые файлы перевести
на импорт из песочницы; точный список копий — в отчёте ревизии,
при находке дублей того же класса сверх списка — включить («чини
класс, не экземпляр»). Поведение боевого кода не меняется — правки
только в tests/ и tasks/*/acceptance_tests/ (если дубли есть там,
трогать ТОЛЬКО файлы, чьи задачи ещё не закрыты, — артефакты
закрытых задач не редактируются; их копии перечислить в артефактах
как известный остаток).

Критерий: полный набор tests/ зелен; grep по сигнатурам дублей
находит только определения в sandbox.py.

Рамка: $15–25.
