# Записка ревьювера, итерация 3

## Выяснено
- Обход белого списка: псевдоним, заданный в самой команде, у которого назначение лежит в его теле, а не в словах argv. Пример: `gitcmd.git("-c", "alias.p=push <клон target-human> main", "p")` из корня пульта; так же с `!git -C <клон> push …`. `_alias_guarded_project` смотрит только на клон вызова и слова после подкоманды, поэтому `_push_plan` возвращает None и шпион видит отправку. Подтверждено пробой в 4 из 4 случаев (target-human и испорченный слой) и сквозным вызовом `gitcmd.git`. Проба удалена.
- Сдвиг refspec `zip(specs, positions[1:])` выровнен: `_refspecs` даёт по одной записи на каждое позиционное слово.
- Путь через переменные окружения (GIT_CONFIG_GLOBAL и подобные) нереалистичен: `_raw_config` берёт `pult_env()`, то есть то же `os.environ`.
