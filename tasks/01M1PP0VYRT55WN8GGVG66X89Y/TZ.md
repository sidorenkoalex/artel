# ТЗ: Частичная стоимость шага по видам токенов (чтения кэша по своей цене), калибровка курса

# ТЗ: частичная стоимость шага по видам токенов, а не по средней ставке

Источник: первое боевое срабатывание тарифа 04.09 (задача
01M1NWCM3TDY0YABEKE8DYQA1C). `spend.step_tokens` суммирует все
счётчики usage (`config.USAGE_TOKEN_KEYS`: input, output, cache_creation,
cache_read), а `spend.partial_cost_usd` умножает сумму на среднее цен
входного и выходного токена роли. Чтения кэша — почти весь объём шага
и стоят на порядок дешевле входа: ставка $9 за миллион завышала
частичную стоимость таймаута в ~20 раз (developer канарейки ч.1:
$83.58 за 9,3 млн токенов при реальных ~$4; по восьми завершённым
шагам цена CLI — $0.42–0.53 за миллион суммарных токенов). Задача
ушла в эскалацию по бюджету с $128 при потолке 70, из них ~$80
фиктивные. Временная мера Оператора 04.09: одинаковая эмпирическая
ставка $0.45/млн на оба вида токена в `config.TOKEN_RATES`.

Требуется:
1. Частичная стоимость считается по видам токенов: поток
   `stream-json` несёт в `message.usage` раздельные счётчики
   `input_tokens`, `output_tokens`, `cache_creation_input_tokens`,
   `cache_read_input_tokens` — накапливать их раздельно (не одной
   суммой) и умножать каждый на свою цену из таблицы курса
   (`config.TOKEN_RATES[role]`: четыре цены на роль, прейскурант
   модели: вход, выход, запись кэша, чтение кэша).
2. Калибровка: команда пульта (или `report`) сравнивает по завершённым
   шагам цену из финального события `result` с расчётом по видам
   токенов и печатает коэффициент расхождения по роли; расхождение
   больше именованного порога — алерт `kind=warning`.
3. Совместимость: записи журнала «agent cost PARTIAL» и колонка
   `spent_estimate_usd` не пересчитываются задним числом (требование
   9 исходной задачи); формат журнала шага дополняется разбивкой по
   видам.
4. Тесты: стоимость таймаута с известной разбивкой равна сумме по
   видам; чтения кэша не тарифицируются по цене входа; калибровка
   печатает коэффициент и поднимает алерт при расхождении; курс без
   одной из цен — именованный отказ, не тихий ноль; существующие
   тесты тарифа (T007, T012, T040, 01M1NWCM3T…) зелёные без
   ослабления.

Зоны: orchestrator/spend.py, orchestrator/config.py (структура
TOKEN_RATES), orchestrator/agent_log.py (накопление по видам),
orchestrator/report.py (калибровка), tests/. Не входит: тариф по
модели вместо роли (бэклог, после поля модели в roles.yaml); пересчёт
прошлых записей.

Рамка: $15.
