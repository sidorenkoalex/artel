## Предложения системе

- `alerts.raise_alert`'s дедуп по точному совпадению `message` подходит для алертов «по шагу/задаче» (естественно идентичный текст при повторе того же отказа), но ломается для алертов-АГРЕГАТОВ, чей текст неизбежно меняется между прогонами (эта задача — первый такой случай, `report.token_rate_divergence`). Стоит явно задокументировать в `alerts.py`, что дедуп по message пригоден только для точечных, не аккумулирующих сигналов — иначе следующая метрика-агрегат наступит на те же грабли.
