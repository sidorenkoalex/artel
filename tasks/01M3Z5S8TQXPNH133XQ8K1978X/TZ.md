# ТЗ: Допуск набора сверяет роли вне набора с боевыми моделями

Источник: строка бэклога 02.10 (П1) «Допуск набора сверяет роли вне
набора с боевыми моделями»; ADR-0019 п.5 («набор целиком прошёл зелёный
прогон трудного класса (роли передают друг другу артефакты, пара
проверяется и в соседстве)»); решение Оператора 02.10 — первая настоящая
задача набора `codex-dev`.

Факты (пин a6904801; номера строк аналитик сверяет):
- `orchestrator/models.py::set_admitted` (около строки 1239) признаёт
  набор допущенным, если есть строка `canary_runs` с `verdict = green` на
  шаблоне класса `трудный`, чья сводка моделей (`summary_models`, около
  строки 1080) совпадает с набором только по ролям, перечисленным в
  наборе.
- Пример: набор `codex-dev` (`developer: gpt-6-sol`) признаётся
  допущенным по прогону 20260930T120255Z (набор канарейки `c-codex-mix`,
  где на Codex шли все четыре роли) — функция называет этот прогон в
  пояснении. Прогон с правильным соседством (остальные роли на боевой
  модели) есть: 20261002T201326Z.
- Боевая модель роли — `models._combat_model(role)` (около строки 1230).

Требуется:
1. Зелёный прогон трудного класса засчитывается набору, только если
   сводка прогона совпадает с набором по ролям набора И каждая роль
   сводки, которой нет в наборе, шла на боевой модели этой роли
   (`_combat_model`). Роль, отсутствующая в сводке прогона, — прогон не
   засчитывается.
2. Пояснение `set_admitted` называет засчитанный прогон; при отказе —
   причину «нет зелёного прогона набором целиком на шаблоне класса
   «трудный» (роли вне набора — на боевых моделях)».
3. Прочие условия допуска (пары, приостановка, класс шаблона) не
   меняются.
4. Тесты в `tests/`: прогон, где роли вне набора шли на других моделях, —
   не засчитан («Ловит мутацию: прогон с другими моделями у ролей вне
   набора засчитан»); прогон с ролями вне набора на боевых моделях —
   засчитан; существующие тесты допуска набора, `new --set` и
   `set-models` не удаляются и не ослабляются.
5. `docs/stack.md`: в разделе о допуске набора — уточнение про роли вне
   набора.

Рамка: $20

Зоны: orchestrator/models.py, tests/, docs/stack.md.

Только чтение (не менять): orchestrator/canary.py, orchestrator/store.py,
orchestrator/catalog.py, orchestrator/runner.py, orchestrator/config.py,
model_sets.yaml, models.yaml, scripts/guard.py, skills/, templates/,
docs/adr/, docs/invariants.md, tests/test_invariants.py, docs/backlog.md,
tasks/, .artel/.

Не входит: правила приостановки и возобновления допуска пары по
канарейке (строка бэклога 02.10 П3); изменение чисел допуска ADR-0019;
выбор набора задачи.
