- Значение «из двух строк» загрузкой файла слоя недостижимо (опыт): `a: |` → `YamlError` «неожиданный отступ»; `"x: y` + перевод строки + `z: w"` разбирается в два разных ключа; `\n` в кавычках остаётся буквальной обратной косой чертой, то есть строка одна. Получить такое значение можно только вызовом `targets.merge_local(name, dict)`. SPEC канал не называет — отклонение 1.
