## Пути обхода гейтов
- **О1. Запись DECLARED остаётся при отказе `approve`.** Новая сверка стоит
  «после сверки «Меняемое поведение»» (SPEC тр. 2). Буквально её можно
  поставить после записи `DECLARED_CHANGE_ACTION` (`fsm.py:1207–1214`). Тогда
  у SPEC артели с обоими разделами запись «объявлена смена поведения тестов»
  ляжет в журнал, а `approve` откажет по «Заменяемым тестам» (у артели раздел
  вне границы). `declared_changes` читает последнюю запись
  (`test_integrity.py:1102`). Если Оператор после этого уберёт «Меняемое
  поведение» и пройдёт `approve`, новой записи не будет: отзыва у DECLARED
  нет, и действовать останется запись отклонённого `approve`. SPEC стоит
  уточнить: новая сверка — до записи DECLARED (`fsm.py:1207`).
- **О2. `approve` не перепроверяет форму раздела.** SPEC тр. 2 сверяет на
  `approve` только «непустой раздел», без повторной проверки формы. Оператор
  может поправить SPEC на гейте после перехода `spec_writing -> spec_gate`.
  `_behavior_change_declaration` на этот случай форму перепроверяет
  (`fsm.py:1056–1058`). Без такого шага в журнал ляжет строка, которую
  `approved_replacements` разберёт неоднозначно или молча пропустит.
- **О3. Сверка замены — только на выходе из `tests_writing`.** После
  утверждения `amend-tests` может заменить тест критерия `AC-<n>` пометкой
  `// AC-<n>: manual`: трассируемость пройдёт, а сопоставление замены
  останется без теста планки. Сверку `approved_replacements` `amend-tests` не
  исполняет. Это вне ТЗ (правку делает Оператор, G3б-2 отдельно проверяет
  красноту), отклонением не поднимается — наблюдение Оператору.
- **О4. Слабая форма AC-17/AC-21** (А3, AC-21 выше): тест, проверяющий
  только «нет записи» без текста отказа, либо переписанный метод без
  существенного утверждения выполняют SPEC буквально.
