## Пути обхода гейтов
- AC-6 без названного пути. Разработчик может сделать запасной заголовок только в `open_forge_mr`, а в `gh pr create` подставлять пустой `{ref}` (`": <название>"`). Тест AC-6 через `forge.open_mr` при этом зелёный, AC-9 этого не видит: у задачи AC-9 ссылка есть (отклонение 1).
- Замечание, не отклонение: общий слой `targets.yaml` неизвестные поля не отвергает (`targets.check`, `targets.py:890-977`), а `_check_delivery` проходит только локальный слой (`merge_local`, `:517`). Значит, `mr_title_template` в общем слое попадёт в плоскую запись без проверки. Так устроены все поля доставки, и ТЗ это не затрагивает. Образец AC-9 (`tests/test_draft_mr_commits.py:31-40, 62`) пишет запись в общий слой. Тест AC-9, написанный по нему буквально, проверит сборку заголовка, но не загрузку из локального слоя. Её проверяют AC-3…AC-5, так что дыры нет.
