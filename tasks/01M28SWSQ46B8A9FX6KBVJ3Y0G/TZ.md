# ТЗ: `amend-tests` гоняет трассируемость критериев перед сдвигом лока планки

Источник: копилка 11.09 (строка «amend-tests не гоняет трассируемость AC»),
предложение ревьювера задачи 01M28NX43E. Обе ветки команды
(`orchestrator/amend.py::_cmd_amend_tests` — правка в worktree,
`_cmd_amend_tests_from_branch` — расхождение между `tests_locked_sha` и
головой артефактной ветки) сдвигают `tests_locked_sha`, не вызывая
`guard.acceptance_traceability_errors`: правка планки может снять тест
критерия или поставить пометку `# AC-n: manual` с отступом, и лок
сдвинется без отказа. Инцидент 11.09 (01M1THKWFX, AC-7: метод заменён
маркером с отступом через `amend-tests`, автогейт приёмки счёл критерий
автоматическим) прошёл именно этим путём. Гейт `tests_writing -> in_dev`
эту проверку делает; задача 01M28NX43E добавила в неё детекцию маркера с
отступом. `amend-tests` — второй вход в планку, проверка должна быть той же.

Требуется:
1. `_cmd_amend_tests` (worktree): после сверки «есть изменения и только в
   `acceptance_tests/`» и ДО коммита в артефактную ветку и сдвига лока
   вызывается `guard.acceptance_traceability_errors(tdir)` по правленной
   планке; непустой список — отказ `sys.exit` с текстом
   «[<id>] amend-tests: отказ — трассируемость AC нарушена: <ошибки guard
   через '; '>», лок и артефактная ветка не тронуты, в журнал — запись
   отказа тем же актором `operator`.
2. `_cmd_amend_tests_from_branch`: та же проверка по содержимому головы
   артефактной ветки (SPEC.md и `acceptance_tests/` с ветки, не с диска —
   приём: материализация снимка во временный каталог либо разбор
   содержимого функциями guard, которые принимают текст; выбор — в PLAN).
   Отказ — тот же текст; `tests_locked_sha` не сдвигается.
3. Проверка не ослабляет существующие: прогон планки (`acceptance.run`),
   маркеры «Красен до реализации» (`guard.scan_redness_markers`), сверка
   содержимого с артефактной веткой — остаются как были, порядок: сначала
   трассируемость, потом прогон.
4. Тесты `tests/test_amend_tests.py` (или существующий файл команды):
   (а) правка снимает единственный тест критерия без пометки — отказ с
   именем критерия, лок не сдвинут (мутация «проверка снята» — красная);
   (б) правка ставит пометку `# AC-n: manual` с отступом — отказ тем же
   путём, что у гейта (детекция из 01M28NX43E; тест зависит от её мержа в
   main); (в) корректная правка — лок сдвинут как раньше; (г) те же (а) и
   (в) для `--from-branch`; (д) существующие тесты `amend-tests` зелёные
   без правки утверждений.

Зоны: orchestrator/amend.py, tests/.
Порядок: после 01M28NX43E (детекция отступа в
`guard.acceptance_traceability_errors`); зоны с ней не пересекаются.

Не входит: изменение правил трассируемости guard; ретро-проверка уже
сдвинутых локов.
