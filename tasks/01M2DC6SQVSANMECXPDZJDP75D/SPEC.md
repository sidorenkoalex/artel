# SPEC: Рефакторинг R8: общая песочница тестов — базовые классы вместо копий setUp и подмножеств PATCHED_ATTRS

## Контекст

Источник: отчёт ревизии №6 `docs/audits/code-revision-2026-09-13.md`,
находка CR-2026-09-13-5 ★ и ТЗ-черновик Р-5; роадмап §3 фаза R, пункт R8.
Предусловия выполнены 13.09: фикс утечки тестов (01M2CN465WEDCF6D77V37FJ82E)
и Р-1…Р-4 смержены; тихое окно, параллельных задач нет.

`tests/sandbox.py` — 966 строк, 7 классов, `ALL_CONFIG_ATTRS` :62–65.
10 файлов `tests/*.py` задают собственное подмножество `PATCHED_ATTRS`
вместо наследования полного набора `TmpRootTest`. 270 методов `setUp`,
среди них 17–26 групп с побайтно одинаковыми телами (например,
`tests/test_agent_log.py:84` = `tests/test_step_cost.py:73` =
`tests/test_agent_failure.py:47`; `tests/test_mutation_claim_gate.py:24`
= `tests/test_protected_paths_gate.py:87`; группы `tests/test_invariants.py:439/733`
и `:635/1420` — защищённый путь, не трогаем). Помощники `event` и
`fake_git_config` побайтно совпадают между файлами; `result_event`
(×3 разных сигнатуры), `spec_text`, `assistant_event` — разные
сигнатуры, дублями не считаются.

Поведение тестов не меняется — задача снимает дублирование кода
песочницы, не меняет сценарии и ассерты.

## Требования

1. Побайтно идентичные тела `setUp` и побайтно идентичные тела
   вспомогательных функций (`event`, `fake_git_config` и прочие такие
   же группы) переносятся в общие базовые классы `tests/sandbox.py`;
   затронутые файлы `tests/*.py` переходят на наследование от этих
   базовых классов вместо копии тела.
2. Каждое сохранившееся подмножество `PATCHED_ATTRS` в `tests/*.py`
   несёт комментарий, объясняющий, почему полный набор
   `ALL_CONFIG_ATTRS` для этого класса избыточен; подмножества без
   такого обоснования расширяются до полного набора (наследование
   `TmpRootTest.PATCHED_ATTRS` без переопределения — не частичный
   список).
3. Ассерты и сценарии существующих тестов не меняются (допустимы
   только правки импортов, путей патчей и переход на наследование);
   полный набор `tests/` зелёный.
4. Полный прогон `tests/` из чистой копии не создаёт ни одного
   каталога в `.artel/worktrees` и оставляет `git status --porcelain`
   пустым — критерий фикса утечки (01M2CN465WEDCF6D77V37FJ82E)
   сохраняется этим рефакторингом, не ослабляется.
5. `PLAN.md` несёт таблицу переносов (откуда — файл/строка исходного
   `setUp`/помощника/`PATCHED_ATTRS` — куда — общий базовый класс или
   решение по подмножеству) и описывает откат: revert одного
   merge-коммита.
6. `tests/test_invariants.py` не редактируется в диффе кода ветки
   задачи; защищённые группы этого файла (`:439/733` и `:635/1420`)
   остаются нетронутыми.

## Критерии приёмки

AC-1. Байтово идентичные тела `setUp` и байтово идентичные тела
вспомогательных функций (`event`, `fake_git_config` и другие такие же
группы, кроме `tests/test_invariants.py`) заменены наследованием от
общих базовых классов `tests/sandbox.py`; ни один файл `tests/*.py`
(кроме `tests/test_invariants.py`) не содержит собственную копию тела,
байтово совпадающего с телом в другом файле или с телом нового
базового класса.

AC-2. Каждое сохранившееся подмножество `PATCHED_ATTRS` в `tests/*.py`
несёт комментарий, объясняющий, почему полный `ALL_CONFIG_ATTRS`
избыточен для этого класса; любое подмножество без такого комментария
расширено до полного набора (класс наследует `TmpRootTest.PATCHED_ATTRS`
без переопределения списком).

AC-3. Ассерты и сценарии существующих тестов не изменены (допустимы
только правки импортов, путей патчей и переход на наследование);
полный набор `tests/` зелёный.

AC-4. Полный прогон `tests/` из чистой копии (интерпретатор
`.artel/venv`) не создаёт ни одного каталога в `.artel/worktrees` и
оставляет `git status --porcelain` пустым.

AC-5. `PLAN.md` несёт таблицу переносов (файл/строка исходного
`setUp`/помощника/`PATCHED_ATTRS` → базовый класс `tests/sandbox.py`
или принятое решение по подмножеству) и описывает откат — revert
одного merge-коммита ветки задачи.

AC-6. Диф кода ветки задачи не содержит правок `tests/test_invariants.py`;
группы `setUp` `:439/733` и `:635/1420` этого файла не изменены.

## Не входит

- `tests/test_invariants.py` — защищённый путь, не правится (см. AC-6).
- Исторические `tasks/*/acceptance_tests/_sandbox.py` (93 файла в
  main) — вне задачи; уборка из main — очередь Оператора.
- `skills/test-authoring.md` — шаблон будущих планок, вне задачи.
- Дедупликация помощников с разными сигнатурами (`result_event` ×3,
  `spec_text`, `assistant_event`) — они не дубли, не трогаются.
- Любая правка ассертов, сценариев тестов или продового кода
  (`orchestrator/`, `scripts/`) — поведение не меняется.
