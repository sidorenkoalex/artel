паузы 90 с при пороге протухания `LEASE_STALE_AFTER_SEC` = 7200 с

фиксирует тест (`push_calls == sync_calls == 40`, 40 пауз). Путь

(снимается в `_publish_merge_artifacts`, :564 — проверено в итерации 1).

  этой задаче не нашёл SPEC/PLAN («в дереве — файл не найден»), а

  где REVIEW.md получил прошлый `status`, а не последний автокоммит.

  возврата» (`_push_merged_main` всё ещё называет `("wait", branch)`):
  при переименовании тега исхода стоит грепать старый тег по модулю, не
  только по месту правки. Адрес: `skills/` разработчика, приём
  «grep старого имени после переименования».
