## Пути обхода гейтов
1. Буквальное исполнение тр. 7-8 и AC-11/AC-12 — `tools` только в `decide`, тесты строят `Profile` через `decide` — даёт зелёную планку при том, что ключ автогейта приёмки (`_task_own_profile`, acceptance.py:2407) `tools` не содержит вовсе, а ключ базы гейта мержа и `suite-run` расходятся. Цель ТЗ п. 3 (не переиспользовать итог при смене инструментов) не достигается там, где ключ реально работает, кроме гейта мержа.
2. AC-3 проходим строковым префиксом вместо сравнения числовых частей (см. таблицу) — проверка `tools` выдаст ok на `3.1` при `3.12.0`.
3. AC-8 «неразбираемая строка» без определения: разработчик может делить по каждому `|` и объявить «неразбираемым» только пустое значение — тест на пример автора пройдёт или упадёт случайно.
