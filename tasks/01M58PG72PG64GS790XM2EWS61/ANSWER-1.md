5. **Вариант A, дополненный по живому файлу.** В sled (`.github/workflows/ci.yml:59-64`) обе переменные — ключи YAML внутри `env:`: `BACKEND_RE: '…'` (одинарные кавычки) и `FRONTEND_RE: >-` (свёрнутый блок, значение — одна строка на следующей строке с большим отступом). Поддержать: ключ YAML `KEY: значение` с кавычками и без; свёрнутый и буквальный блок (`>-`, `>`, `|-`, `|`) — строки с отступом больше ключа, по правилам YAML (у `>` строки склеиваются пробелом); значение блока из нескольких строк для регулярного выражения — `skip` с причиной «многострочное значение не сравнивается», а не догадка о склейке; присваивание оболочки `KEY=…` (допустимо `export`). Строки комментариев `#` пропускаются. Тесты — на копии формы sled (обе переменные), на многострочном блоке (skip) и на присваивании оболочки.
