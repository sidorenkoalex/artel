Решение Оператора по эскалации ревьювера (итерация 1).

Вопрос 1 (R1-F1) — строку раздела «Меняемое поведение» правит Оператор: команды пульта для правки SPEC после гейта нет, возврат в spec_writing из этого состояния невозможен. Оператор исправит строку в снимке tasks/01M45FJD46BX45VHC36S4VS9QN/SPEC.md на main сразу после мержа (до pin-update). Код и тесты задачи по R1-F1 не меняются; проверку формы раздела не ослаблять. Ревьюверу: R1-F1 закрыть как «принято Оператором, правка снимка после мержа», на вердикт не влияет.

Вопрос 2 (R1-F2) — вариант (а): чинить в этой задаче. Разработчик маскирует UnaryOp(USub/UAdd, Constant) как один литерал со знаковым значением (тем же приёмом, что equality() разворачивает унарный знак): `-2` → `-3` даёт фактическую пару (-2, -3); `1` → `-1` — смена ожидания на позиции равенства; строгость порядка оценивается по знаковому значению. Тесты с заявкой «Ловит мутацию» на эти три случая.
