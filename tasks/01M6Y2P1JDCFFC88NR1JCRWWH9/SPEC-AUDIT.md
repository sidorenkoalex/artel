## Пути обхода гейтов
- **О1. Обёртка фикстуры.** «Берёт» в смысле `_FixtureScope.requested`
  (`guard.py:2127-2153`) — только прямые имена. Своя фикстура уровня функции
  `def my(tmp_root): yield tmp_root` (или `def sb(): s = RealGitSandbox();
  s.setUp(); yield s`) и тест, берущий `my`, требованию 3 (`SPEC.md:55-68`)
  удовлетворяют буквально — вторая песочница в модуле с общей фикстурой есть,
  подмены `config` текут. То же — песочница, созданная прямо в теле теста
  вызовом класса `tests/sandbox.py`.
- **О2. Наследование не напрямую.** `class Base(RealGitSandbox)` передан в
  `shared_readonly` (исключение), `class Other(Base)` — «наследует класс
  `tests/sandbox.py`» только транзитивно; прямое/транзитивное не задано
  (`SPEC.md:63-64`). Обратное: «класс `tests/sandbox.py`» включает не-песочницы
  (`FakeProc`, `SpyRun`, `TimeWithSleep`, `SharedStateError`,
  `tests/sandbox.py:469-2299`) — наследник `FakeProc` получит отказ «других
  песочниц».
- **О3. Две общие фикстуры одного модуля.** `a = shared_readonly(RealGitSandbox, b1)`
  и `b = shared_readonly(OriginRealGitSandbox, b2)`: оба класса — первые
  аргументы, исключены; песочницы двух фикстур держат подмены весь модуль и
  накладываются друг на друга — ровно та утечка, которую закрывает требование 3.
- **О4. Нераспознанная форма вызова уходит из всех правил.** Распознаётся только
  `<имя> = shared_readonly(<класс>, <функция>)` уровня модуля (`SPEC.md:44-47`).
  `shared_readonly(Cls, build=build)`, присваивание в теле класса (pytest
  регистрирует фикстуру и там), `from tests import sandbox;
  sandbox.shared_readonly(…)`, `import tests.sandbox as s; s.shared_readonly`
  («псевдоним импорта» не уточняет — функции или модуля) — `scope=` нет,
  `build` не прослежен, требование 3 не включается. Нет правила «иной вызов
  `shared_readonly` — отказ».
- **О5 (наблюдение, вне ТЗ).** Файл с `pytestmark = pytest.mark.size("small")`
  и `seeded = shared_readonly(RealGitSandbox, build)` правила размера не
  ловят: `test_lint._small_findings` (`orchestrator/test_lint.py:445-475`)
  смотрит базовые классы и параметры `HEAVY_FIXTURES`, а `seeded` ни то, ни
  другое. ТЗ этого не просит — не отклонение, строка копилки.
