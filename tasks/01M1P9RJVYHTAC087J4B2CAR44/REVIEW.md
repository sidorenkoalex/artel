- blocker — `docs/codebase-map.md:2-6` — коммит `7d538ec1` («подтяжка origin/main… карта перегенерирована») на самом деле оставил в файле НЕРАЗРЕШЁННЫЕ конфликт-маркеры git (`<<<<<<< HEAD` / `=======` / `>>>>>>> origin/main`) прямо во frontmatter — YAML сломан (два ключа `built_at_sha` через маркеры), это подтверждено чтением файла на HEAD (не только в diff), рабочее дерево при этом чистое (`git status` пуст) — то есть это закоммиченное, а не случайное локальное состояние. `python3 scripts/codebase_map.py` без правок регенерирует файл корректно (только `built_at_sha` меняется, конфликт исчезает) — значит разрешение конфликта подтяжки не было доведено до конца перед коммитом (conventions-core: «регенерируй карту отдельным шагом сразу после разрешения конфликтов подтяжки» — здесь сами конфликты подтяжки не разрешены вовсе). CI-джоб `codebase-map` в `.github/workflows/ci.yml:109` эту поломку не ловит на этой ветке — он условен `if: github.ref == 'refs/heads/main'` и сработает только ПОСЛЕ мержа, то есть без этого замечания поломка ушла бы в `main`.
