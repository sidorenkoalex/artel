Отклонение 1 (AC-12). Граница «арифметики над её результатом» не определена для строковых операций. Нынешнее тело метода строит тексты из литералов:
- `:636–637` — `"    assert value == " + str(sent_other)`, это `BinOp(Add)` в `ast`;
- f-строки `source(...)` и `expectations`, `:590–600`, `:639–647`.

Буквальная `ast`-проверка «нет `BinOp` над результатом» краснит перенос этих строк в помощник как есть. Узкое чтение «новые числа не вычисляются» пропускает их. Смысл решения Оператора — запрет вычислять *значения* литералов мимо функции. Сборка *текстов* фикстуры из уже сгенерированных значений, видимо, разрешена, но SPEC этого не различает. Это не блокирует: решить может ревью, либо разработчик перепишет `:636–637` f-строкой — это не утверждение, учёт гейта не меняется.
