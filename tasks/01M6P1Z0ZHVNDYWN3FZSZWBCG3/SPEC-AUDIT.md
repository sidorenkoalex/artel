## Пути обхода гейтов
- Токены подмодулей в тексте помощника — закрыто AC-7 (`GIT_CONFIG_VALUE_*`,
  `GIT_TRACE`).
- Один общий помощник с `useHttpPath` для всех записей — закрыто литералом
  AC-2.
- Выбор по `.gitmodules` рабочей копии или по префиксу — закрыто AC-3.
- `doctor`, проверяющий подмодуль токеном проекта, — закрыто AC-5 (сверка
  пароля в окружении `ls-remote`).
- Остаётся незакрытой ветка «адрес подмодуля из поля — ssh на хосте
  записи» (п. 3 вердикта). По правилу `url_host` (`gitcmd.py:67–70`)
  scp-адрес `git@host:g/s.git` даёт хост `host` — «тот же хост». Поэтому:
  - требование 4 (SPEC.md:89–93) буквально требует отказа
    `_clone_submodules` при пустом слоте такого подмодуля, хотя ssh-запрос
    помощника не зовёт;
  - требование 5 (SPEC.md:98–114) не называет исход `doctor` для такого
    подмодуля (ни `fail` «другой хост», ни `http://`, ни прежний ssh-`warn`,
    :1390–1392). Исполнитель вправе пустить `ls-remote` по ssh и получить
    `fail`.

  ssh-адреса вынесены в «Не входит» (SPEC.md:284), но исход для них не задан.

## Вердикт
concerns. SPEC фактически верен, критерии проверяемы и безопасны в красной
фазе, зоны достаточны. Отклонения для решения Оператора на гейте:
1. SPEC.md:66–67 — сравнение имени хоста без учёта регистра не проверяется
   ни одним AC: мутация «с учётом регистра» не ловится, в `doctor` она даёт
   ложный `fail` «другой хост». Вариант решения: случай в AC-3 и AC-5 с
   адресом подмодуля, где имя хоста в другом регистре.
2. SPEC.md:153 — «argv равны литералам» в AC-2 не называет, argv каких
   вызовов сравнивается. Эталон `GIT_CONFIG_COUNT` зависит от
   унаследованного `GIT_CONFIG_COUNT` (`gitcmd.py:198–201`), и тест должен
   его снимать. Вариант решения: назвать подкоманды и потребовать чистый
   `GIT_CONFIG_COUNT` в окружении теста.
3. SPEC.md:89–93, :98–114, :284 — для подмодуля из поля с ssh (scp)
   адресом на хосте записи не задан исход:
   - требование 4 буквально даёт отказ клона при пустом слоте;
   - требование 5 не называет строку `doctor`.

   Вариант решения: такой адрес — как сегодня ssh: `warn` «ssh-адрес» в
   `doctor`, без отказа `_clone_submodules` и без чтения слота.
