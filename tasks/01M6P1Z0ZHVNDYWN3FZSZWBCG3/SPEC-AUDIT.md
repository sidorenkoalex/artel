## Вердикт
concerns — одно отклонение, решаемое Оператором на гейте:

1. Правило хоста с портом в `_clone_submodules` не закреплено тестом.
   Треб. 4 (SPEC.md:96-97) требует хост «по правилу требования 2» —
   `url_host` с портом (SPEC.md:64-67). AC-8 случай «адрес подмодуля на
   другом хосте — не отказ» не задаёт форму другого хоста; тест с другим
   именем хоста пропускает правдоподобную мутацию — `_clone_submodules`
   переиспользует `doctor` `_remote_kind` (`project_checks.py:1331-1342`,
   хост без порта): подмодуль из поля на том же имени, другом порту, с
   пустым слотом даст отказ клона вместо «не отказ». Аналогично AC-3
   случай другого порта (SPEC.md:200-202) проверяет только ответ помощника,
   не «слот не читается» (SPEC.md:61-62) — проверка `keychain.token` есть
   лишь для случая другого имени хоста (SPEC.md:211-214). Предложение: в
   AC-8 случай «другой хост» — двумя вариантами (другое имя; то же имя,
   другой порт), в AC-3 для случая другого порта — `keychain.token` для
   слота не вызывается. Дефолт при молчании: принять как есть (утечки нет —
   помощник фильтрует по `host` с портом; ущерб — лишний отказ клона и
   лишнее чтение слота).

Наблюдение (не отклонение): `yamlmini` сохраняет кавычки ключа
(`"vendor/x.y"` читается как `'"vendor/x.y"'`), так что путь в кавычках в
поле не совпадёт с путём `.gitmodules`; ТЗ этого не касается — разработчику
стоит знать, писать пути без кавычек.
