## Проверяемость критериев

| Критерий | Проверяем | Ловимая мутация |
|---|---|---|
| AC-1 | да | проверка поля не добавлена (пустой путь/слот загружается); поле принимается в слое репозитория; `_flatten` не переносит поле. Красная фаза: загрузка отказывает «неизвестное поле» — запись с полем не загружается, тест красный, безопасно |
| AC-2 | да | помощник/порядок `GIT_CONFIG_*` для записи без поля изменён; `useHttpPath` ставится всегда; у записи с полем нет `useHttpPath` в одной из шести подкоманд; `hosting_token` читает слоты. Эталон — литералы в тесте, унаследованные `GIT_CONFIG_*` сняты. Красная фаза: часть «без поля» зелёная (так и задумано), часть «с полем» красная |
| AC-3 | да | выдача по префиксу (`-other`); по хосту без пути (подмодуль получает пароль проекта); сравнение хоста без порта (`_remote_kind`) — слот читается для другого порта; сравнение с учётом регистра; `.gitmodules` рабочей копии вместо клона; относительный адрес не разрешён. | AC-4 | да | `_clone_submodules` без правила требования 2 — сервер отвечает 401, клон не заводится. Красная фаза: отказ git при `GIT_TERMINAL_PROMPT=0`, предел 60 с, сервер в `finally` |
| AC-5 | да | проба подмодуля токеном проекта; пропуск строки при `merge_gate: operator` с полем; ранний `ok` без `.gitmodules`/без адресов; `fail` вместо `warn` для `http://`/ssh; `warn` вместо `fail` для другого порта/пустого слота; регистр хоста |
