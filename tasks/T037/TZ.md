# ТЗ: Общая тестовая песочница и ревизия мокинга subprocess

Общая тестовая песочница + ревизия мокинга subprocess (ревизия CR-2026-08-26-3 + строка беклога P3 «Ревизия мокинга subprocess в тестах», решение Оператора 25.08 по эскалации T022).

Проблема, часть 1 (песочницы): класс TmpRootTest скопирован в 9 тестовых файлов (test_acceptance_tests_flow, test_agent_failure, test_agent_log, test_analyst_role, test_doctor, test_git_fixation, test_multitarget, test_multitarget_invariants, test_step_cost), хелпер capture — 24 определения в 17 файлах, fake_git — 14. Каждая копия патчит СВОЁ подмножество путей config (одни — только DB/TASKS/LOGS/ROLE_*, другие — ещё ROOT/PROJECTS/TARGETS/BACKUP_MARKER): непропатченный путь в очередной копии — тихая утечка теста на реальное дерево пульта.

Проблема, часть 2 (subprocess): тесты 8+ модулей мокают runner.subprocess.Popen с точными счётчиками вместо функций-обёрток — любой новый системный вызов в пути шага ломает десятки чужих тестов (прецеденты: keychain-hotfix, git-идентичность, 76 тестов при сверке пина CLI, стабы pre-flight). Целевой образец — gitcmd.git / keychain.token: обёртка cli-вызова агента, тесты мокают её. После ревизии — вернуть сверку пина CLI в pre-flight (сужение требования 5 T022).

Что сделать: (а) вынести песочницу в общий модуль tests/sandbox.py — TmpRootTest с параметризуемым, по умолчанию ПОЛНЫМ набором патчируемых путей config (чтобы непропатченный путь не мог утечь), общие capture и fake_git; тестовые файлы переходят на импорт; (б) завести обёртку cli-вызова агента по образцу gitcmd.git и перевести тесты с мокинга runner.subprocess.Popen на мокинг обёртки; (в) вернуть сверку пина CLI в pre-flight.

Это задача класса «рефакторинг» (правила T015): поведение не меняется — зелёность существующих тестов и неизменность их сценариев и ассертов есть определение неизменности; допустимые правки в тестах — только импорты и пути патчей, ревьювер сверяет по диффу. PLAN обязан содержать таблицу переносов по файлам; откат — revert одного merge. Смоук до/после: полный прогон python3 -m unittest discover -s tests с фиксацией сравнения («596 == 596, все зелёные»; число актуализировать на момент исполнения). Никаких попутных улучшений; дедупликация — только идентичных/почти идентичных кусков песочницы.

Критерии приёмки (ориентир): (1) TmpRootTest/capture/fake_git определены в одном модуле tests/sandbox.py, в тестовых файлах — только импорт/наследование; (2) набор патчей по умолчанию покрывает все пути config, используемые песочницами сегодня (DB, TASKS, LOGS, ROOT, PROJECTS, TARGETS, ROLE_HOME, ROLE_CONFIG_DIR, BACKUP_MARKER); (3) прямого мокинга runner.subprocess.Popen в тестах не остаётся — мокается обёртка; (4) сверка пина CLI возвращена в pre-flight; (5) полный прогон тестов зелёный, число тестов не уменьшилось; (6) в диффе тестов нет изменённых ассертов и сценариев (только импорты и пути патчей).
