Не подтвердилось / неполно:
1. **«Не уложился» — только про прогон ветки.** Заголовок «прогон не
   уложился в предел» — `orchestrator/suite_run.py:513-516`, по
   `parsed.outcome` прогона ветки. Таймаут прогона базы даёт пояснение
   «прогон базы … не завершён (таймаут прогона)» (`:626-628`), а оно
   печатается только при упавших на ветке (`:532-535`). В ac24 у исходов
   «зелёная» и «красная» задача без коммитов — база гоняет тот же набор,
   что ветка, тем же пределом `limit` (`:620-623`); у «зелёная» упавших
   нет, и таймаут базы в отчёте не виден вовсе. Значит AC-7 («нет „не
   уложился“») не ловит именно тот случай, ради которого усиление
   разрешено: копия базы убрана по ветви таймаута, а не по ветви
   зелёного/красного исхода, — и тест зелёный.
2. Требование 7 / AC-8 для ac21: «журналы обёртки и `conftest.py`
   пусты». В ac21 прогон задачи A намеренно жив (`:1259-1260`), запись
   обёртки A и запись `conftest.py` A уже есть; прежнее утверждение ac21 —
   `branch_calls(wt_b) == []` (`:1267`), не пустота журналов. Скобка «как в
   прежнем утверждении» с буквой «пусты» расходится; буквальный тест ac21
   красен на верном коде.

## Пути обхода гейтов
1. AC-7 буквально: добавить `report()` и `assertNotIn("не уложился", out)`
   для трёх исходов — условие матрицы «усиление ac24 внесено» выполнено,

   «зелёная»/«красная» в «предел» (п. 1 «Фактов»).
2. AC-8, ac21: test_author, видя неисполнимое «журналы пусты», ослабит
   проверку по своему вкусу (например, только `ps` без журналов) — без
   решения Оператора.
3. AC-8, порядок: журналы до `ps` формально удовлетворяют критерию и
   оставляют окно для мутаций с прямым порождением обёртки.
