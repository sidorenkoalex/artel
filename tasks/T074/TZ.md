# ТЗ: pause --now: жёсткая пауза + чекпоинт аварийного шага

# ТЗ: pause --now — жёсткая приостановка + чекпоинт аварийного шага

## Контекст

T070 дала грейсфул-паузу: пометка в БД, бегущий шаг дорабатывает,
следующий не начинается. Жёсткий вариант — прерывание бегущего шага —
сознательно вынесен из T070 в отдельную задачу (SPEC T070 «Не входит»)
как свёртка с P3-строкой «чекпоинт при rc-обрыве» (эвристики ошибок
агента). Фактура необходимости: 29–30.08 остановка живых циклов
делалась убийством процессов руками — два инцидента целостности
«грязная копия артефактов» на рестарте (T070, T072), WIP спасался
ручными чекпоинт-коммитами Оператора. Механика чекпоинта уже есть:
T041 (WIP-чекпоинт на таймауте шага) + T059 (worktree-осведомлённость,
add только пути задачи) — но включается она сегодня ТОЛЬКО на таймауте.

## Что нужно

1. `pause --now <id>`: ставит обычную пометку паузы И прерывает
   текущий агентный шаг задачи, если он бежит: процесс агента
   корректно завершается; незакоммиченный WIP worktree задачи
   чекпоинтится служебным коммитом с пометкой причины «pause --now»
   (механика T041/T059: actor orchestrator, add только пути worktree
   задачи); lease держателя освобождается; журнал полный.
2. Кросс-сессионность: шаг может бежать в другом процессе (фоновый
   auto той же машины) — адресация через данные lease (pid, host).
   Если lease нет или процесс уже мёртв — честное сообщение и
   деградация до обычного pause (не ошибка). Прерывание процессов
   на другом host — вне объёма, честный отказ с текстом.
3. Чекпоинт аварийного шага (свёртка): правило T041 расширяется —
   чекпоинт WIP выполняется не только при таймауте, но и при
   аварийном завершении шага (rc != 0, обрыв потока), если дерево
   worktree грязное; пометка причины в коммите и журнале.
   Диагностическая ценность сохраняется в самом чекпоинт-коммите.
4. Стоимость прерванного шага — по существующей механике T040
   (частичные суммы промежуточных событий; отсутствие данных →
   алерт spend.unknown_cost). Прерванный Оператором шаг не считается
   провалом роли (счётчики отказов/итераций не инкрементятся).
5. Возобновление: `resume <id>` + `auto <id>` — шаг перезапускается
   заново, стартуя от чекпоинта в worktree (как после таймаута T041).
   Инцидент целостности «грязная копия» после pause --now возникать
   не должен — чекпоинт закрывает дерево до выхода команды.
6. Если агентный шаг не бежит — `pause --now` деградирует до обычного
   `pause` с сообщением об этом.

## Границы

- Панельная кнопка — вне объёма (этап 2 панели).
- Прерывание процессов другого host — вне объёма.
- Ослабление таймаут-механики T041, лимитов и инвариантов — запрещено;
  изменения аддитивные (принцип целостности).
- Обычный `pause`/`resume` (T070) не меняются в наблюдаемом поведении.

## Критерии приёмки (ориентир для SPEC)

- `pause --now` бегущего шага: процесс агента завершён, WIP
  зачекпоинчен в ветку задачи с причиной, lease снят, пометка паузы
  стоит, журнал содержит все действия; последующий auto честно стоит
  на паузе, а после resume+auto перезапускает шаг от чекпоинта без
  инцидента целостности.
- Аварийное завершение шага (rc != 0) с грязным деревом порождает
  чекпоинт с причиной (расширение T041) — покрыто тестом.
- `pause --now` без бегущего шага = обычный pause с сообщением.
- Прерванный шаг не инкрементит счётчики провалов роли; стоимость
  учтена по T040 либо открыт spend.unknown_cost.
- Полный тестовый набор зелёный; тесты — в общей песочнице.
