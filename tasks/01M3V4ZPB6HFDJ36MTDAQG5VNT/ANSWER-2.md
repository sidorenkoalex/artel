# ANSWER-2: ответ Оператора

## Ответы

Уточнение Оператора: доступна только существующая подписка ChatGPT; канарейка должна автоматически работать через неё.

Обязательные ограничения: не использовать API-ключи, отдельный API-биллинг или предполагать наличие Enterprise/workspace/IdP. Не требовать интерактивного login для каждого прогона. Первоначальную настройку входа рассматривать отдельно; фактический login требует участия Оператора. После неё штатные прогоны должны использовать подписочный вход автоматически, а при его истечении выдавать понятную диагностику, не обходить авторизацию.

Для исследования приоритетен выделенный постоянный CODEX_HOME только для канарейки с самостоятельным подписочным входом. Это кандидат, а не утверждённая реализация: проверить установленный CLI, стабильность привязки Keychain, обновление входа, восстановление курируемых настроек проверяемого SHA, отсутствие переноса истории/доверия между прогонами, эксклюзивный доступ и очистку. Кодовые клоны остаются временными, боевой профиль не используется и не меняется. Пульт не извлекает и не копирует токены. Для параллелизма можно оценить пул выделенных профилей, но не добавлять его без необходимости.

Сохраняется мандат ANSWER-1: исследование документации, кода и синтетических данных; без чтения реальных токенов, изменения Keychain и запуска login/logout. API/access-token/WIF решения не предлагать как основной путь без подтверждённой доступности в имеющейся подписке. Данное уточнение не разрешает реализацию, изменение инвариантов или прохождение гейта SPEC.
