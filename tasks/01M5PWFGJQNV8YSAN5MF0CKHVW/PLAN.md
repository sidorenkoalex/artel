# PLAN: `mutation-run` — `--wait-lock`, `--copy-table`, `--workers`

## Подход
Вся механика — в `orchestrator/mutation_run.py`; в `orchestrator/artel.py` —
только строка блока «Команды:» и комментарий к `_ROLE_ALLOWED_COMMANDS`.

- Разбор: `_parse_args` получает флаги со значением `--wait-lock`,
  `--workers` и флаг без значения `--copy-table`. Проверки значений —
  `_lock_minutes` (целое `int(строка)` 0…`SUITE_RUN_MAX_WAIT_MIN`, сумма с
  `--wait` не больше предела) и `_workers` (`int(строка)` 1…`os.cpu_count() or 1`,
  ANSWER-2 п. 2–3) до любых файлов прогона. Режим только отчёта с любым из
  трёх флагов — отказ с указанием формата.
- Ожидание замка — своё (`_acquire_lock`), не `suite_lock.wait_acquire`
  (опрос 1 с, SPEC «Материалы»): первая попытка `suite_lock.acquire`;
  занят и `--wait-lock 0` — прежний отказ прежним текстом; иначе строка
  о начале ожидания с `suite_lock.describe(holder)` и цикл «сон 10 с →
  `acquire`» до срока `monotonic() + N·60`. Проигранная гонка за
  освободившийся замок — просто следующая итерация (требование 3). Срок
  кратен 10 с, поэтому отказ приходит ровно в N·60 с. До взятия замка
  ничего не создаётся (`_new_log` — после), `KeyboardInterrupt` из сна
  уходит наружу без перехвата — замок не взят, файлов нет.
- `--workers n`: фоновому процессу передаётся аргументом; `_Run.suite`
  добавляет `-n <n>` в конец `extra` (последнее значение `-n` берёт верх);
  без флага `-n` не добавляется. Шапка таблицы — строка
  `# рабочих процессов: <n>` (значение флага либо `config.FULL_SUITE_WORKERS`).
- `--copy-table`: фоновый процесс получает путь копии
  `artifact_branch.docs_dir(id, target)/mutation-run-<n>.tsv`; `_Run`
  после шапки и после каждой строки перезаписывает копию байтами основной
  таблицы прямым `write_bytes` (без временного файла и `os.replace`),
  только если каталог документов есть; сбой записи копии прогон не роняет.
  Признак `copy_table` сохраняется в `mutation-run.json`; отчёт `_wait`
  перед каждой печатью таблицы обновляет копию (если каталог и основная
  таблица есть) и печатает путь копии либо одну строку «копии нет».

Бюджет SPEC ($45) не пересматривается.

## Влияние на систему
Замок машины, исходы мутаций и пределы не меняются: ожидание лишь
повторяет прежний `suite_lock.acquire`, без флага поведение прежнее
(AC-7). Каталог документов задачи меняется только с `--copy-table` и
только файлом `mutation-run-<n>.tsv`, который guard не считает
посторонним; ссылка документов, ветка и рабочая копия не трогаются.
Основная таблица получает одну строку шапки `#` — существующие тесты
читают шапку подстроками. Откат — revert merge-коммита.

## Риски
Копия может отставать от основной таблицы на строку, пока прогон идёт
(допущено SPEC, требование 12).
