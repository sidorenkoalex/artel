## Требования

1. `--wait-lock <минуты>` (целое от 0 до `config.SUITE_RUN_MAX_WAIT_MIN`; по умолчанию 0 — прежнее поведение): при занятом замке команда ждёт его освобождения не дольше заданного, проверяя не чаще раза в 10 с, и печатает одну строку о начале ожидания с держателем; замок освободился — прогон стартует как обычно; срок вышел — прежний отказ с держателем и словами «ожидание N мин истекло». Ожидание не берёт замок и не создаёт файлов прогона; прерывание (SIGINT, SIGTERM) — выход без прогона и без файлов. Неверное значение — отказ без запуска с форматом.
2. Копия таблицы: после каждой записанной строки таблицы (и после шапки) команда обновляет файл `mutation-run-<n>.tsv` первого уровня каталога документов задачи на диске (`artifact_branch.docs_dir(id, target)`) — побайтно равный основной таблице на этот момент, в том числе у оборванного по пределу прогона. Нет каталога на диске — копия не пишется, отчёт `--wait` говорит об этом одной строкой; прогон не падает. Ссылка `refs/artifacts/<id>`, ветка и рабочая копия командой не меняются.
3. Отчёт `--wait` (и повторный вызов после конца) дополнительно печатает путь копии.
4. Разбор аргументов, исходы мутаций, основная таблица, замок и пределы не меняются; guard не меняется.
5. Тесты (новый файл в `tests/`, в стиле pytest — ADR-0027; у каждой функции — «Ловит мутацию:»; без ожидания по часам — время и сон подменяются, фоновая часть вызывается в процессе теста): (а) замок занят и освобождается до срока — прогон стартует, строка ожидания напечатана; (б) замок занят весь срок — отказ с держателем и «ожидание … истекло», файлов прогона нет; (в) `--wait-lock` без значения, отрицательное, больше предела — отказ без запуска; (г) без `--wait-lock` при занятом замке — прежний отказ сразу (текст прежний); (д) после прогона в каталоге документов есть `mutation-run-<n>.tsv`, побайтно равный основной таблице; (е) обрыв по пределу — копия содержит строки до обрыва; (ж) нет каталога документов — копии нет, отчёт говорит об этом, прогон не падает; (з) отчёт `--wait` печатает путь копии; (и) `guard.is_extraneous_task_root_file("mutation-run-3.tsv")` ложно.
6. Существующие тесты не правятся и остаются зелёными. Строка «Команды:» докстринга `orchestrator/artel.py` и справка команды (`USAGE` модуля) называют `--wait-lock`.
