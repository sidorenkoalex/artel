# ТЗ: автопамять инструмента отключена у ролей курируемого слоя

Источник: копилка 05.09 (docs/backlog.md, приоритет 1), решение Оператора
05.09 по команде «запускать задачи первого приоритета».

Фактура. Роли тратят конец шага на записи в личную автопамять CLI
(`$CLAUDE_CONFIG_DIR/projects/<проект>/memory/`, у ролей —
`.artel/home/.claude/projects/-Users-al-sidorenko-projects-artel/memory/`,
сейчас 196 КБ, десятки файлов `feedback_*.md`): test_author задачи B2
(01M1R5B33C…) упёрся в таймаут 45 мин на этом, 124 млн токенов. Память
ролям не нужна по построению: всё, что должно пережить шаг, лежит в
артефактах задачи, скилах и референсе слоя ролей (ADR-0005: память
проекта — репозиторий, не инструмент). Правило текстом «память после
сдачи артефакта не пишется» — не держится (класс «правило скилов текстом»,
третий случай за неделю).

Документация CLI: автопамять отключается настройкой `autoMemoryEnabled:
false` в `settings.json` каталога конфигурации (у ролей —
`$CLAUDE_CONFIG_DIR/settings.json`) либо переменной окружения
`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`.

Требуется:
1. В референсе слоя ролей `docs/reference/role-home/claude/settings.json`
   — `"autoMemoryEnabled": false`. Это единственный обязательный канал:
   он не зависит от белого списка переменных окружения роли.
2. Тест (`tests/`): референс settings.json содержит ключ со значением
   `false`; проверка doctor референса role-home сравнивает деплой и
   референс по этому файлу (уже есть — не ослаблять).
3. Существующие файлы памяти в `.artel/home/.claude/projects/*/memory/`
   не удалять (сохранность данных, ADR-0005); что с ними делать — заметка
   в RETRO (кандидат: прочитать на ревизии как материал К2, затем
   `prune`).
4. Раскатка в `.artel/home/.claude/settings.json` — операторское действие
   после мержа (деплой при холодном старте); назвать в RETRO.

Зоны: docs/reference/role-home/claude/settings.json, tests/.

Не входит: переменная окружения через runner (зона runner.py занята
задачей путей брифа 01M1RQ12JV…; при желании — отдельной строкой позже),
правка скилов, чистка накопленной памяти.

Рамка: $8.
