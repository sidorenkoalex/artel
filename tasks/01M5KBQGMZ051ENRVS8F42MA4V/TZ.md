## Требуется

1. Промпты: `_log_candidates` отбирает файлы верхнего уровня каталога логов пульта с окончанием `.log` или `.prompt.txt` по прежнему двойному правилу (старше `config.LOG_RETENTION_DAYS` по mtime И задача вне `_kept_task_ids`). Прочие файлы верхнего уровня (`*-state.db*` и т. п.) не отбираются.
2. Каталоги `suite-run`: новая функция `prune._suite_run_candidates(conn) -> list[Path]` — подкаталоги `.artel/logs/suite-run/`, у которых одновременно:
   - `idgen.is_task_id_form(<имя>)` истинно (форма id задачи пульта или исторический `Tnnn`); подкаталог с любым другим именем (`pending-journal`, `tmp-x` и т. п.) не отбирается при любом возрасте;
   - задача вне `_kept_task_ids(conn)` (как у логов: задача, которой нет в БД, — вне множества);
   - самый свежий mtime среди всех файлов внутри (рекурсивно; пустой каталог — mtime самого каталога) старше `config.LOG_RETENTION_DAYS`;
   - замок `suite_lock.holder()` не за этой задачей;
   - в `<id>/run.json` нет живого `pid` — признак тот же, что в `orchestrator/doctor/orphans.py:61`: `pid` читается как целое из `run.json`, `pid` > 0 и `liveness._pid_alive(pid)` истинно — каталог не отбирается; нет `run.json`, он нечитаем или `pid` не целое — признака живого прогона нет.
   Файл `lock.json` и каталог `pending-journal/` не отбираются никогда. Удаление — каталог целиком, без перехода по символическим ссылкам: подкаталог-ссылка не отбирается.
3. `.artel/notes-work`: новая функция `prune._abolished_candidates() -> list[Path]` — каталоги упразднённых механизмов из константы `prune.ABOLISHED_DIRS = (".artel/notes-work",)` (пути относительно корня пульта), если такой путь существует и это каталог, а не ссылка. Условия давности нет. Удаление — каталог целиком и только если в нём нет несохранённой работы: вывод `git status --porcelain` в этом каталоге пуст и нет коммитов вне `origin` (вывод `git log --branches --not --remotes --oneline` пуст); оба вызова — локальные, без сети, через `gitcmd.in_repo`. Иначе — каталог не удаляется, строка отчёта `  каталог упразднённого механизма <путь> оставлено: <причина>` (причина — «незакоммиченные правки», «коммиты вне origin» или «git не ответил: <ошибка>»); в план удаления такой каталог не входит.
4. `cmd_prune`: план и исполнение считаются одним расчётом (как сейчас). Отчёт `_print_report` добавляет строки `  лог <имя>.prompt.txt будет удалён | удалён` (для промптов — та же форма, что у строк логов), `  каталог suite-run <имя> (<N> файлов) будет удалён | удалён` и `  каталог упразднённого механизма <путь относительно корня пульта> (<N> файлов) будет удалён | удалён`; ошибка удаления — строка «… не удалён: <ошибка>», остальное продолжается. «нечего убирать» — только когда пусты все виды и нет строк «оставлено». Существующие строки отчёта (логи, диагностика канарейки, alerts) — прежние побайтно.
5. Прежние виды (логи `*.log`, диагностика `.artel/canary/`, архивация alerts) работают как прежде; уборка `kill`/`done` логи и хозяйство `suite-run` не трогает (инвариант 16 не меняется).
6. `docs/retention.md`: в раздел `.artel/logs/` — промпты `*.prompt.txt` и каталоги `.artel/logs/suite-run/<id>/` по тому же двойному правилу (давность — по самому свежему файлу каталога; `lock.json`, `pending-journal/` и каталог задачи, держащей замок, не убираются); новый раздел «Каталоги упразднённых механизмов» (`.artel/notes-work` — целиком, `prune --execute`, без условия давности); новый раздел «Сессии ролей (`.artel/home/.claude/projects`)» — объём и темп роста, политики хранения пока нет, `prune` их не трогает, уборка — отдельная строка бэклога.
7. Тесты, детерминированные, без сети (песочница корня пульта — `tests/sandbox.py`, образец — `tests/test_prune.py`; mtime ставится `os.utime`):
   - старый промпт задачи вне последних 20 закрытых — в плане и удалён `--execute`; свежий промпт и промпт задачи из последних 20 — нет (на текущем коде — красный: промпт не отбирается);
   - старый каталог `suite-run/<id>/` закрытой задачи вне 20 — удалён целиком; каталог, где хоть один файл свежий, — нет; каталог задачи, держащей замок (`lock.json` с её id), — нет; старый каталог с `run.json`, где `pid` живого процесса (подмена `liveness._pid_alive` или `os.getpid()`), — нет; `pending-journal/` и `lock.json` — целы при любом возрасте; старый подкаталог `tmp-x` — не отбирается; подкаталог-ссылка — не отбирается;
   - строка отчёта для старого промпта — `  лог <имя>.prompt.txt будет удалён` в сухом прогоне и `… удалён` при `--execute`;
   - сухой прогон: ни один файл не удалён, план называет каталоги;
   - `.artel/notes-work` — репозиторий git с чистым рабочим деревом и без коммитов вне `origin`: в плане сухого прогона, после `--execute` каталога нет; повторный `--execute` — «нечего убирать» (если других видов нет);
   - `.artel/notes-work` с незакоммиченной правкой и отдельно — с коммитом, которого нет в `origin`: строка «оставлено: <причина>», после `--execute` каталог и его содержимое целы;
   - существующие тесты `tests/test_prune.py`, в том числе «нечего убирать» на пустой песочнице, — без правки зелёные.
   Существующие тесты не правятся и остаются зелёными.
