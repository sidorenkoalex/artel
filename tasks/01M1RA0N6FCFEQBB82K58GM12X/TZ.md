# ТЗ: гейт ёмкости diff не считает артефакты задачи в кодовой ветке

Источник: наблюдение 05.09 (копилка роадмапа §4 п.8а). Гейт ёмкости
на переходе `in_dev -> review` (`fsm_advance._capacity_gate_refuses`)
меряет `git diff main...HEAD` целиком, включая копию `tasks/<id>/`
(SPEC, PLAN, залоченная планка) в кодовой ветке. У канарейки ч.1
планка дала 175 КБ при коде 101–114 КБ: дифф 276–289 КБ при потолке
262 144 байт, переход дважды проводился мостом Оператора. Планка не
предмет ревью-диффа: ревьювер получает артефакты отдельными
компонентами пакета из артефактной ветки.

Требуется:
1. Мера гейта ёмкости исключает `tasks/<id>/` (артефакты и
   `acceptance_tests/`) из диффа: `git diff main...HEAD -- . ':!tasks/'`
   либо эквивалент через существующий `review.git_diff_part`; порог
   `REVIEW_SNAPSHOT_DIFF_MAX_BYTES` не меняется.
2. Инкрементальный дифф ревью-пакета (`review.git_diff_part`,
   регрессия №10) тем же правилом не несёт `tasks/<id>/` — артефакты
   идут в пакет своими компонентами, дубль в диффе только раздувает
   контекст.
3. Отказ гейта называет две цифры: размер кода и размер исключённых
   артефактов, чтобы Оператор видел, что именно превысило потолок.
4. Тесты: ветка с кодом ниже потолка и планкой, уводящей общий дифф
   выше, — проходит; ветка с кодом выше потолка — отказ как сейчас;
   в диффе ревью-пакета нет строк из `tasks/<id>/`; существующие
   тесты гейта ёмкости и ревью-пакета (01M1GCN1FP, T029, №10) зелёные
   без ослабления.

Зоны: orchestrator/fsm_advance.py, orchestrator/review.py, tests/.
Пересечение с B2 ТЗ-1 (fsm_advance, review) и «auto переход до роли»
(fsm_advance): обе на стадии планки, код этой задачи короткий — идёт
первым, они подтягиваются. Не входит: смена потолка; исключение иных
путей.

Рамка: $10.
