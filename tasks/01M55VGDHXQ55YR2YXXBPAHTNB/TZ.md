# Гейт зон признаёт долгоживущие файлы задачи внешнего проекта по профилю

## Факты

Строка бэклога 17.10 (аудит SPEC 01M551W0TFCT2XRQ71XFXJDKB9, Ф-3). Гейт зон (`orchestrator/advance_gates/zones.py:274-276`) добавляет к заявленным зонам задачи общие зоны `config.COMMON_ZONES` только у артели (`repo_context.is_artel`); у артели в них входит `tests/`, и долгоживущий файл задачи `tests/test_<id>_<имя>.py` всегда в зоне. У внешнего проекта общих зон нет: долгоживущий файл задачи в `long_lived_dir` профиля (у sled `backend/tests/test_<id>_<имя>.py`) — «вне заявленных zones», если каталог не вписан в зоны задачи. Сегодня это обходится правилом «зоны задачи внешнего проекта включают `long_lived_dir`» (ТЗ первой задачи sled 01M55SKHZ293CCAK0N7T4H7ZMR вписывает `backend/tests/` целиком), что шире нужного: роль разработчика получает зону на все тесты проекта.

Чекпоинт test_author после 01M551W0TFCT2XRQ71XFXJDKB9 уже считает своими долгоживущие файлы задачи по каталогу и шаблону профиля (`project_profile.Profile.is_long_lived`, `long_lived_prefix`).

## Требуется

1. Гейт зон у задачи внешнего проекта признаёт зоной собственные долгоживущие файлы задачи — пути, для которых `Profile.is_long_lived(task_id, path)` истинно (каталог `long_lived_dir` и шаблон `long_lived_name` с id задачи), — тем же источником профиля, что гейт выхода из `tests_writing`. Прочие пути `long_lived_dir` в зону не входят. `config.COMMON_ZONES` не меняется.
2. Отказ определения профиля — гейт зон не расширяет зону (сегодняшнее поведение), текст отказа называет причину профиля; у внешнего проекта без `test_profile` — расширения нет.
3. У артели поведение гейта зон и тексты отказов не меняются; зафиксировать тестами до правки.
4. Аналитик сверяет по коду другие места, где зоны задачи сверяются с диффом (чекпоинт `_stray_staged_paths`, гейт мержа, ревью-пакет), и перечисляет в SPEC, нужна ли там та же правка; вне зон — эскалация до SPEC.
5. Тесты детерминированы, без сети: учебный внешний проект с `long_lived_dir: backend/tests`, задача с зонами `backend/src/` — дифф с `backend/tests/test_<id>_x.py` проходит гейт зон, дифф с `backend/tests/test_other.py` — отказ.

Критерии приёмки:
- у артели гейт зон прежний;
- у учебного внешнего проекта свой долгоживущий файл задачи проходит гейт зон без зоны `backend/tests/`, чужой файл каталога — отказ;
- после мержа ТЗ задач sled могут не вписывать `long_lived_dir` в зоны.

Зоны: `orchestrator/advance_gates/zones.py`, `tests/`.
