## Подход
Причина возврата (инцидент целостности 77d5a1d3 -> fd8a6e68) — коммит
ANSWER-2 Оператора в `refs/artifacts/<id>`. Шаг выполняет SPEC с
уточнениями ANSWER-2.

- `orchestrator/pin.py`: новая `_prune_origin_refs()` — последний вызов
  `cmd_pin_update`, после записи «pin обновлён» и `_report_stale_cycles`,
  то есть после успешного `merge --ff-only` (ANSWER-2 п.2). Число N —
  разница перечней `for-each-ref refs/remotes/origin/` до и после `git
  remote prune origin` (п.3). Сбой: `None` или ненулевой код (п.6) —
  строка «уборка ссылок origin не выполнена: <причина>», без `sys.exit`.
  Перечень до уборки не получен — уборка не запускается (без него N не
  посчитать), строка предупреждения с причиной.
- `orchestrator/prune.py`: вид «бесхозные каталоги .artel/worktrees».
  `_worktree_dir_candidates` — отбор по типу (каталог, не ссылка) и имени
  (не id незакрытой задачи; закрытые не защищены, п.5); при пустом отборе
  git не вызывается. `_worktree_list(repo)` — свой разбор `git worktree
  list --porcelain`, отличающий «не получен» (`None`) от пустого
  (`workspace.registered_paths` их не различает и не правится). Перечни
  главной копии (`config.ROOT`) и клона артели (`workspace.repo`), любой
  не получен — вид пропущен строкой «пропущено». Незарегистрированный
  каталог с `.git` (файл или каталог) — оставлен строкой «оставлен — есть
  .git» (п.4); остальные — к удалению существующим `_remove_dirs`
  (строка сбоя — прежний формат «… не удалён: <причина>», п.1).
  `_print_report` получил три параметра по умолчанию; «нечего убирать»
  подавляется непустым видом или строкой «пропущено». Прежние строки
  отчёта не тронуты.
- `docs/retention.md`: оба раздела по требованию 4.
