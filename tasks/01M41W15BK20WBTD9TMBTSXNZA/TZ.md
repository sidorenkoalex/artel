# ТЗ: plank-run работает в шаге роли — путь планки, который признаёт сторож роли

Источник: копилка 04.10.2026 (П1). Задача 01M41R4YAM4NGEQXW1FWH7T22M
(слита 03.10) ввела команду `artel.py plank-run`; первый же вызов из
шага роли (test_author задачи 01M41VH0Z3CQ0WY039SV1ERGMB, 03.10 21:47Z)
получил отказ сторожа роли, роль прогнала планку обходом через
`unittest`. Решение Оператора 04.10.2026 «ок по рекомендациям».

Факты (пин d860c974):
- `orchestrator/plank_run.py:139-141` передаёт pytest АБСОЛЮТНЫЙ путь:
  `target_arg = str(tests_dir / selected)` либо `str(tests_dir)`, где
  `tests_dir` — `<рабочая копия>/tasks/<id>/acceptance_tests`; запуск —
  `acceptance.run_plank([target_arg], code_dir)` с `cwd=code_dir`.
- Сторож роли `conftest.py::pytest_configure` (при заданной переменной
  роли) пропускает только позиционные пути, которые
  `_is_targeted_path` признаёт целевыми: относительный путь ниже
  `tests/` или путь с первым сегментом `tasks` и сегментом
  `acceptance_tests`. Абсолютный путь начинается с пустого сегмента —
  отказ «Сторож роли: полный прогон набора тестов внутри шага запрещён»
  (проверено 04.10: `_is_targeted_path('/…/tasks/ID/acceptance_tests')`
  → False).
- Процесс pytest, который запускает `plank-run`, наследует окружение
  роли (переменная роли задана) — поэтому сторож срабатывает.
- Тесты задачи 01M41R4YAM4NGEQXW1FWH7T22M
  (`tests/test_01m41r4yam4ngeqxw1fwh7t22m_plank_run.py`,
  `tests/test_plank_run_edges.py`) подменяют `subprocess.run` и
  настоящий сторож под окружением роли не исполняют.
- `conftest.py` защищён (настройки сбора тестов): правка только
  приложением; решение этого ТЗ его не меняет.

Требуется:
1. `plank-run` передаёт pytest путь планки в форме, которую признаёт
   сторож роли (относительный от рабочей копии кода:
   `tasks/<id>/acceptance_tests[/<файл>]`), для всей планки и для
   одного файла; поведение без окружения роли не меняется.
2. Сквозной сторож в `tests/` (заявка «Ловит мутацию»): `plank-run`
   под окружением роли, БЕЗ подмены `subprocess.run`, на песочнице с
   настоящим `conftest.py` репозитория — прогон доходит до pytest и
   даёт его итог (не отказ сторожа роли); краснеет при возврате
   абсолютного пути. Тот же случай для аргумента одного файла.
3. Если существующий долгоживущий тест задачи 01M41R4YAM4NGEQXW1FWH7T22M
   закрепляет абсолютную форму аргумента — SPEC называет тест и
   утверждение; правка только в объёме смены формы пути, с перечнем в
   PLAN (гейт сохранности тестов — мандат Оператора при необходимости).
