# ANSWER-1: ответ Оператора

## Ответы

1. Шифр (AC-1, требование 1). Факт принят: `openssl enc` не умеет
   AEAD-шифры, литерал `aes-256-gcm` в SPEC был ошибкой аналитика.
   Решение — вариант (a): `openssl enc -aes-256-cbc -pbkdf2` плюс тег
   HMAC-SHA256 по шифртексту через `openssl dgst -sha256 -hmac`
   (encrypt-then-MAC). Порядок при восстановлении: сверить тег, и
   только при совпадении расшифровывать; сравнение тегов —
   `hmac.compare_digest`; неверный тег — именованный отказ без записи
   открытого пула. Ключ HMAC выводится из ключа пула детерминированно
   (SHA-256 от ключа с суффиксом `:mac` или эквивалент), чтобы в keychain
   оставался один слот. Формат файла `canary/pool.sealed` — на усмотрение
   разработчика (например, тег первой строкой/первыми 32 байтами, далее
   шифртекст), формат зафиксировать докстрингом модуля. SPEC (контекст,
   требование 1, AC-1) исправлен Оператором тем же коммитом, что этот
   ответ; `age` не вводим — новая установка противоречит объявленному
   стеку; вариант без аутентификации отклонён.
2. Запрет для ролей (AC-13, требование 5). Варианты (a) и (b) вместе.
   В `permissions.deny` референса `docs/reference/role-home/claude/
   settings.json` добавляются четыре литерала:
   `Bash(python3 orchestrator/artel.py init:*)`,
   `Bash(python3 orchestrator/artel.py doctor --restore:*)`,
   `Bash(openssl enc -d:*)`,
   `Bash(security find-generic-password:*)`.
   Тест AC-13 закрепляет наличие всех четырёх строк в файле референса.
   Ролям ни `init`, ни `doctor --restore`, ни прямой openssl/security не
   нужны в штатной работе — запрет ничего не отбирает. Отдельную
   подкоманду расшифровки (вариант c) не заводим.
3. Слот keychain для ключа пула — `artel-canary-pool-key`; имя
   объявляется константой в `orchestrator/config.py` рядом с
   `CANARY_POOL_DIRNAME`, тесты читают константу, не литерал.
4. Порядок: планка дописывается по этим ответам (AC-1 — проверка
   наличия тега HMAC и отказа на повреждённом теге, AC-13 — четыре
   литерала), затем developer. Бюджет поднят до $45 под рукописный
   encrypt-then-MAC.
