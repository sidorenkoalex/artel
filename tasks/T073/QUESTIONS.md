# QUESTIONS: Retention-политика и команда prune

## Вопросы
1. **Чему равно N в лимите «90 дней И N последних задач» для
   `.artel/logs/`?** ТЗ (и роадмап, и оба аудита-источника,
   docs/roadmap.md:169, docs/audits/roadmap-audit-2026-08-23-v3-engineer.md:218)
   называют лимит «N последних задач», но конкретное число N нигде не
   зафиксировано. Без него нельзя написать проверяемый AC для
   docs/retention.md и для второго лимита `prune` (test_author не
   сможет из AC вывести приёмочный тест на конкретное число хранимых
   задач) — варианты: A) N=20; B) N=50; C) N=100; D) другое число
   (указать) — дефолт: A) N=20, если Оператор промолчит по этому
   пункту (порядок величины «десятки последних задач», ближе всего к
   типичному числу одновременно осмысленных для отладки прогонов).
