# PLAN: Допуск нескольких пар и правка набора одним коммитом

## Подход
Меняется только `orchestrator/models.py::cmd_admit` и его разбор
(`_parse_admit_args`), плюс тексты справки.

- Разбор: позиционные собираются `nargs="*"` в один список `pairs`;
  флаг `--set <имя>`. Ноль позиционных или нечётное их число — тот же
  отказ разбора `admit: …\n{ADMIT_USAGE}`, что и прежде.
- `--set` с двумя парами одной роли — отказ до сверок.
- Сверка всех пар до записи: роль и модель каждой пары (прежние тексты
  отказа), затем сводка `pair_admission` печатается по КАЖДОЙ паре, недобор
  копится по парам; после цикла — отказ, если хоть одна пара недобрала.
  Для одной пары текст отказа прежний байт в байт; для нескольких —
  перечень сгруппирован по парам с заголовком «пара R → M:».
- Правки документа в памяти: записи всех пар (одно `--basis`), при `--set`
  — `sets.<имя>` дополняется моделями пар (прочие роли набора не тронуты,
  набор создаётся). Затем проверка допуска пар набора после записи тем же
  правилом, что пункт (а) `set_admitted`: пара на боевой модели роли
  пропускается, прочие — `_pair_refusal(document, …)` по обновлённому
  документу и `pair_suspension_refusal`. Отказ — без записи.
- Запись — один `notes.doc_commit_content`. Сообщение: одна пара без
  `--set` — прежнее «<действие> пары R → M: <основание>»; несколько пар —
  «<действие> пар R1 → M1, R2 → M2: …»; при `--set` перед основанием
  добавляется «, набор <имя>».

Бюджет SPEC ($40) достаточен: два файла кода, один долгоживущий файл
тестов уже написан test_author.

## Влияние на систему
Механизм `doc-commit` и гейт полного набора не меняются — вызов
`doc_commit_content` прежний, просто один на вызов `admit`. Числа допуска
ADR-0019 п.5 и `set_admitted` не меняются; проверка набора в `admit`
читает те же `_pair_refusal`/`pair_suspension_refusal`. Одна пара — прежний
вывод, текст отказа и сообщение (существующие тесты команды не правятся).
`--set` не проверяет пункт (б) `set_admitted` — по SPEC «Не входит»; допуск
набора к задачам по-прежнему проверяют `new --set`/`set-models`. Откат —
revert merge-коммита.

## Риски
- Разбор `nargs="*"` с флагами вперемешку: обычный `parse_args` склеивает
  только подряд идущие позиционные — поэтому `parse_intermixed_args`,
  флаги допустимы и между парами.
