# ТЗ: Допуск нескольких пар и правка набора одним коммитом

Источник: решение Оператора 14.10.2026 («сразу нельзя все допустить? —
лучше задачу на допуск»); перевод набора `codex-all` на `gpt-6-astra`
по канарейке 20261013T203530Z — пять пар, затем правка набора.

Факты (main 2baf1b2a):
- `orchestrator/models.py::cmd_admit` принимает ровно одну пару
  (`_parse_admit_args`: позиционные `role`, `model`) и пишет её
  изолированным коммитом через `notes.doc_commit_content`.
- `model_sets.yaml` входит в `notes.DOC_COMMIT_CONFIG_PATHS`, поэтому
  каждый коммит гонит полный набор `tests/` перед отправкой (около 15
  минут). Пять пар и последующая правка набора через `doc-commit` — шесть
  коммитов и шесть полных прогонов, около полутора часов, при том что
  проверяется одна и та же конфигурация.
- Записи набора (`sets:`) команды не имеют: набор правится `doc-commit`
  всего файла, отдельным коммитом и отдельным прогоном.

Требуется:
1. `admit` принимает несколько пар за один вызов (форма — выбор SPEC,
   например повтор `<роль> <модель>` или `--pair <роль>=<модель>`).
   Одна пара — поведение и вывод прежние, байт в байт.
2. Сверка до записи — для всех пар: сводка прогонов печатается по каждой
   паре; недобор хотя бы у одной — отказ с перечнем недостающего по
   каждой паре, файл и HEAD не трогаются (всё или ничего, частичной
   записи нет). `--revoke` для нескольких пар — так же одной записью.
3. Необязательный `--set <имя>`: тем же вызовом записать в набор
   `sets.<имя>` модели названных пар (роль → модель). Набор создаётся,
   если его нет; роли набора, не названные в вызове, не меняются.
   Отказ, если хотя бы одна пара набора после записи не допущена.
4. Запись — один изолированный коммит через `notes.doc_commit_content`
   с одним прогоном гейта полного набора; сообщение коммита перечисляет
   все пары и набор. Основание `--basis` — общее для всех пар вызова.
5. Справка (`ADMIT_USAGE`, строка в `orchestrator/artel.py`) показывает
   новую форму.
6. Тесты: одна пара — прежний вывод; несколько пар — один коммит и одна
   запись; недобор у одной из пар — отказ без записи; `--set` — набор
   записан, прочие роли набора не тронуты; `--set` с недопущенной парой
   — отказ; `--revoke` нескольких пар.

Матрица неослабления:
- Числа допуска ADR-0019 п.5 сверяются по каждой паре, как сейчас; флага
  вопреки недобору нет (требование 2).
- Гейт полного набора не обходится и не ослабляется: прогон один, но на
  итоговом дереве со всеми правками (требование 4).
- Набор не может сослаться на недопущенную пару (требование 3).

Зоны: orchestrator/models.py, orchestrator/artel.py, tests/.

Не входит: изменение чисел допуска и критерия чистого прогона (задача
01M4VC31NFCS6JZ0VE8HNJ7FYM); изменение механизма `doc-commit` и гейта
полного набора в `orchestrator/notes.py`.
