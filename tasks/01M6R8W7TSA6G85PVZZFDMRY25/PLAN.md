# PLAN: target-set: запись автора коммитов пульта machine.commit_author

## Подход
Форма `--from-file` (`orchestrator/projects.py:_target_set_block`) уже несёт
разбор файла, сверку `_target_set_block_mismatches`, копию прежнего файла и
журнал; путь блока проверяет `_block_keys`. Добавляется третья ветка
`_block_keys`: ключи `["machine", "commit_author"]` (имя поля — из
`targets.DELIVERY_MACHINE_FIELDS`, единственное место имени в targets.py) —
и дописывается конец строки `BLOCK_PATHS`. Проверка формы `{name, email}`
уже живёт в `targets.merge_local` (`orchestrator/targets.py:715-720`) и
срабатывает на пересборке слоя до записи — отдельная проверка в projects.py
не нужна (подтверждено test_author: отказ приходит текстом «нужно {name,
email}»). Справка `artel.py:200` пишет путь блока общим `<путь блока>` —
не меняется (требование 5).

Меняется только набор допустимых путей формы `--from-file`: прочие пути
`machine.*` отказывают как прежде (ветка совпадает ровно с одним путём).

тесты, лимиты не затронуты. Существующий тест 01M6QZ4R… проверяет перечень
вхождением прежней строки — она остаётся началом. Откат — revert коммита.
