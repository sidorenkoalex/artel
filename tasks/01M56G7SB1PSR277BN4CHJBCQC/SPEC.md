# SPEC: Ревью-пакет задачи внешнего проекта: конвенции проекта, без карты пульта

## Контекст
Задача 01M5634E094QF7JX8HD3KSG4KN (смержена 18.10) положила в брифы ролей
задачи внешнего проекта конвенции проекта (`CLAUDE.md`, `AGENTS.md` корня
базовой ветки клона) вместо карты пульта, но ревьювер остался вне её зон:
пакет ревьювера собирает `orchestrator/review.py::review_package`
(`review.py:721`, сборка частей `:870-1002`). Сегодня в пакете ревьювера
задачи внешнего проекта конвенций проекта нет, а абзац об исключении карты
(`review.py:965-975`) называет `docs/codebase-map.md`, джоб CI «Карта кодовой
базы генерируется и свежа» и команду `python3 scripts/codebase_map.py` — у
внешнего проекта (sled) их нет.

## Требования
1. Ревью-пакет задачи внешнего проекта несёт конвенции проекта (`CLAUDE.md`,
   `AGENTS.md` корня базовой ветки клона проекта) тем же источником, что брифы
   ролей после 01M5634E094QF7JX8HD3KSG4KN, — функцией
   `orchestrator/brief.py` (`_project_conventions_parts` /
   `_read_project_conventions`), без дублирования чтения в `review.py`; с теми
   же пометками: «файла нет» (`brief.PROJECT_CONVENTIONS_ABSENT_MARK`) на
   месте отсутствующего файла и «конвенции проекта не прочитаны: <причина>»
   (`brief.PROJECT_CONVENTIONS_UNREAD_MARK`) на месте нечитаемого.
2. У задачи внешнего проекта пакет не выводит абзац об исключении карты пульта
   и команде её регенерации: в тексте пакета нет `docs/codebase-map.md`,
   `scripts/codebase_map.py` и названия джоба CI «Карта кодовой базы
   генерируется и свежа». Признак проекта — тот же, что у брифа
   (`repo_context.is_artel` / `brief.is_artel_task`).
3. У задачи артели пакет ревьювера не меняется ни на байт; это фиксируется
   тестом, написанным и зелёным до правки `review.py`.
4. Тесты детерминированы и без сети: учебный внешний проект — песочничный
   git-клон с базовой веткой.

## Критерии приёмки
AC-1. Пакет ревьювера задачи учебного внешнего проекта, в базовой ветке клона
которого есть `CLAUDE.md`, содержит текст этого `CLAUDE.md`.

AC-2. Пакет ревьювера задачи учебного внешнего проекта, в базовой ветке клона
которого нет `CLAUDE.md`, содержит пометку `файла нет` для `CLAUDE.md`
(текст пометки — `brief.PROJECT_CONVENTIONS_ABSENT_MARK`, как в брифе роли).

AC-3. Пакет ревьювера задачи учебного внешнего проекта, базовую ветку которого
прочитать нельзя, содержит пометку `конвенции проекта не прочитаны` с
причиной (текст — `brief.PROJECT_CONVENTIONS_UNREAD_MARK`), и сборка пакета
при этом не падает.

AC-4. Пакет ревьювера задачи учебного внешнего проекта не содержит строк
`docs/codebase-map.md`, `scripts/codebase_map.py` и `Карта кодовой базы
генерируется и свежа`.

AC-5. Пакет ревьювера задачи артели на фиксированном входе (одинаковые
SPEC/PLAN/форма вердикта/ветка/diff и тот же идентификатор запуска) побайтно
совпадает с пакетом, собранным кодом до правки: в нём по-прежнему есть абзац
об исключении `docs/codebase-map.md` с командой `python3
scripts/codebase_map.py` и нет компонентов конвенций проекта.

AC-6. Тесты AC-1–AC-5 не обращаются к сети: учебный внешний проект — локальный
git-репозиторий песочницы.

## Оценка объёма и деление
Сработавший сигнал — «число затрагиваемых модулей/файлов» (и как следствие
«прогноз диффа не дан»): guard считает все упомянутые в тексте
`orchestrator/*.py`/`scripts/*.py`, а большинство из них здесь — пути только
для чтения из ТЗ (`brief.py`, `repo_context.py`, `role_prompt.py`,
`codebase_map.py`). Правится один модуль — `orchestrator/review.py` (развилка
артель/внешний проект в `review_package`) — плюс тесты в `tests/`.

Прогноз диффа: 12 КиБ

Обоснование монолита: правка — одна развилка в одной функции и её тесты;
требование 3 («у артели пакет не меняется») и требования 1-2 проверяются на
одном и том же месте сборки пакета, резать нечего — часть без развилки не
даёт наблюдаемого изменения, часть без тестов не мержима по ТЗ (требование
3 требует фиксацию тестом до правки).
