# Ревью-пакет задачи внешнего проекта: конвенции проекта, без карты пульта

## Факты

Продолжение задачи 01M5634E094QF7JX8HD3KSG4KN (бриф роли внешнего проекта, смержена 18.10): по решению на эскалации ревьювер вынесен в «Не входит», потому что пакет ревьювера собирает `orchestrator/review.py::review_package` (`:870-1002`), вне зон той задачи. Сейчас в пакете ревьювера задачи внешнего проекта нет конвенций проекта (`CLAUDE.md`/`AGENTS.md` sled), а абзац об исключении карты (`review.py:965-975`) говорит о `docs/codebase-map.md`, джобе CI «Карта кодовой базы…» и команде `python3 scripts/codebase_map.py` — у sled их нет. Для остальных ролей задача 01M5634E09 уже кладёт конвенции проекта с базовой ветки клона (тот же источник — использовать его функцию из `orchestrator/brief.py`, не дублировать).

## Требуется

1. Ревью-пакет задачи внешнего проекта несёт конвенции проекта (`CLAUDE.md`, `AGENTS.md` корня базовой ветки) тем же источником и с теми же пометками «файла нет» / «конвенции проекта не прочитаны: <причина>», что брифы ролей после 01M5634E09.
2. У задачи внешнего проекта абзац пакета об исключении карты пульта и команде её регенерации не выводится (карту проекта, если она есть, пакет не исключает — вне задачи).
3. У артели пакет ревьювера не меняется ни на байт; зафиксировать тестами до правки.
4. Тесты детерминированы, без сети: учебный внешний проект с `CLAUDE.md` в базе — пакет содержит его текст и не содержит абзаца о `docs/codebase-map.md`; без файла — пометка; у артели — прежний пакет.

Критерии приёмки:
- ревьювер задачи внешнего проекта видит конвенции проекта;
- в пакете внешней задачи нет указаний на карту и генератор пульта;
- у артели пакет прежний.

Зоны: `orchestrator/review.py`, `tests/`.

Только чтение: `orchestrator/brief.py`, `scripts/codebase_map.py`, `orchestrator/repo_context.py`, `orchestrator/role_prompt.py`, `docs/backlog.md`. Правка вне зон — эскалация до SPEC.

Не входит: миссия ревьювера (задача 01M56G23ZQDHV2BKEVWWC22R96); карта кода внешнего проекта.

Рамка: $25. Набор моделей — по умолчанию.
