## Пути обхода гейтов
- **П1 (требование 3 / AC-5).** «Тест, написанный и зелёный до правки» никакой гейт не проверяет. Исполнитель может снять эталон пакета артели уже после правки `review.py`. Тогда AC-5 побайтно сравнит новый код сам с собой и пропустит любую регрессию пакета артели. Спасает только порядок коммитов (тест отдельным коммитом раньше правки) и проверка этого ревьювером. SPEC не требует ни того, ни другого, ни литерального эталона, сверенного с `main`.
- **П2 (AC-4 / требование 2).** Требование выполнимо удалением всего абзаца `:965-975` у внешней задачи вместе с фразой о `tasks/<id>/` (D1): AC-4 при этом зелёный.
- **П3 (AC-1).** Компонент конвенций можно вставить без `brief.wrap_boundary` — например, адаптером `render`, который возвращает голый текст. AC-1 при этом зелёный, а недоверенный `CLAUDE.md` внешнего проекта попадает в промпт ревьювера без границ (D3).
