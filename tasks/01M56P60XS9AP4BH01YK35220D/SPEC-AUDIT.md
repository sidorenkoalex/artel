## Пути обхода гейтов
1. **Смена значения метки без смены текста маркера.** Маркер в наборе
   сравнения — текст (`markers - base_markers` в `test_integrity.py:450`).
   База: `requires_pg = pytest.mark.skipif(False, reason="…")`, ветка:
   `requires_pg = pytest.mark.skip` — у тестов текст `@requires_pg` тот же,
   находки нет. Для импортированной метки хуже: правится только модуль
   метки (без тестовых методов), файлы тестов не меняются, узел их даже не
   сравнивает. Требования 1–2 этого не закрывают: прямой
   `@pytest.mark.skipif` → `@pytest.mark.skip` даёт новый маркер и
   находку, а через метку — нет; «тот же класс находки, что прямой
   декоратор» буквой выполнен, смыслом нет (D1).
2. **Пропуск варианта через `parametrize`.** `pytest.param(…,
   marks=pytest.mark.skip)` или пустой список аргументов
   (`parametrize("x", [])` — pytest пропускает тест целиком) — это
   пропуск, но по требованию 6 он лишь «наблюдение» журнала и пакета, не
   находка класса пропуска (D3).
3. **Метка вне модулей тестов.** Требование 1 ограничено «модулем тестов
   проекта»; метка из фабрики (`def requires(x): return
   pytest.mark.skipif(…)`, `@requires("pg")`) или из модуля вне
   `weakening_scope` не опознаётся. Это за рамкой ТЗ, отклонением не
   считаю — отмечаю для Оператора.
4. **Послабление на существующем файле.** Буквально по AC-3/AC-4 можно
   дать послабление условной метке/`pytestmark` с причиной и на методах,
   которые в базе уже были, — сейчас прямому декоратору такого
   послабления нет (D1).
5. **Свёртка вариантов и убыль вариантов.** «Каждый вариант» считается
   по набору, который отчитал pytest; если новая версия теста убрала
   варианты, свёртка идёт по меньшему набору, а убыль видна только
   наблюдением требования 6 (D3, D4). Кроме того, смену ожидания в
   строке `parametrize` нельзя объявить в «Меняемом поведении»: литералы
   объявления берутся только из утверждений (`guard.method_literal_keys`,
   `guard.py:3834-3846`) — AC-10 исполним, только когда смена — в
   утверждении тела метода; SPEC этого не говорит.
