## Пути обхода гейтов
1. **Режим прослеживания у артели (C1).** Требование 6 задаёт правило
   «по области ослабления профиля», а область артели —
   `tests/**/*.py` (`targets.yaml:49`): буквальное применение правила
   к артели прослеживает импорт из любого модуля `tests/` и ломает
   AC-10 (в). Чтобы удержать AC-10 (в) и пройти AC-9, исполнитель обязан
   развести режимы по признаку, которого SPEC не называет: `is_artel`,
   наличие `workdir`, раннер `pytest-own`… Выбор признака — решение по
   существу (третий проект с `weakening_scope: [tests/**/*.py]` без
   `workdir` получит режим артели, т. е. помощники других модулей не
   прослеживаются — пропуск ослабления на чужом стеке, ради которого
   задача). То же разведение затрагивает импортированную метку у артели
   (требование 5): AC её не проверяет, и реализация «как у помощников,
   только `tests/sandbox.py`» у артели проходит все AC.
2. **Цепочки имени и формы `pytestmark` (C4).** Требование 1 —
   «имя, связанное … с `pytest.mark.skip…`»; требование 4 — «`pytestmark
   = …`». Буквой не покрыты: псевдоним псевдонима (`_skip =
   pytest.mark.skip; requires_pg = _skip`), `pytestmark += [...]` /
   `pytestmark.append(...)`, модульный `raise unittest.SkipTest(...)` /
   `raise pytest.skip.Exception(...)`, повторное связывание имени после
   использования декоратором (какое значение «связанного имени»
   сравнивать — последнее в модуле или действующее на строке `def`).
   Исполнитель, сделавший разбор одного присваивания `Name =
   Call(pytest.mark.*)`, проходит все AC, а ослабление через эти формы
   остаётся без находки. Фабрика и модуль вне модулей тестов SPEC
   исключил явно по ТЗ — это не отклонение.
3. **Читатель объявления без `workdir` (C2)** — см. «Зоны»: не обход, но
   две разные картины утверждений помощника у гейта и у сверки объявления.
4. Хуки сборки (`conftest.py` `pytest_collection_modifyitems`,
   `request.applymarker`) пропускают тесты мимо любых маркеров; у sled
   `**/conftest.py` в `no_paths` (`targets.yaml:74`), у артели нет. За
   рамкой ТЗ — отмечаю Оператору, не отклонение.
