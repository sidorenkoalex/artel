Уточнение Оператора к возврату с гейта мержа 04.11.

Пункт 3 причины возврата («защита от повторного входа: переменная-признак вложенного вызова») ОТМЕНЯЕТСЯ: он противоречит требованию SPEC «никакая переменная окружения не выключает обёртку» (решение Оператора, возврат 8). Не вводить никакой переменной, по которой обёртка пропускает разбор.

Повторный вход исключается пунктом 1: real_git ищет настоящий git по PATH в обход ВСЕХ каталогов с обёрткой роли (любой копии пульта), поэтому обёртка никогда не вызывает другую обёртку. Пункты 1, 2 и 4 причины возврата — в силе. Тест пункта 4 дополнить: при двух обёртках на PATH вызов git в своей рабочей копии дублёра (где обёртка читает git config) завершается в пределах таймаута, а число процессов git за время вызова не больше 3.
