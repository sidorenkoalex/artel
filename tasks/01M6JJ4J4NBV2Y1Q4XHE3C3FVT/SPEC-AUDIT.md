## Пути обхода гейтов
- Е-П1 и Е-П2 визита 2 сняты. Отказ верхнего уровня не зависит от запуска
  pager (псевдотерминал), а таймаут 30 с ловит рекурсию fsmonitor (AC-7).
- Наблюдение, не отклонение: правило «значение содержит вызов git как
  команду» в SPEC не формализовано. Узкая реализация (например, только префикс
  `git `) пропустит `cd . && git clean -fX` или `/usr/bin/git clean -fX`, а AC-7
  фиксирует лишь форму `git clean -fX`. Под модель угрозы (ошибочная команда, не
  намеренный обход) и под букву решения №2 это подходит; держать на ревью.
- Наблюдение, не отклонение: родственные каналы вложенного запуска git вне
  списка решения №2 — `pager.<команда>` (проверено: при TTY `-c
  pager.log='echo …'` исполняется), `core.hooksPath`/хуки, `core.editor`,
  `GIT_SSH_COMMAND`. В шаге роли нет TTY, значит pager не запускается вообще.
  Остальные каналы требуют намеренной настройки, это вне модели угрозы. ТЗ их
  не называет, поэтому отклонением это не считаю.
