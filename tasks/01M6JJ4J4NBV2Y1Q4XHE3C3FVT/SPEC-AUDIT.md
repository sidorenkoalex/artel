## Пути обхода гейтов
- Наблюдение, не отклонение. Исключение «клон своей задачи и его
  подкаталоги, в том числе общий `.git`» (SPEC.md:62-67) включает служебные
  каталоги чужих рабочих копий того же клона
  (`<клон>/.git/worktrees/<чужая задача>`). Это не «внутри рабочей копии
  другой задачи», поэтому оговорка SPEC.md:62-63 их не отсекает.
  `GIT_DIR=<клон>/.git/worktrees/<чужая> git reset --hard` из своей копии
  двигает индекс чужой задачи. Для модели угрозы (ошибочная команда) это
  маловероятно, к тому же общие ссылки (`git branch -D task/…`) достижимы и
  из своей копии без всяких флагов. Держать на ревью: разработчик может
  отсечь `<клон>/.git/worktrees/<не своё>`, не выходя за SPEC.
- Наблюдения прошлых визитов (нестрогое «содержит вызов git»; каналы
  `pager.<команда>`/хуки) в силе, держать на ревью.
