# ТЗ: R1 — разбор цикла `auto` на шаги с явным контрактом

Источник: роадмап §3, фаза R (план рефакторинга 05.09), пункт R1.
`orchestrator/auto.py::_cmd_auto` — 246 строк одной функции: предварительный
advance по готовым артефактам (с рубежами регрессии №13), запуск роли,
разбор отказов (guard, зоны, лимит параллельности, бюджет, CI, лок планки),
стоп-краны (буксование, повтор одинакового отказа), лимит шагов, журнал и
подсказки Оператору. Три регрессии 05.09 (№11, №13 и повтор эскалации после
ANSWER) сидели именно здесь; каждая правка требовала читать функцию целиком.

Правила фазы R: поведение не меняется — рефакторинг ≠ фикс; смоук байт-в-байт;
существующие тесты без правки утверждений; защиты и инварианты не трогаются.

Требуется:
1. `_cmd_auto` разобрать на именованные шаги цикла, каждый — отдельная
   функция с одним делом и явным входом/выходом: (а) решение «нужен ли
   пред-advance» (правила №13 — возврат с основанием переделки, возврат из
   escalated — в одном месте); (б) выполнение пред-advance и разбор его
   исхода; (в) запуск шага роли и разбор исхода (finished/failed/skipped/
   timeout); (г) стоп-краны (буксование N шагов без перехода, повтор
   одинакового отказа, лимит шагов за вызов); (д) остановка с журналом и
   подсказкой (`auto_stop`). Цикл `_cmd_auto` становится короткой
   композицией этих шагов.
2. Исходы шагов — явные значения (перечисление или маленький dataclass:
   `advanced`, `role_ran`, `refused(<причина>)`, `stop(<причина>)`), без
   передачи состояния через локальные переменные цикла и флаги.
3. Тексты журнальных записей, подсказок и печати сохраняются буквально
   (`тесты test_auto_cycle.py` и планки 01M1R8B3ZK…, 01M1RHFRQ2… сверяют их).
4. Смоук байт-в-байт: на живом журнале пульта (копия БД в песочнице)
   сценарии `auto` из существующих тестов дают тот же журнал и тот же
   вывод до и после рефакторинга; отдельный тест сравнивает вывод
   старого и нового цикла на трёх записанных сценариях (фикстура —
   записанный вывод текущей реализации).
5. Существующие тесты `tests/test_auto_cycle.py`, планки задач
   01M1R8B3ZKXQT0Z0G6QQQDV906 и 01M1RHFRQ2C0P4A57XJJ1WZV8N зелёные без
   правки утверждений.

Зоны: orchestrator/auto.py, tests/. Свободны (№13 смержена). Не входит:
изменение поведения, правки fsm_advance.py, новые рубежи.
