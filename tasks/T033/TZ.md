# ТЗ: advance по зафиксированному состоянию (симметрия с approve)

Фикс по строке подметалки P3 из T032: асимметрия advance/approve.

Инцидент: ревьюер обновил REVIEW.md (approved), но не закоммитил;
advance пропустил переход review -> acceptance по грязному артефакту,
а approve на acceptance отказал по чистоте — задача застряла между
двумя проверками, чинил Оператор коммитом чужого вердикта.

Хочу:
1. Симметрию: advance выполняет переход только по зафиксированному
   состоянию артефактов задачи (та же сверка чистоты, что у approve
   из T021): артефакт-условие перехода изменён, но не закоммичен —
   отказ перехода с именованной причиной вида «REVIEW.md не закоммичен
   — роль обязана коммитить артефакты (скил conventions-core);
   закоммить и повтори advance». Не эскалация — просто отказ с
   подсказкой: незакоммиченный артефакт штатно докоммичивается.
2. Причина отказа пишется в журнал задачи (видна в log).
3. Существующее поведение для чистого состояния не меняется; тесты
   не ослабляются; новое поведение — тестами (переход по грязному
   артефакту каждого типа условия: SPEC ready, PLAN ready, REVIEW
   вердикт).
4. Если найдёшь место, где отказ невозможен без ломки легитимного
   флоу (например, переходы, где грязь штатна) — не изобретай,
   назови в PLAN «Риски» с обоснованием.
Класс — мелкий фикс, $15. Строку подметалки про асимметрию удали
этой же задачей (как T032 удалила свою).
