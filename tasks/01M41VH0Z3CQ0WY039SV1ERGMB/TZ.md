  красен на ветке; замер «после» по CI ветки для такой правки
  невозможен.

Требуется:
1. В `skills/spec-authoring.md`, раздел «Границы», два пункта (смысл —
   обязателен, формулировка — на усмотрение роли, по-русски, с
   основаниями-прецедентами):
   а) тест в `tests/` заказывается по свойству, а не по месту: свойство,
      которое держит долгоживущий приёмочный тест автора тестов
      (ADR-0020), SPEC повторно в `tests/` не требует (основание —
      пересчёт 03.10);
   б) для правки, которая едет приложением к защищённому пути: сторож
      свойства требуется внутри того же приложения, не отдельным файлом
      `tests/` ветки (основание — 01M41JYGHTP8ZVXVPEF8K8W381); замер
      «после» по CI ветки не заказывается — «до» по CI `main`, «после»
      даёт первый CI `main` после мержа.
2. Правка — приложением к PLAN, проверенным `git apply --check`; других
   изменений нет.
