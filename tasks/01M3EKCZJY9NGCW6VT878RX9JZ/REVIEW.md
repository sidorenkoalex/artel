  исполнением»): при подтверждённом входе ChatGPT — `rc=0`,
  `stdout=''`, `stderr='Logged in using ChatGPT\n'`. Сценарий поломки:
  Оператор ставит указатель связки, входит, вход сохранён — и всё равно
  получает `codex-chatgpt-auth = fail` с рецептом «войдите»; репро через
  код пульта даёт ровно это. Поскольку `provider.check_token(role)` —
  блокирующая строка предполёта шага (`preflight.py:651-655`), НИ ОДИН
  шаг роли на `codex` не сможет стартовать, а `doctor` не станет зелёным

  кладут строку входа в stdout — обе описывают CLI, которого нет.
  Предложение: искать `CHATGPT_LOGIN_RE` по ОБЪЕДИНЁННОМУ тексту
  `stdout` + `stderr` (в `detail` по-прежнему не подставлять ни один из
