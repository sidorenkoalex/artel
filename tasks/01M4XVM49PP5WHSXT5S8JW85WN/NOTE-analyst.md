## Выяснено
Сдан SPEC.md: ready, schema_version 5, AC-1–AC-15, бюджет $45 в рамке $50; zones из ТЗ. ANSWER-1.md снял блокеры: 1A (адресная миграция по ADR-0024), 2B (принадлежность процесса живому шагу через существующие process/lease). Полный принятый ADR приведён в ответе; его публикация остаётся за Оператором.
Мандат касается только пяти методов readonly_db из матрицы SPEC, не helpers/всего файла. Сохраняются имена, виды и строгость assertions, исходы разрешённых запусков. Отдельные AC закрепляют отчёты, досыл, общий замок, timeout и логи. Раздел «Меняемое поведение» не используется: разрешена смена области сценариев, не скалярных ожиданий.
Потеря ARTEL_ROLE при подтверждённом developer не разрешает полный запуск. Без доказанной принадлежности сохраняется прежний маршрут. Чтение существующей БД допустимо без побочных эффектов; создание/открытие на запись, deliver_journal, файлы, замок, PID и запуск до отказа запрещены. Старый тест миссии сохраняется с командами статуса/ожидания/повтора.
