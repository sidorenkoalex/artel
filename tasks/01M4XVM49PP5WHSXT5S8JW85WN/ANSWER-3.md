# ANSWER: точечный доверенный канал и пересмотр SPEC

Оператор 15.10.2026 подтвердил весь пакет: ровно один Unix-сокет брокера, kernel peer PID + ancestry + идентичность актуального process/lease; эффективные запреты прочей сети и процессов сохраняются. При UNKNOWN/сбое канала новый full запрещён без побочных эффектов, включая операторский; status/wait/разрешённый failed и внутренние гейты/CI сохраняются. Реальные проверки Codex/Claude на macOS/Linux обязательны до признания реализуемости; debug sandbox не заменяет их. Несовместимость версии/отсутствие фильтрующего proxy/ошибка удостоверения — отказ, без fallback на ENV, один PGID или открытие сети. Действующий потолок $45 не увеличивается.

Этот адресный мандат заменяет прежние запреты изменения sandbox/allow-policy/provider только в части единственного socket-допуска. Он не разрешает отключить старые assertions конфигурации целиком: их свойства должны быть сохранены предметными проверками эффективной политики. Прямой TCP/UDP/IPv6, соседний Unix-сокет, внешние domains и ps/process ограничения проверяются отдельно; разрешение filesystem не равно IPC. Endpoint и ENV — доставка адреса, не удостоверение. Проверяются подмена брокера/lease, PID reuse, завершение/смена lease и ограниченные сроки IPC.

Факт capability: реальная текущая роль отказала connect EPERM. На codex-cli0.157.1 config network.enabled=false с proxy on/off также EPERM. Временный debug-профиль network.enabled=true + network_proxy + limited + domains={} + один Unix allow прошёл только контрольные one-socket/siblingUnix/rawTCP/proxy403/kernelpeerPID; остальное ещё не доказано. Не переносить debug-профиль в production без пересмотра и live проверки.

Аналитику: прочитать ADR-0024, ADR-0025, ANSWER-1/2 и фактический PLAN/NOTE; подготовить новый SPEC с явной матрицей сохранения, точными product/test zones и оценкой остатка бюджета. Добавление provider и платформенных адаптеров назвать явно. Прежний запрет нового полного developer-прогона сохраняется; роль определяется по process/lease. Ранее согласованные пять адресных замен readonly_db из ANSWER-1 не расширяются. Все остальные тесты, пределы suite, таймауты, guards и гейты сохраняются. Не обещать общий same-UID OS perimeter.
