# ТЗ: Codebase-map пульта автогеном

Нужна автогенерируемая карта кодовой базы пульта (codebase-map) —
по роадмапу §2 «codebase-map пульта автогеном» и ADR-0003 3б
(принцип свежести: кэш с меткой источника, никогда молчаливое
доверие).

Что хочу:
- Скрипт генерирует карту репозитория artel: список модулей
  (orchestrator/*, scripts/*, tests/* — верхний уровень), для каждого
  краткое назначение (первая строка docstring — она в этом репо
  обязательна по конвенциям), ключевые публичные функции, и кто кого
  импортирует. Никакого LLM — детерминированно из исходников.
- Выход — один markdown-файл с frontmatter, в котором built_at_sha
  (head репо на момент генерации) — по ADR-0003 3б.
- Где карта живёт — реши сам (напрашивается docs/ или .artel/knowledge/,
  посмотри как по ADR-0003 3а/3д правильнее для догфуда до A7).
- Генератор запускается в CI после мержа в main; провал генерации
  или стухшая карта (built_at_sha отстал от head) — это должен ловить
  doctor или CI, не глаза.
- Карта — будущий вход брифа разработчика и среза для analyst,
  так что формат должен быть машинно-срезаемым (секции по модулям).
Бюджет — класс $15 (мелкая задача).
