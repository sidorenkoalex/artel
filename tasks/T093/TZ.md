# ТЗ: К2 — куратор знаний: дистилляция копилки и ретро в правки скилов

Источник: роадмап §3 «Контур обучения», строка К2 ($25). Триггер
«антипаттерн повторился» зажжён (решение Оператора 01.09): третий
случай класса «скил отстаёт от свежей механики» — T064-guard,
T079-verifying, T075-ANSWER×spec-authoring (латали руками, CR-1
ревизии 31.08).

Вход (корпус дистилляции):
- секции «Предложения системе» во всех артефактах задач (копилка
  К1, наполняется с T046);
- RETRO-корпус docs/retro/ (итоги, эскалации, стоимости);
- ANSWER-файлы задач (решения Оператора по эскалациям);
- отчёты аудитов/ревизий 31.08–01.09 (docs/audits/) — только как
  контекст повторяемости, их находки уже разнесены отдельно.

Требуется:

1. Дистилляция: выделить УРОКИ, повторившиеся минимум дважды
   в корпусе (единичное наблюдение — не урок, остаётся в копилке);
   каждый урок — кандидат в конкретный скил (test-authoring,
   spec-authoring, review-checklist, coding-standards,
   conventions-core, escalation-rules) или в шаблон.
2. Каждая правка скила несёт ссылку на фактуру (номера задач/
   инцидентов, из которых урок дистиллирован) — правка без фактуры
   не принимается.
3. Дистиллированные записи ВЫЧИЩАЮТСЯ из копилки тем же MR
   (секция «Предложения системе» соответствующих артефактов
   закрытых задач — правка с мандатом, см. п.5) либо, если чистка
   артефактов закрытых задач признана в PLAN слишком инвазивной, —
   сводный реестр «дистиллировано → куда» в артефактах этой задачи
   с адресами (решить в PLAN, обосновать).
4. Ничего не ослаблять: правки скилов только ДОБАВЛЯЮТ дисциплину
   или чинят устаревшее; смягчение любого правила — вне мандата,
   эскалация.
5. Мандат на защищённые пути: skills/ и templates/ в no_paths —
   эта задача правит их ПО МАНДАТУ Оператора, выданному на
   spec_gate (прецедент T085/AC-6): SPEC обязан перечислить
   целевые файлы скилов явно; ревью проверяет соответствие правок
   фактуре и отсутствие ослаблений; финальный merge — операторский
   гейт, как всегда.

Не входит: правки механики/кода оркестратора; изменение состава
ролей; правки gates/roles/targets/CLAUDE.md/инвариантов; уроки
с единичной фактурой.
