Код `runner.py` не меняется. Боевой пульт запускается с обычным PATH и сохраняет `/usr/bin`; ту же вставку в PATH пульта делать нельзя без отдельного ТЗ с разбором PATH ролей (иначе роль в бою лишится тех же команд).
