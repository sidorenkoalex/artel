## Пути обхода гейтов
- Мандат при записи не шире гейта: обе стороны берут `Profile.in_weakening_scope` из одного `decide(target)`. Принятый мандат гейт засчитает точным вхождением; при `refusal`/`skip` мандат отказывается, а не принимается молча.
- Решение (2) закрыло прежнюю лазейку: у внешнего проекта ячейка со ссылкой `tests/…` (вне области его гейта) больше не снимает требование «ок при условии». Это закреплено в AC-5.
- Случай для сведения, не отклонение: внешний проект без профиля (`skip`) с мандатом зон. Матрица там нужна, а мандат ослабления отказывается требованием 2. Требование 4 буквально ограничено «задачей с профилем проекта», значит здесь остаётся прежнее распознавание `tests/…`. Гейт неослабления у такого проекта не выполняется, поэтому ослабления нет.
- Замечание разработчику, не отклонение SPEC: `_covered` сравнивает с нижним регистром (`_normalized`, `mandate.py:272-275`). Маска профиля с заглавными буквами не совпала бы со ссылкой. У sled маска строчная.
