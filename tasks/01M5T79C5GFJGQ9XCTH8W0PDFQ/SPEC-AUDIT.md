## Вердикт
**concerns.** Шесть пунктов прошлого аудита SPEC закрыл в соответствии с решением Оператора. Остались мелкие пробелы проверяемости, их Оператор может снять строкой на гейте:

1. **AC-4 не требует, чтобы место 1 останавливало процесс по истечении срока.**
   - Сейчас: после `TimeoutExpired` место 1 убивает процесс (`process.kill(); process.communicate()`, `orchestrator/acceptance.py:2951-2952`).
   - Требование 2 называет остановку процесса только для потокового чтения (место 4), а AC-4 у места 1 проверяет только `None`.
   - Правдоподобная мутация: новая функция `gitcmd` на `Popen` возвращает отказ срока без `kill`. Тесты AC-4 зелёные, а процесс git остаётся висеть.
   - Предложение: в AC-4 у места 1 добавить «процесс git остановлен».
2. **AC-7 не называет `cwd` места 1.**
   - Сейчас `cwd=config.ROOT` (`orchestrator/acceptance.py:2945`). При `-C` на результат git он не влияет, но при отсутствующем каталоге `config.ROOT` запуск отказывает `OSError`, а это исход AC-8.
   - Требование 3 («поведение не меняется») это покрывает, перечень AC-7 — нет.
   - Предложение: в AC-7 у места 1 добавить «тот же `cwd`», либо принять как есть.
3. **Уточнение без решения.** Перечень подмен в требовании 4 не называет подмену самого модуля `mock.patch.object(acceptance, "subprocess", fake)` (10 мест, например `tests/test_report_outcome_module.py:1336`, `tests/test_01m52eehsrd93wmphwb5vjyrkd_profile_callers.py:727`). Место 1 после переноса уйдёт из-под неё. По коду исход ни одного такого теста не меняется («Факты против кода»), так что это сведение разработчику, не отклонение.
