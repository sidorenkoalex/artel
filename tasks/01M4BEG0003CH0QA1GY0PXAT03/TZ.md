# ТЗ: канарейка не гоняет полный набор tests/ на приёмке своей задачи

Источник: разбор 07.10 (решение Оператора 07.10: меры 1–3, это мера 3).
Канарейка проверяет конвейер (роли, гейты, переходы), а не код пульта:
код целевого sha уже проверил CI main. Сегодня автогейт приёмки внутри
клона канарейки гоняет полный набор `tests/` (~550–650 с на всех 14 ядрах
машины), а вердикт канарейки от него не зависит: приёмка проходится
синтетически. 07.10 прогон канарейки на 37b20d5c упал по пределу 1500 с,
наложившись на автогейт задачи 01M4AG3QYV (оба по таймауту), а строка
`canary_runs` №130 — `verdict=green`, отказ автогейта лишь записан полем
`autogate_refusal`.

Факты (пин 37b20d5c, сверка 07.10):
- Приёмка канарейки — `orchestrator/canary.py::_pass_acceptance_gate`
  (~1315): переводит задачу в `merge_gate` с пометкой «приёмка пройдена
  автоматически (эквивалент operator approve)» независимо от автогейта.
- Автогейт с полным набором — `orchestrator/fsm_autogate.py` (~306,
  `acceptance.full_suite`), его зовёт цикл ведения задачи в клоне.
- Клон канарейки патчит модульные атрибуты `config` на время блока —
  `orchestrator/canary.py::_ephemeral_clone` (~1086): тем же приёмом
  подменяются пути пульта в клоне.

Требуется:
1. В клоне канарейки автогейт приёмки не гоняет полный набор `tests/`:
   журнал задачи клона получает запись «полный набор пропущен: канарейка
   проверяет конвейер, код целевого sha проверяет CI main» и автогейт
   продолжает так, как при зелёном наборе. Признак «идёт канарейка» —
   решение SPEC (например, атрибут `config`, выставляемый в
   `_ephemeral_clone` тем же приёмом, что пути).
2. Вне канарейки автогейт и `approve` не меняются: признак по умолчанию
   выключен, и обычная задача гоняет набор, как сегодня.
3. Строка `canary_runs` не теряет поле `autogate_refusal` для прочих
   отказов автогейта; пропуск набора отказом не считается.
4. Тесты в `tests/` с заявками «Ловит мутацию»: в клоне (подменённом)
   автогейт не вызывает `acceptance.full_suite` и пишет запись пропуска;
   вне клона вызывает; признак выставляется на время блока клона и
   снимается по выходу из него (в том числе по исключению); вердикт
   канарейки не меняется. Реальная канарейка и реальные роли не
   запускаются. Существующие тесты не ослабляются.

Зоны: orchestrator/canary.py, orchestrator/fsm_autogate.py,
orchestrator/config.py, tests/, docs/codebase-map.md.

Только чтение (не менять): conftest.py, tests/test_invariants.py,
docs/invariants.md, docs/adr/, docs/roadmap.md, docs/backlog.md,
docs/operator-session.md, templates/, skills/, CLAUDE.md, models.yaml,
roles.yaml, targets.yaml, .github/workflows/ci.yml,
orchestrator/acceptance.py, orchestrator/fsm.py.

Не входит: перенос канарейки в CI; изменение вердикта канарейки и
условий сдвига пина; уборка сирот канарейки (задача 01M4AXPY1P).
