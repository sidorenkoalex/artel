# ТЗ: автокоммит артефактов шага учитывает .gitignore (регрессия нового флоу A7 №4)

Источник: инцидент 03.09, задача CR-2 (01M1KCJGN61QT1M0PZKGMVA86Y).
Developer прогнал приёмочные тесты в рабочем каталоге, интерпретатор
создал `tasks/<id>/acceptance_tests/__pycache__/*.pyc`, автокоммит
артефактов шага (`checkpoint._commit_external_step_artifacts`, обход
`task_dir.rglob("*")` без фильтра) занёс их в артефактную ветку
`artifact/<id>`. Лок приёмочных тестов сравнил дерево с зафиксированным
sha, увидел новые файлы и дважды отклонил переход в review — стоп-кран
остановил цикл. Тексты тестов не менялись; отказ ложный. Лечение шло
мостом Оператора (запись без чекаута, журнал). Тот же класс у задачи
«скилы из main» (01M1K7KP0D8ZKRM9KTE75DCCYR): шесть `.pyc` попали в
саму зафиксированную планку.

Легализация по ADR-0013 (частичная поломка — hotfix конвейером,
отдельной задачей; решение Оператора 03.09, вариант A).

Требуется:
1. Автокоммит артефактов шага в артефактную ветку пропускает файлы,
   которые игнорирует `.gitignore` целевого репозитория (пульта):
   критерий — тот же, что у git (`git check-ignore` либо эквивалент
   по правилам корневого `.gitignore`), не самодельный список
   расширений. Как минимум `__pycache__/`, `*.pyc`, `*.log`.
2. Игнорируемые файлы, уже лежащие в артефактной ветке, не
   считаются изменением артефактов: их отсутствие в рабочем каталоге
   не порождает удаления, их наличие — добавления.
3. Сверка лока приёмочных тестов (`fsm_advance`, «лок приёмочных
   тестов») не учитывает игнорируемые файлы внутри
   `acceptance_tests/` — чтобы планка, зафиксированная до этой задачи
   с `.pyc` внутри, не ломалась после уборки.
4. Уборка: игнорируемые файлы удаляются из артефактных веток живых
   задач одним служебным действием (команда `doctor --fix` либо
   отдельная команда пульта — выбор аналитика), с записью в журнал
   задачи; main не трогается.
5. Тесты: автокоммит не заносит `__pycache__/*.pyc` из каталога
   задачи; лок не отклоняет переход, когда разница с зафиксированным
   деревом — только игнорируемые файлы; уборка убирает `.pyc` из
   артефактной ветки и журналирует; существующие тесты (в том числе
   планка A7, 44 теста, и планка hotfix 01M1KT0792125J9ZNJNZJ86E9Q)
   зелёные без ослабления.

Зоны: orchestrator/checkpoint.py, orchestrator/artifact_branch.py,
orchestrator/fsm_advance.py (сверка лока), orchestrator/doctor.py
(уборка), tests/. Конфликт зон с hotfix 01M1KT0792125J9ZNJNZJ86E9Q
(checkpoint.py, требование 4 hotfix — перенос удалений): стартовать
после его мержа; до мержа — только SPEC.

Не входит: изменение механики лока (инвариант 27) и планки;
перевод других команд на источник артефактов (hotfix); пересмотр
списка `.gitignore` пульта.
