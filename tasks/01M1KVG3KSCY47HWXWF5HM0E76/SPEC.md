# SPEC: Автокоммит артефактов шага учитывает .gitignore

## Контекст
Инцидент 03.09 (задача CR-2, 01M1KCJGN61QT1M0PZKGMVA86Y): developer
прогнал приёмочные тесты в рабочем каталоге, интерпретатор создал
`tasks/<id>/acceptance_tests/__pycache__/*.pyc`, автокоммит артефактов
шага (`checkpoint._commit_external_step_artifacts`, обход
`task_dir.rglob("*")` без фильтра) занёс их в артефактную ветку
`artifact/<id>`. Лок приёмочных тестов сравнил дерево с зафиксированным
sha, увидел новые файлы и дважды ложно отклонил переход в review — тексты
тестов не менялись. Тот же класс — у задачи «скилы из main»
(01M1K7KP0D8ZKRM9KTE75DCCYR): шесть `.pyc` попали в саму зафиксированную
планку. Легализация по ADR-0013 (частичная поломка — hotfix конвейером,
решение Оператора 03.09, вариант A).

## Требования
1. Автокоммит артефактов шага в артефактную ветку (`checkpoint.
   _commit_external_step_artifacts`) пропускает файлы, которые
   игнорирует `.gitignore` целевого репозитория (пульта): критерий —
   тот же, что у git (`git check-ignore` либо эквивалент по правилам
   корневого `.gitignore`), не самодельный список расширений. Как
   минимум `__pycache__/`, `*.pyc`, `*.log` не попадают в артефактную
   ветку.
2. Игнорируемые файлы, уже лежащие в артефактной ветке (например,
   зафиксированные до этой задачи), не считаются изменением артефактов
   автокоммитом: их отсутствие в рабочем каталоге задачи не порождает
   удаления записи из артефактной ветки, их наличие в рабочем каталоге
   не порождает добавления записи.
3. Сверка лока приёмочных тестов (`fsm_advance`, переход `in_dev` ->
   `review`) не учитывает внутри `acceptance_tests/` файлы, которые
   игнорирует `.gitignore` пульта — разница с зафиксированным деревом
   только по таким файлам не отклоняет переход.
4. Уборка: игнорируемые файлы удаляются из артефактных веток живых
   задач одним служебным действием — командой `artel doctor --fix`;
   `main` не затрагивается; выполнение действия оставляет запись в
   журнале каждой затронутой задачи (`store.journal`).

## Критерии приёмки
AC-1. Автокоммит артефактов шага не включает в коммит файлы, которые
`.gitignore` пульта считает игнорируемыми (эквивалент `git
check-ignore`, не список расширений).

AC-2. Автокоммит артефактов шага не заносит `__pycache__/*.pyc` из
каталога задачи (`tasks/<id>/`) в артефактную ветку.

AC-3. Игнорируемый файл, уже находящийся в артефактной ветке, при
последующих автокоммитах не порождает удаления записи, если файл
отсутствует в рабочем каталоге задачи, и не порождает добавления
записи, если файл присутствует в рабочем каталоге задачи.

AC-4. Сверка лока приёмочных тестов не отклоняет переход `in_dev` ->
`review`, когда единственная разница между рабочим деревом
`acceptance_tests/` и зафиксированным sha — игнорируемые файлы
(например, ранее занесённые `.pyc`).

AC-5. Существует команда пульта `artel doctor --fix`, которая убирает
игнорируемые файлы из артефактных веток живых задач и оставляет запись
в журнале (`store.journal`) каждой затронутой задачи; `main` этой
командой не изменяется.

AC-6. Планка A7 (44 приёмочных теста) и планка hotfix
01M1KT0792125J9ZNJNZJ86E9Q остаются зелёными без ослабления
существующих проверок.

## Не входит
- Изменение механики лока приёмочных тестов (инвариант 27) и самой
  планки — только учёт игнорируемых файлов в сверке.
- Перевод других команд пульта на источник артефактов (это зона
  hotfix'а, не этой задачи).
- Пересмотр списка `.gitignore` пульта.
