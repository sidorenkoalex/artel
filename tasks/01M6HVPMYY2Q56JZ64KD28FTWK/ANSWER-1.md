2. Аварийный выход: перезапуск не раньше следующего опроса (пауза — не меньше `EPIC_POLL_SEC`); после трёх аварийных выходов подряд — остановка, тревога `attention` и запись журнала с причиной. 4. Надзор открытого эпика не завершается сам, когда все задачи окончательны; завершение — `epic stop` или `epic close`. Самозавершение «оставшиеся задачи заблокированы без решения Оператора» сохраняется и для открытого эпика (тесты ac28, ac29, ac30 по этим случаям без правки).
