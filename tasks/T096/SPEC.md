# SPEC: П4: design-system + скил ui-standards

## Контекст
Роадмап §3 «Панель», этап 1, строка П4 ($25, «до первых UI-задач»).
Фактура стиля пульта уже существует раздельно и с расхождениями:
утверждённый макет `tasks/T080/mockup.html` и живой
`orchestrator/report.py` (T092). П4 систематизирует её в переиспользуемый
стандарт `docs/design-system.md` и новый скил `skills/ui-standards.md`
для будущих UI-задач (доработки report, панель Г0+).

## Требования

1. `docs/design-system.md` — компактный стандарт UI-поверхностей пульта:
   палитра (включая тёмную/светлую тему, только если её несёт хотя бы
   один из источников), типографика, раскладка борда/карточек/блоков,
   состояния FSM и их цветовое кодирование, принципы (самодостаточный
   HTML, без JS-фреймворков и сборки, без внешних ресурсов). Источник —
   РЕАЛЬНЫЕ `tasks/T080/mockup.html` и `orchestrator/report.py`, не
   изобретение с нуля; расхождения между ними — выявлены, для каждого
   предложена норма.
2. Новый скил `skills/ui-standards.md` — инструкция роли для будущих
   UI-задач: читает `docs/design-system.md`, несёт правила
   самодостаточности, запреты (CDN, сборка, демоны в этапе 1), чек
   «открывается file:// без сети».
3. Мандат на защищённый путь: `skills/ui-standards.md` — новый файл в
   no_paths-каталоге `skills/`; мандат выдаётся Оператором на spec_gate
   по механике T093, ограничен ровно этим одним файлом. Существующие
   скилы диффом не меняются.
4. `orchestrator/report.py` приводится к зафиксированному в
   `docs/design-system.md` стандарту ТОЛЬКО если расхождение —
   косметическое и локальное (класс «цвет/отступ»); расхождение,
   требующее структурного изменения report.py, диффом не устраняется —
   вне объёма, отдельная задача.

## Критерии приёмки

AC-1. `docs/design-system.md` существует и документирует: палитру
(цветовые токены), типографику, раскладку борда/карточек/панелей,
состояния FSM с их цветовым кодированием, принципы самодостаточности
(без JS-фреймворков, без шага сборки, без внешних ресурсов/CDN).

AC-2. `docs/design-system.md` явно ссылается на `tasks/T080/mockup.html`
и `orchestrator/report.py` как источники и содержит раздел с
выявленными расхождениями между ними — минимум расхождение по
цветовому кодированию состояний борда (в `mockup.html` колонки/карточки
несут цвет по состоянию через `--ok`/`--warn`/`--danger`/`--killed`
и классы `.col.done`/`.col.killed`/`.col.escalated`/`.col.in_dev`/
`.col.merge_gate`/`.col.review`; в `orchestrator/report.py` таких
токенов и классов нет) — с предложенной нормой для каждого выявленного
расхождения.

AC-3. Если ни `tasks/T080/mockup.html`, ни `orchestrator/report.py` не
несут тёмной темы (медиа-запрос `prefers-color-scheme` или аналог) —
`docs/design-system.md` фиксирует это явно как текущую границу
стандарта (светлая тема), а не домысливает тёмную тему.

AC-4. `skills/ui-standards.md` создан (новый файл) и содержит: указание
читать `docs/design-system.md`, правила самодостаточности (запрет CDN,
запрет шага сборки, запрет демонов на этапе 1), явный чек «страница
открывается напрямую как file:// без сети».

AC-5. Diff задачи не меняет ни один существующий файл каталога
`skills/`, кроме создания нового `skills/ui-standards.md`.

AC-6. Diff задачи не затрагивает `tasks/T080/mockup.html` (исторический
артефакт остаётся неизменным).

AC-7. Любые правки `orchestrator/report.py` в диффе (если есть)
ограничены классом «цвет/отступ» — значениями CSS-токенов, цветов,
паддингов и размеров шрифта внутри существующих правил `_STYLE`; ни
одна функция рендера, HTML-структура, добавленный или удалённый
CSS-класс/селектор не меняется. Расхождение, требующее такого
структурного изменения, в `orchestrator/report.py` не применяется —
только описано в `docs/design-system.md` как задача вне объёма.

AC-8. Diff задачи не создаёт новых UI-поверхностей и не касается
демона/панели этапа 2.

## Не входит

- демон/панель этапа 2;
- правки макета `tasks/T080/mockup.html` (исторический артефакт);
- новые UI-поверхности;
- структурные изменения `orchestrator/report.py` (только отдельной
  задачей);
- правки любых файлов `skills/`, кроме создания нового
  `skills/ui-standards.md`.
