## Пути обхода гейтов
- Тест AC-5 ищет подстроки «ручн», «автогейт», имена гейтов — шапка вида
  «acceptance — ручной, автогейт выключен; spec_gate, merge_gate …
  gates.yaml» прошла бы тест при неверном факте. Смысловую часть держит
  AC-2 (ревью/планка), форма теста задана ТЗ дословно — не отклонение
  SPEC, замечание для ревью.
- Блок «Команды:» — последняя строка `[--interval SEC] [--until <state>]`
  без хвостового « |». Дописав новые команды в конец блока, исполнитель
  вынужден изменить эту строку, что нарушит AC-1 («прежние строки без
  изменений») — вставлять нужно в середину. Не дефект SPEC (требование
  однозначно), а ловушка для разработчика.
- Прямой тест (AC-3) удовлетворяется голыми словами без форм; формы
  держит AC-1, его должна проверять планка, не только тест AC-3.
