# SPEC: Один разбор строки зон с учётом переноса строки внутри пути

## Контекст
Разные потребители строки зон по-разному обрабатывают перенос внутри
пути. Из-за этого путь, разорванный после `/`, `_` или `-`, превращается
в обрывок, а число зон зависит от вёрстки ТЗ. Разбор должен нормализовать
такой перенос в общем месте, сохранив прежнее поведение для остальных
строк.

## Требования

1. `scripts/guard.py::zone_items` склеивает перенос внутри пути после
   `/`, `_` или `-`, если следующая строка имеет отступ, по правилу
   `_TZ_WRAPPED_PATH_BREAK`.
2. `orchestrator/budget.py::count_zone_paths` использует тот же разбор
   строки зон: перенос внутри пути не меняет число зон; кандидаты
   упоминаний путей не включаются в счёт, а поведение строк без переноса
   не меняется.
3. `orchestrator/catalog.py` не изменяется: его предварительная склейка
   остаётся идемпотентной при уже склеенной строке.
4. Добавляются тесты равенства результатов для строки с переносом и без
   него, отсутствия склейки переноса после слова прозы и сохранения
   прежнего результата строки без переноса; указанные в ТЗ существующие
   тесты остаются зелёными и не ослабляются.

## Критерии приёмки

AC-1. `guard.zone_items` для строки зон склеивает путь, разорванный
переносом после `/`, `_` или `-` с отступом следующей строки, и возвращает
тот же набор элементов, что для идентичной строки без переноса.

AC-2. `budget.count_zone_paths` для ТЗ с переносом внутри пути возвращает
то же число зон, что для того же ТЗ без переноса; кандидаты упоминаний
путей не входят в это число, а результат строк без переноса не меняется.

AC-3. `orchestrator/catalog.py` не изменён; его предварительная склейка
на уже склеенной строке не изменяет результат.

AC-4. Тесты покрывают перенос внутри пути, перенос после слова прозы без
склейки и строку без переноса; `tests/test_guard_zones.py`,
`tests/test_guard_path_mentions.py`, `tests/test_catalog_tz_path_check.py`,
`tests/test_catalog_zone_overlap.py`, `tests/test_spec_budget.py` и
`tests/test_budget_calibration_table.py` проходят без ослабления.

## Оценка объёма и деление

Сработал сигнал: зона затрагивает инвариантный механизм разбора путей.
Прогноз диффа: 6 КиБ.

Обоснование монолита: склейка в общем разборе и подсчёт зон должны
смениться вместе, иначе разные потребители одной строки будут давать
разные результаты. Без тестов этой общей семантики нельзя подтвердить
сохранение прежнего поведения; поэтому ни одна из трёх зон не образует
самостоятельно мержимой части с зелёной планкой.
