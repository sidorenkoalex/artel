# ТЗ К-4б: Карточки знаний — команда `knowledge` для роли, журнал обращений, подсказка в миссии

Источник: решение Оператора 12.10.2026 — план обогащения ролей знаниями,
задача 4 из 4, часть Б (часть А — формат, хранение, проверка формы и
`doc-commit` карточек, К-4а). Суть: роль во время шага спрашивает
`knowledge <id> <путь или символ>` и получает короткие карточки о
ловушках и правилах этого места; каждое обращение пишется в журнал; в

п. 3з (проектный слой — данные, проект не ослабляет роль), п. 3е (хэши
знаний, вошедших в шаг, — в журнал), п. 14;
`docs/research/2026-09-22-chatgpt-agent-integration.md`, «Итог обсуждения
(27.09.2026)», § 5 (в бриф — перечень, не содержимое; свежесть считает
код).

   прочитаны: <код причины>», другой вид выдаётся; код возврата при таком
   отказе ненулевой. «Файл не заведён» и «нет поля» — строкой, не отказ.

7. Пометка «возможно устарела»: для элемента `where` формы `p::s` код
   проверяет, что файл `p` есть и символ `s` в нём есть: у системных
   карточек — в дереве пульта (для задач проекта `config.DEFAULT_TARGET`

   же `ls-tree`, что в К-4а п. 4; размер сверяется до чтения командой
   `git cat-file -s`); у проектных — в рабочей
   копии задачи. Рабочей копии нет (каталог не существует, в том числе

   нет». Читается только обычный файл (не ссылка и не специальный файл)
   не больше `config.KNOWLEDGE_CARD_STALE_FILE_MAX_BYTES`; файл
   разбирается один раз за вызов. Для `.py` — `ast.parse` (ловит
   `SyntaxError`, `ValueError`, `RecursionError`, `MemoryError` → «свежесть
   не проверена: <класс причины>»); учитываются `def`, `async def`,
   `class`, `Assign`, `AnnAssign`, `AugAssign` верхнего уровня, в том
   числе внутри верхнеуровневых `if`/`try`; `Class.method` — вложенно.
   Для прочих файлов — поиск последнего сегмента символа как отдельного
   слова. Код проекта не импортируется и не исполняется. Нет файла или
   символа — «возможно устарела: <что не найдено>»; пометка не скрывает
   карточку. Путь файла сверяется после `resolve()` внутри рабочей копии
   задачи (ссылка на каталог внутри пути отвергается, не только ссылка на
   сам файл); `ast.parse` идёт под `warnings.catch_warnings()` с
   подавлением `SyntaxWarning` — вывод команды ими не засоряется; пометки
   «возможно устарела» проектных карточек выводятся внутри блока границы.

Матрица неослабления:
- Белый список команд роли расширяется одной командой. Она не меняет
  состояние задачи, lease, ветки, рабочие копии и файлы карточек, но
  первой из команд роли пишет в журнал — одну запись своего действия со
  своим постоянным автором, которому не доверяет ни один читатель
  журнала. Закрытость списка по умолчанию не меняется.
- Сверка `<id>` с `ARTEL_TASK` защищает от ошибочного вызова, но не
  граница: роль и без неё читает `show` любой задачи и файлы каталога
  знаний; роль, сменившая `ARTEL_TASK`, пишет запись обращения в журнал
  чужой задачи — в пределе, постоянным автором, без влияния на гейты.
- Предел записей на задачу действует и на досыл очереди: роль на Codex
  через очередь не пишет больше предела.
- `canary.py:1484–1520` и `doctor/leases.py:103` читают последнюю запись
  журнала: запись обращения может сократить короткое замыкание ожидания
  канарейки и попасть в строку `doctor`; решений гейтов это не меняет.
- Гейт `tests_writing` получает исключение пары «новый автор + действие
  обращения» — того же рода, что уже есть у `lease`; отказ по отброшенным файлам после этого не
  снимается поздней записью — строже, чем без исключения.
- Очередь отложенного журнала расширяется одним действием со своим
  автором; правило досыла не меняется. Роль на Codex и сейчас может
  положить в очередь файл о любой задаче; новое действие этот риск не
  расширяет до доверенного автора.
- Проектные карточки приходят роли внутри границы недоверенных данных,
  как бриф; системные — с защищённого пути, как скилы; причины отказа в
  промпте — фиксированные коды без цитат.
- Код проекта при проверке свежести не исполняется (только `ast` и
  чтение текста).
- Промпт роли растёт на одну строку (не больше предела ключей), вывод
  команды ограничен пределом карточек — цена, не ослабление.

Оценка объёма: сигнал «зоны» срабатывает (7 путей); деление на формат
