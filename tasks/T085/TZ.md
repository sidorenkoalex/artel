# ТЗ: Исполнение ADR-0010 — стоп-лосс из автогейта в отчётную веху

Источник и мандат: docs/adr/0010-stop-loss-as-milestone.md (принят
Оператором 31.08); фактура — аудит v6, находка MJ-2
(docs/audits/roadmap-audit-2026-08-31-v6-complex.md).

Требуется:

1. Удалить условие «пороги расхода программы (A1) не пробиты»
   из состава автогейта acceptance (реализация T066 — orchestrator/
   gates.py / fsm.py, место по коду). Остальные условия автогейта
   не трогать.
2. Алерты программных порогов (PROGRAM_ALERT_RATIOS): деградировать
   в информационные — событие журнала и строка в doctor/status
   остаются, kind без ack-обязательств; участие в каких-либо
   автоматических решениях исключить.
3. Комментарии config.py (PROGRAM_STOP_LOSS_USD, PROGRAM_ALERT_RATIOS)
   привести к семантике ADR-0010 («отчётная веха»).
4. Тесты условий автогейта (кодирующие состав условий T066) обновить
   под новый состав — мандат ADR-0010: это санкционированное
   Оператором изменение состава условий гейта, не ослабление.
   Тесты информационных алертов — сохранить/обновить.
5. Учёт не трогать: total_spent, стоимости RETRO, пересев (T049) —
   без изменений.

Не входит: потолки задач и их эскалации (инвариант 5); kill-switch
gates.yaml; любые другие условия автогейта; docs/roadmap.md §5
(правку экономической рамки Оператор внесёт сам).

Рамка: $15.
