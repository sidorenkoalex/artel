# ТЗ: RETRO: полное первое предложение сути, killed — из ТЗ

## Контекст

Строка P3 роадмапа «Качество RETRO-экстракта „Суть“». Аудит 27.08:
у done-задач Фазы 0 суть — названия-пустышки, у killed — шаблонная
заглушка SPEC, у T042 — обрезка на запятой; экстрактор первой строки
контекста наивен.

## Решение (Оператор 28.08)

Улучшить детерминированное извлечение «Сути» в RETRO (orchestrator/
retro.py): полное первое предложение контекста SPEC (до точки, не до
запятой/переноса), для killed-задач — суть из ТЗ (TZ.md), если оно
есть, иначе прежний фолбэк. Извлечение остаётся детерминированным
кодом — никакого LLM (решения 26.08 по RETRO).

## Границы

- orchestrator/retro.py и тесты, карта.
- Формат RETRO-файла и его адресация (merge-sha:путь) не меняются.
- Существующие RETRO в docs/retro/ не переписываются задним числом.

## Не входит

- LLM-суммаризация.
- Изменение структуры/шаблона RETRO.

## Приёмка (минимум)

- Суть done-задачи — полное первое предложение контекста SPEC
  (обрезка по границе предложения, не по запятой).
- Суть killed-задачи с TZ.md — первое предложение ТЗ; без TZ.md —
  прежний фолбэк.
- Существующие тесты зелёные; docs/retro/ не тронут.
