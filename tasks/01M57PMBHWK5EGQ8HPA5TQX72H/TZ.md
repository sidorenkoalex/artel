# Несколько проектов: проект в report и алерты пульта в наблюдении внешнего проекта

## Факты

Строка бэклога из разбора 18.10 «что прибито под артель». Одно наблюдение на задачи с явным проектом сделано (01M563E1SH, смержено); `status` уже помечает задачу внешнего проекта (`[sled]`).

- `report` не показывает проект задачи (`orchestrator/report.py:544`): в сводке задачи артели и sled неразличимы.
- Алерты уровня пульта (без задачи или без проекта: триггеры `docs/triggers.md`, сигналы doctor) видны только наблюдению артели (`orchestrator/watch.py:299`); дозор наблюдения внешнего проекта их не показывает, и Оператор, ведущий задачу sled, о них не узнаёт.

## Требуется

1. `report` (сводка и построчный вывод) показывает проект каждой задачи так же, как `status` (метка `[<проект>]` у внешнего проекта; у артели — прежний вид без метки). Итоги по стоимости и числам — с разбивкой по проекту, если в выборке больше одного проекта; при одном проекте вывод прежний.
2. Алерты уровня пульта (не привязанные к задаче или к проекту) доставляются дозору любого активного наблюдения, с тем же правилом «оповещено» (каждое наблюдение отмечает свою позицию), без повторной доставки одному наблюдению.
3. Аналитик сверяет по коду, какие ещё выводы `status`/`report`/`watch` смешивают проекты (минуты очереди, потолки, триггеры с полем проекта); найденное в зонах — в требования, вне зон — эскалация до SPEC.
4. У артели тексты `status`, `report` и `watch` прежние — зафиксировать тестами до правки.
5. Тесты детерминированы, без сети: задачи артели и учебного внешнего проекта в одной БД; два наблюдения.

Критерии приёмки:
- `report` различает задачи двух проектов, при одном проекте вывод прежний;
- алерт уровня пульта виден дозорам обоих наблюдений, каждому — один раз;
- у артели тексты прежние.

Зоны: `orchestrator/report.py`, `orchestrator/watch.py`, `orchestrator/catalog.py`, `tests/`.

Только чтение: `orchestrator/artel.py`, `orchestrator/alerts.py`, `orchestrator/store.py`, `docs/triggers.md`, `docs/backlog.md`. Правка вне зон — эскалация до SPEC.

Не входит: автоподбор наблюдения без флага; мьютекс мержа по проекту (отдельная задача).

Рамка: $25. Набор моделей — по умолчанию.
