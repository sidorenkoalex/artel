# ТЗ: команда `note` — строка в копилку/бэклог изолированным коммитом от origin/main

Источник: аудит обходных сценариев Оператора 06.09. Правило проекта
(CLAUDE.md, `docs/operator-session.md`, решение 06.09): аномалия
фиксируется в `docs/backlog.md` сразу, изолированным коммитом с push.
Главная копия пульта стоит на пине (ADR-0013), коммитить документы из
неё нельзя, поэтому каждая запись — 40 строк оболочки: `git worktree
add --detach <scratch> origin/main`, правка python-сценарием (вставка
строки после разделителя таблицы нужного раздела), коммит, push с
повторами, уборка worktree; при сетевом сбое коммит удерживается в
worktree и пушится повтором. За 06.09 — 12 таких заходов, два с
осложнениями (сеть, потеря коммита при уборке worktree). Вторая
сессия делает то же руками. Класс — «тихий сценарий вместо команды
пульта» (правило 06.09).

Требуется:
1. `artel.py note (копилка|бэклог|очередь) --text "<строка таблицы без
   внешних |>" [--task <id>]` (имена разделов — как заголовки
   `docs/backlog.md`): берёт `origin/main` (fetch), в эфемерном
   worktree/клоне вставляет строку первой после разделителя таблицы
   раздела (текущая конвенция: новые строки сверху), проверяет число
   колонок против шапки таблицы (5 у копилки, 6 у бэклога — иначе
   отказ с указанием ожидаемых колонок), коммитит с сообщением
   `оператор: <раздел> — <первые 80 символов текста>` и пушит в
   `origin/main`; при non-fast-forward — повтор с новым fetch (до 3
   раз); при сетевом отказе — коммит остаётся в `.artel/notes-pending/`
   (или локальной ветке `notes-pending`), `doctor` предупреждает о
   неотправленных заметках, повторный `note` (или `note --flush`)
   допушивает. HEAD главной копии не трогается (пин).
2. `note --append <подстрока-ключ> --text "…"`: дописать текст в
   последнюю колонку существующей строки, найденной по подстроке
   (случай «второй вид/повтор аномалии» — 06.09 дважды).
3. Журнал пульта (без task_id, actor `operator`): «заметка: <раздел>
   <sha>» — чтобы `report` считал частоту аномалий.
4. Тесты: (а) в песочнице с локальным origin `note` создаёт коммит
   только с `docs/backlog.md`, строка на месте, число колонок сверено
   (мутация: отказ на 4 колонках снят — красный); (б) HEAD песочницы
   «главной копии» не изменился; (в) отказ сети — коммит удержан,
   `doctor` warn, `--flush` допушивает; (г) `--append` меняет одну
   строку; (д) существующие `tests/test_doctor.py` и тесты CLI зелёные.
5. `docs/operator-session.md` (приложением): правило «копилка сразу»
   исполняется командой `note`, сценарии со scratch-worktree снимаются.

Зоны: orchestrator/artel.py, orchestrator/notes.py (новый),
orchestrator/gitcmd.py, orchestrator/doctor.py,
docs/operator-session.md, tests/.
Порядок: после мержа разреза `doctor.py` (01M1TT9BPB) — зона
`doctor.py`; сверить по `status`.

Не входит: правка роадмапа и ADR (остаются ручными документными
коммитами); автоматическое сведение дублей копилки (скил ревизии).
