## Пути обхода гейтов
- **О-2.** AC-11 держит только `sqlite3.connect` по атрибуту модуля. Чтение
  `store.db().execute(...)` своим SELECT мимо `store.all_canary_runs`
  (требование 5: «строки — `store.all_canary_runs(store.db())`») проходит все
  AC; поведенчески разница — пропуск ленивого заведения (`набор=—` для
  `NULL` станет достижим). Ловится ревью, не тестом.
- **О-3.** AC-12 с подменой `subprocess.Popen` автор тестов может «починить»
  на холодной БД, подменив Popen позже вызова `store.db()` внутри команды —
  тогда критерий перестаёт проверять подпроцессы `cmd_canary_runs`. Нужен
  прогрев БД до подмены, не поздняя подмена (Ф-2).
