# ТЗ: Тестовая подметалка — уборка git-песочниц и изоляция от реального git

Источник: роадмап P3, две строки одной задачей: «Флейк уборки
песочниц git на раннере CI» и «Изоляция песочниц от реального
git — донести до путей T047».

Часть 1 — флейк уборки (фактура 26.08, ран post-merge T038):
`test_git_fixation` (ExternalApproveDoesNotCommitOthersWorkInProgress,
ExternalTransitionCommits) — `OSError: [Errno 39] Directory not
empty: '.git'` в `TemporaryDirectory.cleanup()`: сценарии прошли,
упала уборка. Локально не воспроизводится — среда раннера. Красит
main ПОСЛЕ мержа. Фикс: устойчивая уборка git-песочниц
(ignore_errors/повтор/chmod) в общей песочнице tests/sandbox.py
(T037) — одним местом на все копии.

Часть 2 — изоляция от реального git (фактура 28.08, приёмка T048):
`test_spec_budget.SpecBudgetOnTheGateTest` и родственные классы без
fake_git после T047 зовут реальный git пульта из песочницы: на CI
(detached HEAD) зелено, в живой копии с ветками задач — 16 ложных
падений полного набора. Фикс: перевести эти классы на общий
sandbox/fake_git (T037) — принцип «чини класс, не экземпляр».

Критерий приёмки обеих частей: полный набор tests/ зелен в копии
с произвольными ветками/worktree и не зависит от реального git
пульта; поведение боевого кода не меняется (только tests/).

Границы: строго tests/; orchestrator/ и scripts/ не трогать.
Оценка рамки: $15+$15 (роадмап, две строки).
