# SPEC: Тестовая подметалка: уборка git-песочниц и изоляция от реального git

## Контекст
Роадмап P3 сводит в одну задачу две строки одного класса «песочница
тестов ведёт себя не по прописанному»:

- флейк уборки (фактура 26.08, ран post-merge T038): `test_git_fixation`
  (`ExternalApproveDoesNotCommitOthersWorkInProgressTest`,
  `ExternalTransitionCommitsTest`) — `OSError: [Errno 39] Directory not
  empty: '.git'` на `TemporaryDirectory.cleanup()`: сценарии проходят,
  падает только уборка, локально не воспроизводится — особенность
  раннера CI. Красит `main` уже ПОСЛЕ мержа;
- изоляция от реального git (фактура 28.08, приёмка T048):
  `test_spec_budget.SpecBudgetOnTheGateTest` и родственные классы того же
  дефекта — без `fake_git` после T047 зовут реальный git пульта из
  песочницы: на CI (detached HEAD) зелено, на живой копии с ветками
  задач — 16 ложных падений полного набора.

## Требования
1. Уборка временных git-песочниц в общей песочнице `tests/sandbox.py`
   (T037) сделана устойчивой к `OSError: [Errno 39] Directory not empty`
   при удалении `.git` (например `ignore_errors`/повтор/`chmod`) — одним
   местом на все копии, не по отдельным тестовым файлам.
2. Тестовые классы, которые после T047 зовут реальный git пульта из
   песочницы без `fake_git` (пример: `tests/test_spec_budget.py::
   SpecBudgetOnTheGateTest` и родственные ей классы того же дефекта),
   переведены на общий `sandbox`/`fake_git` (T037) — «чини класс, не
   экземпляр».
3. Полный набор `tests/` зелёный при прогоне в копии с произвольными
   ветками/worktree и не зависит от состояния реального git пульта.
4. Поведение боевого кода не меняется — правки только в `tests/`.

## Критерии приёмки
AC-1. Уборка временных git-песочниц с настоящим git (`TemporaryDirectory.
cleanup()`) в общей песочнице `tests/sandbox.py` устойчива к `OSError:
[Errno 39] Directory not empty` (`ignore_errors`/повтор/`chmod`) —
правка в одном общем месте, не дублируется по копиям тестовых файлов.

AC-2. Тестовые классы, которые после T047 зовут реальный git пульта из
песочницы без `fake_git` (пример: `tests/test_spec_budget.py::
SpecBudgetOnTheGateTest` и родственные ей классы того же дефекта),
переведены на общий `sandbox`/`fake_git` (T037) и больше не обращаются
к реальному git пульта.

AC-3. Полный набор `tests/` зелёный при прогоне в копии репозитория с
произвольными ветками/worktree и не зависит от состояния реального git
пульта.

AC-4. Поведение боевого кода (`orchestrator/`, `scripts/`) не изменено —
правки задачи ограничены `tests/`.

## Не входит
- Правки `orchestrator/` и `scripts/` — граница ТЗ «строго tests/».
- Любые изменения поведения боевого кода.
