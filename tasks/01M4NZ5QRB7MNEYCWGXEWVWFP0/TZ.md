# ТЗ: answer и zones-extend отказывают мандату без матрицы неослабления (ADR-0022 п.4)

Источник: строка бэклога 11.10 «answer: мандат без матрицы неослабления —
отказ» (приоритет 2); ADR-0022 п.4 и план исполнения п.3
(`docs/adr/0022-handoff-audit.md`); канон матрицы —
`docs/operator-gates.md`, раздел «Матрица неослабления» (решение Оператора
11.10.2026); решение Оператора 11.10.2026 — заводить в волне.

Прецедент: 01M4M67SGNEYMN9F1C7XVX24XE — первая рекомендация мандата на
удаление трёх тестов пропустила пять свойств, оставшихся без покрытия;
независимая проверка их нашла. Правило держится только дисциплиной
сессии, механикой не проверяется.

Факты (origin/main 172d9919, сверка 11.10):
- `orchestrator/answer.py::_cmd_answer` (~230) принимает файл ответа;
  строки мандатов разбирает `orchestrator/advance_gates/mandate.py`
  (`TEST_WEAKENING_MANDATE_MARKER` «Ослабление тестов разрешено:»,
  маркер зон `fsm_advance._ZONES_MANDATE_MARKER` «Расширение зон
  разрешено:», `MERGE_AFTER_MANDATE_MARKER` «Зависимости мержа:»);
  негодная строка мандата — отказ `_read_checked_answer_file` (~102–120).
- `answer.cmd_zones_extend` (~342) сам собирает ANSWER с мандатом зон
  из списка путей, без файла Оператора.
- Канон матрицы: таблица `| Что меняется | Какое свойство сейчас держит
  (…файл:строка) | Остаётся ли свойство после изменения | Чем покрыто
  после (тест файл:строка) или «не покрыто» | Решение |`; строка
  «остаётся, не покрыто» → решение «ок при условии» с перечнем
  замен; изменения тестов/гейтов/лимитов/мандатов перепроверяет
  независимый проверяющий.

Требуется:
1. `answer` отказывает файлу, где есть строка мандата «Ослабление тестов
   разрешено:» или «Расширение зон разрешено:», если в файле нет раздела
   `## Матрица неослабления` с таблицей канонических пяти столбцов (по
   заголовкам) и хотя бы одной строкой данных. «Зависимости мержа:» и
   указание без мандатов — без изменений.
2. Каждый элемент мандата (метод теста; путь зоны) назван хотя бы в
   одной строке таблицы в столбце «Что меняется» — иначе отказ с
   перечнем неназванных элементов.
3. Строка, где «Остаётся ли» — да/остаётся, а «Чем покрыто» — «не
   покрыто» (без ссылки на тест), обязана иметь в «Решение» «ок при
   условии» и непустой перечень замен; иначе отказ с номером строки.
4. Для мандата «Ослабление тестов разрешено:» в файле есть строка
   `Независимая проверка: <вердикт>` (непустой вердикт) — иначе отказ.
   Для мандата зон — не требуется.
5. `zones-extend` принимает файл матрицы (`--matrix <файл>`) и без него
   отказывает; раздел и проверки 1–3 — те же; матрица попадает в
   созданный ANSWER.
6. Отказ — до записи ANSWER и до коммита в ссылку документов; текст
   отказа называет, чего не хватает, и ссылается на
   `docs/operator-gates.md` «Матрица неослабления».
7. Проверка формы — одна функция, общая для `answer` и `zones-extend`;
   содержание матрицы (верность свойств) не проверяется механикой.
8. Ослабления нет: существующие проверки строк мандатов
   (`mandate.refusals`, запрет мандата из окружения роли и автокоммита
   роли, инвариант 38) не меняются; добавляются только отказы.

Критерии приёмки (направление; планку пишет test_author):
- Мандат тестов без раздела матрицы — отказ, ANSWER не создан, ссылка
  документов не сдвинута; с полной матрицей и строкой независимой
  проверки — проход как сегодня.
- Элемент мандата не назван в таблице — отказ с его именем.
- «не покрыто» без «ок при условии» и замен — отказ с номером строки.
- Мандат тестов без «Независимая проверка:» — отказ; мандат зон без
  неё — проход.
- `zones-extend` без `--matrix` — отказ; с файлом — ANSWER несёт
  матрицу.
- Указание без мандатов и «Зависимости мержа:» — поведение прежнее.
- Мутация «проверка матрицы отключена» ловится.
