# ТЗ: ложный инцидент целостности при отклонённом advance

## Контекст

Роадмап, P3-строка «Ложный инцидент целостности при отклонённом
advance». Фактура (двойная, 29–30.08): T069 и T073 — sha фиксируется
на входе в состояние (`tests_writing`); роль легитимно коммитит свои
артефакты внутри шага (приёмочные тесты); guard отклоняет переход
(маркеры красноты T064) → advance сравнивает голову ветки с фиксацией
входа и эскалирует «инцидент целостности: sha разошёлся», хотя
единственные новые коммиты — собственные коммиты роли её же шага.
Успешный переход перефиксировал бы sha сам; отклонённый оставляет
старую фиксацию против сдвинутой головы. Каждый случай — ручной
разбор Оператора и approve по новому sha на ровном месте.

## Что нужно

На пути отклонённого перехода (guard/условие не пройдено) сверка
целостности не должна эскалировать, если ВСЕ новые коммиты между
зафиксированным и текущим sha порождены шагом задачи — проверяемо
по журналу задачи (agent run started/finished окна шага) и/или
принадлежности коммитов ветке задачи с момента фиксации. В этом
случае фиксация обновляется на текущую голову (с журнальной записью
«sha перефиксирован после отклонённого перехода: коммиты шага»),
задача остаётся в текущем состоянии с причиной отказа guard —
как и сейчас, но без эскалации.

Эскалация «инцидент целостности» сохраняется для действительно
посторонних изменений: коммиты вне окна шага, чужое авторство вне
механики ролей/оркестратора, грязное дерево (класс «грязная копия» —
не трогать, он отдельный и легитимный).

## Границы

- Инвариант 19 и механика фиксаций approve-по-sha (T021/T033/T051)
  не ослабляются: меняется только реакция на sha-сдвиг при
  ОТКЛОНЁННОМ переходе, успешные пути не трогаются.
- Класс «грязная копия артефактов» — вне объёма (легитимный инцидент).
- Не вводить обход для approve: операторские approve по-прежнему
  требуют точный sha.

## Критерии приёмки (ориентир для SPEC)

- Сценарий T069/T073 (роль закоммитила артефакты, guard отклонил
  advance) не порождает эскалацию: задача остаётся в состоянии
  с причиной отказа, sha перефиксирован, журнал содержит
  перефиксацию.
- Посторонний коммит (вне окна шага) при отклонённом переходе
  по-прежнему эскалирует инцидент целостности.
- Существующие тесты фиксаций/целостности зелёные и не ослаблены.
- Полный тестовый набор зелёный.
