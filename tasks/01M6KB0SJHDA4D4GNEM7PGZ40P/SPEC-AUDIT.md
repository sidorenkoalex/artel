## Пути обхода гейтов
- Поле «Прежние решения» (SPEC.md:56–58) проверяется только на
  «ссылку на несуществующий номер». Если прежние решения есть,
  «первое решение» (форма шаблона) или текст без номеров проходит. Так
  обходится смысл поля — сверка с прежними решениями, урок 04.11 п. 4,
  «противоречие двух решений». SPEC не задаёт отказа «первое решение» при
  наличии прежних и не требует хотя бы одного номера.
- Из-за незаданной формы «Чем проверяется», «Существующие тесты» и
  «Зоны» (SPEC.md:42–45) любое непустое значение («-», «см. выше»)
  проходит. ТЗ сознательно не проверяет истинность, но форму («поле не
  по форме») заявляет.
- Мандат: при правиле «подмножество/подстрока» (не задано, AC-7)
  можно сослаться на ANSWER с другим набором элементов.
- Как пульт узнаёт, что прежний возврат был файлом (k.n), а не текстом
  (k), SPEC не задаёт. Журнал хранит только текст (`fsm.py:1919`),
  признака формы нет. Разбор текста журнала тем же модулем — значит
  текстовая причина, похожая на файл решения, получит номера k.n. Новая
  отдельная запись журнала — уже иное устройство журнала. Влияет на
  AC-6/AC-8.
