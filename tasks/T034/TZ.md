# ТЗ: Подметалка minor T017–T031

Подметалка minor — строка беклога P3 «Подметалка minor»: накопленные
мелкие замечания ревью T017–T031 одним проходом. Каждый пункт мелкий,
адреса известны, поведение системы не меняется сверх описанного.

1. yamlmini: `rfind("]")` затягивает `]` из комментария в поток-список;
   вложенный `[a, [b]]` разбирается молча вместо YamlError (ревью T017).
2. Цикл auto: отказ guard на advance повторяет шаг агента вместо
   остановки (ревью T017) — отказ guard должен останавливать цикл
   с подсказкой, как остановка по гейту.
3. ci.py: сверка полноты пагинации `len == total_count` маскируется
   дублями при повторе страницы API (ревью T018) — дедупликация записей
   по id перед сверкой, либо честно снять слово «безусловная» из
   комментария-гарантии; реши по цене, тестом закрепи выбранное.
4. test_ci_status: `serve()` в subTest-цикле стекает патчеры до teardown
   (ревью T018).
5. runner: предупреждение о git-идентичности смотрит только пару
   AUTHOR — при экспортированных GIT_AUTHOR_* без конфига commit падает
   rc=128 без предупреждения; собрать absent из полного GIT_IDENTITY
   (ревью T019).
6. store.py: SCHEMA объявляет `target TEXT`, миграция —
   `TEXT DEFAULT 'artel'` — свежая и мигрированная БД расходятся
   дефолтом (ревью T019); привести к одному виду, тест на равенство
   схем свежей и мигрированной БД.
7. artel.py: type-hint `_tz_arg` не совпадает с фактическим типом
   (ревью T025).
8. codebase_map: шум связей импорта для orchestrator/__init__.py
   (ревью T027) — реши как потребитель (бриф уже есть): исключить
   __init__.py из связей или пометить отдельно.
9. Файлы, кодирующие инвариант 28, — добавить шапку-маркер с номером
