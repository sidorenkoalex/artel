# SPEC: Гейт неослабления: помощники по области ослабления проекта

## Контекст
Часть задачи 01M56P60XS9AP4BH01YK35220D (требования 6, 10, 11 её SPEC в
части помощников; её AC-9, AC-10). Гейт неослабления тестов прослеживает
помощников по устройству артели: вызывающие ослабленного помощника ищутся
только в `tests/` (`orchestrator/advance_gates/test_integrity.py:631-650`,
`_helper_callers`), имя модуля переводится как `tests.x` → `tests/x.py`
(`scripts/guard.py:1013-1019`), импортированные функции прослеживаются
только из `tests/sandbox.py` (`guard.py:1087`). Поэтому помощники чужого
стека (проект sled: `workdir: backend`, `weakening_scope:
[backend/tests/**/*.py]`; например `backend/tests/rbac_support.py`) гейту
невидимы, и потеря утверждения в них проходит без находки. Вызовы узла из
`orchestrator/review.py:650-652` и `orchestrator/fsm_merge_gate.py:144-146`
передают только предикат области; у `review_lines`,
`merge_gate_escalates`, `_test_integrity_gate` есть `task_id`, профиль
проекта задачи читается `project_profile.decide`.

## Требования
1. Режим поиска вызывающих и прослеживания помощников задаёт признак
   `repo_context.is_artel`.
   - У внешнего проекта (`is_artel` ложен) поиск вызывающих ослабленного
     помощника и прослеживание помощников идут по области ослабления
     профиля проекта задачи (`weakening_scope`): импортированная функция
     прослеживается из любого модуля области, имя модуля переводится в
     путь от корня проекта с учётом `workdir` профиля (`tests.x` при
     `workdir: backend` → `backend/tests/x.py`).
   - У артели (`is_artel` истинен) — как сейчас: вызывающие ищутся в
     `tests/`, импортированные функции прослеживаются только из
     `tests/sandbox.py`.
2. Профиль (в том числе `workdir`) узел сравнения получает внутри зон
   задачи; вызовы узла из `orchestrator/review.py:650-652` и
   `orchestrator/fsm_merge_gate.py:144-146` не меняются. Если без их
   правки не обойтись — эскалация до правки.
3. `guard.TestModules` и `guard.method_literal_keys` меняются обратно
   совместимо: `workdir` — необязательный аргумент, без него поведение
   прежнее; их вызов в `orchestrator/fsm.py:1053-1060` не правится.
4. У артели прежние исходы фиксируются тестами до правки и не меняются
   после неё: функция своего модуля без префикса `test_` — находка на
   вызывающем; функция `tests/sandbox.py` — находка; функция другого
   модуля `tests/` — находки нет; функция своего модуля с префиксом
   `test_` — не помощник; вызывающие ищутся только в `tests/`.
5. Тесты детерминированы, без сети; поведение чужого стека проверяется на
   учебном проекте с `workdir: backend` и `weakening_scope:
   [backend/tests/**/*.py]`.

## Критерии приёмки
AC-1. Помощник `backend/tests/rbac_support.py` учебного проекта (`workdir: backend`, `weakening_scope: [backend/tests/**/*.py]`), потерявший утверждение на ветке, вызываемый из неизменённого теста `backend/tests/test_<x>.py` (импорт `from tests.rbac_support import …`), даёт находку гейта неослабления.

AC-2. У артели исходы помощников прежние (зафиксированы тестом до правки, проходят после неё): (а) функция своего модуля без префикса `test_`, потерявшая утверждение, даёт находку на вызывающем тесте; (б) функция `tests/sandbox.py`, потерявшая утверждение, даёт находку на вызывающем тесте другого файла `tests/`; (в) функция другого модуля `tests/` (не `tests/sandbox.py`), импортированная и потерявшая утверждение, находки на вызывающем тесте не даёт; (г) функция своего модуля с префиксом `test_` помощником не прослеживается; (д) вызывающий ослабленного помощника ищется только среди файлов `tests/`.

Сработавший сигнал: зона задевает механизм, на который опирается запись
`docs/invariants.md` № 38 (гейт неослабления тестов,
`orchestrator/advance_gates/test_integrity.py`, `scripts/guard.py`).

Решение — **монолит**, материал для Оператора: задача уже сама является
первой частью нарезки родителя 01M56P60XS9AP4BH01YK35220D (раздел
«Деление» его SPEC, рамка $25). Перевод имени модуля с учётом `workdir`
(`guard.py`) и область поиска вызывающих (`test_integrity.py`) — одна
смена механики: перевод без поиска вызывающих по области не даёт находки
AC-1, поиск без перевода не прослеживает импорт; промежуточной части с
собственным проверяемым результатом нет. Инвариант 38 усиливается для
внешних проектов, у артели исходы прежние (AC-2).
