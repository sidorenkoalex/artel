# ТЗ: Ответы Оператора в брифе ревьювера

# ТЗ: ответы Оператора (ANSWER-n) в брифе ревьювера

Источник: инцидент 04.09, задача 01M1KCSTBYF1CRJBSY4P6VYQEA. Добавка
брифа с последним `ANSWER-n.md` (`brief.py`, SPEC T075 AC-6) выдаётся
только analyst/test_author/developer; ревьювер её не получает. Когда
ревьювер сам эскалирует (залоченная планка красна не по вине
реализации), ответ Оператора ANSWER с мандатом ADR-0012 до него не
доходит: повторный шаг ревьювера эскалирует снова тем же вопросом
($4.5 впустую), задача не может выйти из review иначе как ручной
правкой планки Оператором.

Требуется:
1. Бриф ревьювера включает ВСЕ `ANSWER-n.md` задачи (не только
   последний) — как границы решений Оператора, обязательные к учёту
   при вердикте: правка залоченной планки по ANSWER — авторизованная
   (skills/review-checklist.md уже признаёт канал ADR-0012), снятая
   эскалация не повторяется.
2. Компоненты брифа ревьювера журналируются с fingerprint так же, как
   у остальных ролей (SPEC T101).
3. Гейт ёмкости ревью-пакета учитывает добавку (ANSWER короткие,
   но входят в потолок).
4. Тесты: ревьювер получает ANSWER-1..n в брифе, fingerprint в
   журнале; отсутствие ответов — бриф прежний байт-в-байт;
   существующие тесты зелёные.

Зоны: orchestrator/brief.py, orchestrator/review_package.py (если
добавка живёт там), skills/review-checklist.md (одна строка:
«ANSWER задачи — границы решений Оператора»), tests/.

Не входит: изменение канала ANSWER для остальных ролей; авторешения
ревьювера по залоченной планке.

Рамка: $15.
