## Пути обхода гейтов
Путь Е1 круга 5 (правка помощника фикстуры общего модуля при вызывающем тесте вне диффа) закрыт требованием 5 и AC-14 п. 4.

Границы, а не отклонения: по решению круга 4 новые пробелы такого рода аудит записывает как границу.
- Межфайловая цепочка вне диффа. Помощник объявлен в файле A (в диффе), его вызывает фикстура в файле B (вне диффа), фикстуру запрашивает тест в файле C (вне диффа). `weakened_helpers` по A назовёт помощника, `git grep` найдёт B. В `pending` после B попадают только наследники классов (test_integrity.py:993–995), поэтому C не сравнивается. Та же граница есть сейчас у цепочек помощников; правка в `test_integrity.py` вне задачи.
- Справочно: нелитеральные правки тела (`yield real()` → `yield fake()`) записей не меняют — принято Оператором (круг 3, п. 3).
