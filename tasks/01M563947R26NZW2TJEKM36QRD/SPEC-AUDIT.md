## Пути обхода гейтов
1. Держатель без строки задачи → `store.task_target`
   (`store.py:705-706`) → «артель» → окно открыто прежним текстом без
   причины. Буквально AC-4 («называет id») выполнен, требование 2
   («называет … причину (… отсутствующая задача)») — нет. Пересекается с
   отклонением в) выше.
2. Порядок «разрешить проект → проверить состояние»: если `resolve`
   звать для КАЖДОЙ строки `all_tasks`, а не только для задач в
   состояниях окна, задача `done`/`killed` проекта, удалённого из
   `targets.yaml`, держит окно открытым навсегда (или каждый вызов
   читает `targets.yaml` по всем задачам). SPEC требования 1–2 и AC-4
   говорят «в состоянии окна», но ни один AC не требует негативной
   проверки «неразрешаемая задача вне состояний окна окна не открывает»;
   тесты такую реализацию пропустят. Мелкое.
