# Окно тишины note и doc-commit — только по задачам артели

## Факты

Строка бэклога 18.10 «Несколько проектов: окно тишины и мьютекс мержа по проекту», разбор «что прибито под артель». Окно тишины (`orchestrator/notes.py:264-283`, `_silence_window_reason`) удерживает запись `note`/`doc-commit` в `origin/main` артели, пока жив держатель мьютекса мержа или любая задача стоит в `config.NOTE_SILENCE_WINDOW_STATES`. Зачем оно (`orchestrator/config.py:498-509`): пуш в main артели в этих состояниях заставляет подтягивать main на точках сверки свежести или гоняется с пушем мержа (сбои 11.09 и 12.09). Но перебор (`notes.py:279-281`) идёт по `store.all_tasks` без фильтра по проекту: задача sled 01M55SKHZ293CCAK0N7T4H7ZMR, стоящая в `verifying` в своём репозитории, 17–18.10 удерживала все записи копилки и бэклога, их отправлял `note --flush`. Так же мерж задачи внешнего проекта (держатель мьютекса) открывает окно, хотя пушит не в main артели.

## Требуется

1. Окно тишины открывают только задачи проекта артели (`repo_context.is_artel` / `target` задачи — тем же признаком, что остальные потребители) в состояниях `NOTE_SILENCE_WINDOW_STATES` и держатель мьютекса мержа, чья задача — задача артели. Задачи внешних проектов окна не открывают; причина окна в тексте удержания прежняя.
2. Неизвестный проект задачи (запись не разрешается) — окно открыто (осторожный исход), текст называет задачу и причину.
3. У артели поведение окна и тексты не меняются; зафиксировать тестами до правки.
4. Тесты детерминированы, без сети: задача внешнего проекта в `verifying` — `note` пушит сразу; задача артели в `in_dev` — удерживает; держатель мьютекса с задачей внешнего проекта — не удерживает, с задачей артели — удерживает.

Критерии приёмки:
- задача внешнего проекта в состояниях окна и её мерж запись note/doc-commit не удерживают;
- у артели окно прежнее.

Зоны: `orchestrator/notes.py`, `tests/`.

Только чтение: `orchestrator/config.py`, `orchestrator/store.py`, `orchestrator/merge_lock.py`, `orchestrator/repo_context.py`, `docs/backlog.md`. Правка вне зон — эскалация до SPEC.

Не входит: разделение мьютекса и очереди мержа по проектам (`orchestrator/merge_lock.py`, `orchestrator/merge_queue.py`, схема `store.py` — отдельная задача той же строки бэклога).
