# ТЗ: объявленный стек пульта, часть 3 — окружение роли из манифеста, снятие временного хука

Источник: разбор 05.09 (копилка роадмапа §4 п.8), завершение серии
«объявленный стек» (части 1–2). `orchestrator/runner.role_env`
строит окружение роли копией `os.environ` Оператора: PATH со всеми
его pyenv/shim'ами, переменные его сессии. Роль видит инструменты,
которых у проекта нет (pytest из pyenv — 217 логов шагов), а
воспроизводимость шага зависит от машины Оператора. Временная мера
05.09 — PreToolUse-хук `docs/reference/role-home/claude/hooks/
bash_guard.py` (отказ полного прогона тестов) — симптоматическая и по
решению Оператора снимается этой задачей: инструмент, которого нет в
мире роли, запрещать не нужно.

Требуется:
1. `role_env` собирает окружение роли из манифеста
   (`orchestrator/stack.py`, часть 1): PATH — только каталоги
   абсолютных путей объявленных инструментов (`python3`, `git`, `gh`,
   `claude`), разрешённых ОДИН раз при старте шага через
   `shutil.which` в окружении пульта; переменные — по белому списку
   (HOME, CLAUDE_CONFIG_DIR, git-идентичность, токен роли, LANG/LC_*,
   TMPDIR, TERM и то, что нужно CLI claude — список в манифесте с
   причиной у каждой). Всё остальное из `os.environ` роли не
   передаётся. Интерпретатор роли — тот же `python3`, что и у пульта
   (`sys.executable`), не первый из PATH.
2. Отсутствие любого объявленного инструмента — шаг не стартует с
   журналом `agent run SKIPPED` и именованной причиной (по образцу
   «окружение роли не подготовлено»), без тихого отката на PATH
   Оператора.
3. Снятие временного хука: удалить `docs/reference/role-home/claude/
   hooks/bash_guard.py`, запись `hooks.PreToolUse` из
   `docs/reference/role-home/claude/settings.json` (deny-список
   остаётся), тест `tests/test_role_bash_guard.py`; обновить
   `docs/reference/role-home.md`. Правило «полный набор tests/ в шаге
   не гонять» остаётся текстом скилов; сторож зависших прогонов —
   задача «группа процессов» (01M1PNBSHR…).
4. `doctor` (или `check_stack` части 1) сообщает, если развёрнутый
   `.artel/home/.claude/` отличается от референса `docs/reference/
   role-home/claude/` (референс разворачивается только при холодном
   старте — 05.09 deny-список канарейки на пульте не действовал).
   WARN с перечнем отличающихся файлов, без автоправки.
5. Тесты: окружение роли не содержит переменных вне белого списка и
   каталогов PATH вне объявленных инструментов (подменённый
   `os.environ` с мусором); отсутствие инструмента — SKIPPED с
   причиной; интерпретатор роли равен `sys.executable`; проверка
   расхождения референса на временном каталоге; существующий набор
   `tests/` зелёный, тесты `role_env` (T019/T020/ADR-0003) — без
   ослабления, при необходимости обновлены под белый список.

Зоны: orchestrator/runner.py (role_env), orchestrator/stack.py,
docs/reference/role-home/, tests/. Порядок: после мержа «группы
процессов» (01M1PNBSHR…, правит runner.py) и части 1. Не входит:
смена CLI роли, права инструментов (`--allowedTools`), контейнеризация.
