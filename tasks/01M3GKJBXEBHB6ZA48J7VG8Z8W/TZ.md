# ТЗ: answer: проверка строки мандата при записи и подсказка approve после ответа

Источник: строка бэклога 26.09 «answer: проверка строки мандата и
подсказка approve» (docs/backlog.md), условие старта «после мержа
01M3FQ2V (общий разбор мандатов)» наступило 26.09. Прецедент 26.09:
мандат «Расширение зон разрешено: orchestrator/artel.py — только разбор
аргументов…» в ANSWER-1 задачи 01M3FQ3J молча не действовал (элемент
после двоеточия не путь), а ответ в escalated не снял эскалацию — её
снимает approve, цикл auto остановился сразу. Задача вне линии
провайдеров.

Факты (origin/main после мержа 01M3FQ2V):
- Команда `answer <id> <файл>` (orchestrator/answer.py::cmd_answer →
  _cmd_answer): в escalated кладёт ANSWER-n в артефактную ветку
  коммитом «<id>: ANSWER-n — ответ Оператора» и печатает «создан и
  закоммичен»; в in_dev/review дополнительно обновляет zones_extension
  по строке мандата (`_zones_mandate_marker_paths`, :52-61 — путь
  берётся `line.startswith(marker)`, без strip, элементы через запятую).
  Возврат из escalated делает `approve <id>` (orchestrator/fsm.py:887,
  «эскалация разрешена, продолжаем»); answer об этом не сообщает.
- Мандаты читают гейты по файлам ANSWER-n на ветке: расширение зон —
  orchestrator/advance_gates/zones.py (`_ZONES_MANDATE_MARKER`
  «Расширение зон разрешено:», `_answer_zones_mandate`, строки со strip,
  элементы через запятую, `_answer_commit_is_role_step_autocommit`);
  ослабление тестов — orchestrator/advance_gates/test_integrity.py
  (маркер «Ослабление тестов разрешено:», элементы — путь или
  `путь::Класс::метод`, задача 01M3FQ2V). Разбор строки мандата
  реализован в трёх местах (answer.py, zones.py, test_integrity.py).
- Элемент мандата, не совпадающий ни с одним путём (пробел, тире,
  пояснение, несуществующий путь), гейтом не засчитывается молча:
  ни при записи, ни при проверке имени файла отказа нет.

Требуется:
1. Один разбор строк мандата на все три места: функция в
   orchestrator/advance_gates/ (или в guard) «маркер → список
   элементов» со strip и делением по запятым, используемая answer.py,
   zones.py и test_integrity.py без изменения их поведения на валидных
   строках (существующие тесты трёх модулей зелёные без правок
   ожиданий).
2. Проверка при записи: `answer` до коммита ANSWER разбирает все строки
   мандатов файла и отказывает именованно, если элемент (а) содержит
   пробел или не похож на путь репозитория, (б) для мандата зон —
   не существует в дереве ветки задачи как файл или каталог (с учётом
   `/` на конце), (в) для мандата ослабления — путь не под `tests/`
   либо форма `путь::имя` нарушена. Отказ называет строку, элемент и
   причину; файл ANSWER не создаётся. Пустой список элементов после
   маркера — отказ.
3. Подсказка после ответа: в escalated `answer` печатает строку
   «дальше: artel.py approve <id> (снятие эскалации)» и пишет в журнал
   задачи запись «ANSWER создан, ждёт approve». Флаг автоматического
   approve в этой задаче не заводится: разбор аргументов —
   orchestrator/artel.py, зона задачи 01M3FQ3J в полёте.
4. Документация: docs/operator-gates.md — формат строки мандата (только
   пути через запятую, пояснения отдельным абзацем), проверка при
   записи, шаг approve после ответа.
5. Тесты (tests/): отказ на элемент с тире/пояснением, на
   несуществующий путь, на путь вне tests/ для мандата ослабления, на
   пустой список; валидный мандат с отступом проходит; три потребителя
   разбирают одну и ту же строку одинаково (общий разбор); подсказка и
   запись журнала в escalated; существующие tests/test_answer.py,
   tests/test_answer_gate.py, tests/test_answer_branch_reads.py,
   tests/test_zones_gate.py, tests/test_test_integrity_gate.py зелёные,
   ни один не ослаблен.

Зоны: orchestrator/answer.py, orchestrator/advance_gates/,
docs/operator-gates.md, tests/.

Только чтение (не менять): orchestrator/artel.py (зона задачи 01M3FQ3J
в полёте; usage не меняется), orchestrator/fsm.py, scripts/guard.py (если общий разбор ляжет туда — вопрос
расширения зон), orchestrator/store.py, docs/operator-session.md (зона
задачи 01M3FQ3J в полёте), docs/backlog.md, tests/test_invariants.py.

Не входит: новые виды мандатов; изменение семантики гейтов зон и
неослабления; автоматический approve (флаг `--continue` — следующей
задачей, когда artel.py свободен).
