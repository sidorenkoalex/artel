# SPEC: Транслитерация слага ветки

## Контекст
`cmd_new` в orchestrator/artel.py строит слаг ветки регуляркой
`[^a-z0-9]+` по нижнему регистру названия. Кириллические названия
(а они основные) вычищаются целиком, слаг деградирует в "task" —
имя ветки `task/t001-task` неинформативно. Найдено при тестовом
прогоне T001.

## Требования
1. Кириллица в названии задачи транслитерируется в латиницу при
   построении слага ветки (ГОСТ-подобная простая схема, без внешних
   зависимостей — только stdlib).
2. Поведение для латинских названий не меняется.
3. Слаг по-прежнему ограничен 30 символами, пустой слаг заменяется
   на "task" (как сейчас).
4. Функция построения слага выделена и покрыта юнит-тестами в tests/
   (кириллица, латиница, смешанное, спецсимволы, пустая строка).

## Критерии приёмки
1. `new "Тест проверки"` создаёт ветку вида `task/tXXX-test-proverki`.
2. `new "Fix CI pipeline"` создаёт ветку вида `task/tXXX-fix-ci-pipeline`.
3. `python3 -m unittest discover -s tests` зелёный, есть кейсы из
   требования 4.
4. guard и CI зелёные.

## Не входит
- Переименование веток уже существующих задач (T001).
- Любые другие изменения оркестратора (kill-очистка, повторное ревью —
  отдельные задачи).
