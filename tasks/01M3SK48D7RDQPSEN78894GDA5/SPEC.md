# SPEC: Канарейка не меняет боевой дом Codex пульта

## Контекст

При прогоне канарейки шаг Codex получает `CODEX_HOME` боевого дома
пульта. Codex дописывает в его `config.toml` доверие временного каталога
клона, из-за чего канарейка изменяет окружение настоящих задач и дом
расходится с референсом. У клона уже есть собственный развёрнутый дом
Codex, поэтому шаги канарейки должны пользоваться им.

## Требования

1. Для роли на Codex в эфемерном клоне `CODEX_HOME` шага указывает на
   отдельный развёрнутый дом Codex этого клона, а не на
   `.artel/home/.codex/` пульта. Канарейка не передаёт боевой дом в
   `canary_drive` как переопределение дома шага.
2. Вход Codex клона по-прежнему использует указатель системной связки
   ключей; учётные данные и файлы входа в дом клона не копируются. При
   отсутствии указателя проверка входа клона отказывает до запуска роли.
3. Вне канарейки `CodexProvider` по-прежнему выдаёт настоящей задаче её
   обычный дом; её поведение не меняется.
4. Проверка `doctor` соответствия дома Codex референсу сохраняется.
   Накопленные канарейкой записи доверия в боевом доме этой задачей не
   удаляются.
5. В `tests/` добавлены проверки из критериев приёмки.

## Критерии приёмки

AC-1. Прогон канарейки с ролью на Codex и подменённым запуском Codex,
дописывающим доверие в `config.toml` своего дома, оставляет
`.artel/home/.codex/config.toml` пульта байт в байт прежним; запись
доверия делается в доме клона.

AC-2. Вход Codex клона по-прежнему проверяется и отказывает без
указателя связки ключей; файлы учётных данных в клон не копируются.

AC-3. Настоящая задача вне канарейки получает и может изменять свой дом
Codex как прежде.

AC-4. `doctor` продолжает сверять дом Codex с референсом, а накопленные
канарейкой записи доверия в доме пульта не удаляются этой задачей.

## Не входит

- Чистка накопленных записей доверия в боевом доме пульта.
- Изменение референса дома Codex.
- Изменение дома Claude.
- Только чтение: `.artel/home/.codex/` и
  `.artel/home/.codex/config.toml` — боевой дом пульта; задача его не
  пишет.
