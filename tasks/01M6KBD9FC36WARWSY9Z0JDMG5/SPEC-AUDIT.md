## Пути обхода гейтов
- Е1. Комментарии теряются молча. Отказ «строка, начинающаяся с `#`»
  (SPEC.md:57) при буквальном чтении (первый символ строки) не ловит
  строку-комментарий с отступом `    # почему так` и хвостовой комментарий
  `failure_errors: [X]  # см. инцидент`: `yamlmini` оба выбрасывает
  (`orchestrator/yamlmini.py:126`, :35, :53), а сверка шага (а) по
  разобранному отображению их не видит. Полная пересборка `_render`
  сотрёт их без отказа — именно то, от чего отказ и ставился. Нужна
  формулировка «строка, чей первый непробельный символ `#`, или `#`
  после пробела в значении» либо явное решение Оператора, что хвостовые
  комментарии терять допустимо (копия в `config.LOGS` их сохранит).
- Е2. Добавление компонента через поле. Перечень требования 2 проверяет
  поле, но не существование `<к>`: `target-set p
  description.components.new.command [pytest]` создаёт новый компонент
  (новое промежуточное отображение + один лист — шаг (а) при буквальном
  счёте «листов» пройдёт), и `merge_local` его примет, если у компонента
  нет обязательных полей сверх `command`. Это «добавление компонентов
  целиком», которое SPEC выносит в «Не входит» (SPEC.md, раздел), но
  отказа на него нет. Для `policy.components.<к>`/`machine.components.<к>`
  неизвестный `<к>` уже отвергает `merge_local`
  (`orchestrator/targets.py:541-543`), для `description.components.<к>` —
  нет. Аналогично `description.<поле>` с `components`/`test_profile`
  (поля есть в `LOCAL_FIELDS["description"]`, `targets.py:351-353`)
  — запись скаляра вместо отображения; её отвергнет `merge_local`, но
  явного отказа «путь во вложенное отображение» SPEC для них не называет.
- Е3. AC-2 без шва часов. Тест «вторая правка в ту же секунду» без
  подмены времени — гонка с часами (линт детерминизма
  `orchestrator/test_lint.py` ловит ожидание по часам), с подменой —
  тест-автор навяжет имя внутреннего источника времени (класс
  `тест-навязывает-устройство`, `skills/escalation-rules.md`). Обход
  буквы: тест может заранее создать файл `targets-<сейчас>.yaml` руками
  и проверить лишь, что команда не затёрла его, — это и есть свойство
  AC-2, если тест создаёт файлы на текущую и следующую секунду. Решаемо
  тест-автором; отмечаю как риск, не как дефект SPEC.
- Е4. Шаг (б) через запись (Ф3): разработчик, буквально следуя «`layers()`
  на новом тексте», запишет файл, вызовет `layers()` и откатит при
  ошибке — между записью и откатом читатели пульта видят непроверенный
  слой, и «файл байт в байт прежний» AC-3 формально выполнится. SPEC
  стоит разрешить сверку `yamlmini.mapping` + `merge_local` по образцу
  `_migrate_mismatches` (`orchestrator/projects.py:329`) либо прямо
  назвать временный файл.
- Е5. Отсутствие изменения: `target-set` значения, равного текущему, —
  ноль различающихся листов; по букве шага (а) («ровно одним листом») —
  отказ. Поведение не оговорено; мелко, решить на гейте (отказ «значение
  не изменилось» либо успех без записи).
