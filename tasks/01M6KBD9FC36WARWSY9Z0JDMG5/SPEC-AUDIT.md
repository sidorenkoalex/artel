## Пути обхода гейтов
- О-1. Разбор значения argv не назван (треб. 1: «литерал подмножества
  `yamlmini`»). Самый прямой путь — `yamlmini.scalar` / разбор строки
  `v: <значение>` — режет хвост после ` #` (yamlmini.py:35, :53):
  `target-set p description.components.app.workdir "src # old"` запишет
  `src`, а сверка AC-4 «собранное читается так же» пройдёт, потому что
  сравнивает уже усечённое значение с его же повторным чтением. Так же
  `""`, `~`, `null` молча становятся `None`. Буквально SPEC выполнен,
  смысл «значение, которое yamlmini прочитал бы иначе, — отказ» обойдён на
  входе. Нужна норма: значение argv, чей разбор теряет текст (комментарий,
  пустое/null), — отказ (либо сверка разобранного значения с исходным
  текстом аргумента).
- О-2. Строка doctor: AC-8 не проверяет, что компонент без `report`
  (вне границы отчёта) в перечень `warn` не попадает, — реализация,
  перечисляющая все компоненты записи `components:` с пустым
  `failure_errors`, проходит все критерии (см. В-3).
- Прочие возможные обходы закрыты критериями: сверка (а) по сведённой
  записи — AC-5; отказ после копии — AC-3 («копии нет»); комментарий по
  сырому `#` — AC-9 (кейс `"a # b"`).
