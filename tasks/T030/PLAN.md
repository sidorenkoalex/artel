# PLAN: Команда version

## Подход
Новый read-only модуль `orchestrator/version.py` с единственной функцией
`cmd_version()` — тот же паттерн, что `doctor.cmd_doctor`/`budget.cmd_budget`:
одна команда CLI — один модуль, `artel.py` только диспетчерит.

Три значения:
- пин CLI — `config.CLI_VERSION_PIN` (константа, без подпроцесса);
- фактическая версия — `doctor.cli_version()` (AC-3 явно требует «тем же
  способом, что и `doctor.cli_version()`» — не дублировать разбор
  `claude --version` вторым regex'ом);
- версия схемы — `guard.SUPPORTED_SCHEMA_VERSION`, импорт `from scripts
  import guard` (уже устоявшийся паттерн: `fsm.py`, `acceptance.py`).

Расхождение (AC-5): если `doctor.cli_version()` вернула значение и оно не
равно пину — печатается отдельная строка-пометка. Если версия не
определилась (`None`, тот же случай, что `doctor.check_cli_version()`
трактует как `warn`, не как расхождение) — пометки о расхождении нет,
только сама строка вывода отражает «не определилась».

Read-only без специальных мер (AC-4, AC-6): команда только читает
константы и вызывает `subprocess.run(["claude", "--version"])` внутри
`doctor.cli_version()` — ни один из использованных путей (`config`,
`doctor.cli_version`, `guard.SUPPORTED_SCHEMA_VERSION`) не открывает БД,
не пишет файлы и не зовёт git. Действие требования 4 обеспечивается самим
выбором источников данных, а не отдельной защитой.

`artel.py --help`/`-h` (AC-7): сейчас `main()` печатает `__doc__` только
при пустом `argv`, а `--help`/`-h` уходят в общую ветку «неизвестная
команда» (`sys.exit`, вывод в stderr — не ловится приёмочным тестом,
читающим stdout). Расширяю условие показа справки до
`not args or args[0] in ("-h", "--help")` и добавляю `version` в список
команд докстринга — тем самым `--help`/`-h` становятся валидными флагами
общей справки (сами по себе не входили в критерии SPEC, но AC-7 не
проходит без них при текущей реализации `main()`), и команда видна в
её тексте.

## Влияние на систему
Новый модуль и одна строка в таблице команд `artel.py` — не меняет
поведение существующих команд. Единственная правка вне нового модуля —
условие показа `__doc__` в `main()` (`--help`/`-h`); раньше эти флаги
падали как «неизвестная команда» — расширение множества распознаваемых
входов, не сужение и не ослабление проверки. `doctor.cli_version()`
переиспользуется как есть, без изменений сигнатуры или поведения —
`doctor`/`check_cli_version`/связанные тесты не затрагиваются. Тестов,
гейтов, лимитов или guard-проверок изменение не ослабляет и не убирает.
Откат — удаление `orchestrator/version.py`, строки `"version"` из таблицы
команд и docstring, возврат условия показа `__doc__` к `not args`.
