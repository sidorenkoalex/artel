# ТЗ: Команда version

Хочу команду version у artel.py: печатает версию пина CLI из конфига,
фактическую версию установленного claude и версию схемы артефактов.
Если пин расходится с фактической версией — явная пометка об этом
в выводе. Команда только печатает, ничего не меняет (ни конфиг,
ни БД, ни git). Куда встроить в справку — на усмотрение исполнителя,
лишь бы Оператор нашёл. Класс — мелкий фикс, $15.
