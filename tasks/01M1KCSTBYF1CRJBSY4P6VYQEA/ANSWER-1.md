# ANSWER-1: ответ Оператора

## Ответы

Вопрос 1 — вариант B, с мандатом на расширение зон.

Алерт «цикл буксует / остановка не на гейте» закрывается при ЛЮБОМ
успешном переходе состояния задачи, кем бы он ни был вызван
(`auto`, ручной `advance`, `approve`, `reject`). Мандат этим ответом:
хук авто-закрытия ставится в общую точку перехода
(`store.set_state` либо обработчики `fsm.py`/`fsm_advance.py` —
выбор разработчика по образцу авто-закрытия T035/T088); зоны задачи
расширяются на эти файлы. Оговорка ТЗ «конфликт зон — эскалация»
касалась стройки A7 — A7 смержена 03.09, зоны свободны.
Обоснование: при варианте A алерт после ручного `approve` Оператора
висел бы ложно до следующего вызова `auto` — ровно тот класс
ложных сигналов, который эта задача призвана убрать.

Вопрос 2 — вариант B, кроме паузы.

Правило общее: алерт поднимает КАЖДАЯ остановка `auto` не на
ручном гейте — в том числе общий отказ `run` стартовать (бюджет до
старта, лимит параллельных задач) и структурный отказ guard'а
артефакта; пятёрка в ТЗ — примеры, не исчерпывающий список.
Исключение одно: остановка по `pause` — действие самого Оператора,
алерт не поднимается. Обоснование: тихие остановки «run отказался
стартовать»/«guard отказал» — тот же класс невидимого простоя,
что и инциденты 02–03.09.

Вопрос 3 — вариант A (дефолт).

Когда на последнем из N шагов нет класса отказа, хвост
«, последний отказ: <класс>» опускается: сообщение «цикл не
сходится: N шагов без перехода». Отсутствие хвоста само по себе
несёт факт «отказа не было — агент продолжал работу».
