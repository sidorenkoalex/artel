# ТЗ: guard на артефактных ветках: черновики не красят CI, сданные артефакты проверяются строго

# ТЗ: guard на артефактных ветках не красит черновики — статус draft и WIP как законное промежуточное состояние

Источник: наблюдение 05.09. CI запускается на пуш каждой артефактной
ветки `artifact/<id>` (T094, требование 7) и гоняет `guard.py --all`.
Каждый шаг роли заканчивается автокоммитом артефактов и пушем, а
промежуточные артефакты по определению неполны: SPEC в `status: draft`
без поля `zones`, PLAN в работе без итогов прогонов, ANSWER без секции.
За сутки 58 из 100 прогонов CI пришлись на артефактные ветки, почти все
красные, Оператор получает уведомление о каждом. Сигнал тонет в шуме:
настоящие нарушения формы (ANSWER без «## Ответы», SPEC без секции
оценки объёма у принятой задачи) неотличимы от «ещё пишется».

Требуется:
1. guard различает черновик и сданный артефакт: для артефакта со
   `status: draft` (SPEC, PLAN, REVIEW, TEST_REPORT) проверяются только
   базовые условия (frontmatter читается, `task`/`type`/`schema_version`
   на месте, версия не выше поддерживаемой), обязательные секции и
   поля содержания (`zones`, «Оценка объёма и деление», AC-разметка,
   маркеры красноты) — только для `ready`/`approved`/`escalate`/
   `changes_requested`. Переход состояния в пульте (`advance`, гейты)
   по-прежнему требует полной проверки — там черновик не проходит,
   как сейчас.
2. Режим `guard.py --all --ci-artifact-branch` (или переменная
   окружения) для джоба на ветках `artifact/**`: нарушения формы у
   сданных артефактов — ошибка (exit 1), у черновиков — предупреждение
   в вывод без падения джоба; на `main` и `task/**` поведение прежнее.
   Правка `.github/workflows/ci.yml` — защищённый путь, диффом-
   приложением к PLAN для Оператора.
3. Отчёт: guard в CI печатает сводку «сдано N / черновиков M /
   нарушений K» первой строкой, чтобы уведомление читалось без логов.
4. Тесты: draft-SPEC без `zones` — предупреждение в режиме артефактной
   ветки и ошибка на `advance`; ready-SPEC без `zones` — ошибка в обоих
   режимах; ANSWER без «## Ответы» — ошибка всегда (у ANSWER нет
   черновика); существующие тесты guard (`tests/test_guard*.py`)
   зелёные без ослабления; инвариант 17 (обязательные секции PLAN
   на переходах) не ослабляется.

Зоны: scripts/guard.py, tests/test_guard*.py, .github/workflows/ci.yml
(диффом), docs/invariants.md при необходимости (диффом). Не входит:
отключение CI на артефактных ветках; смена схемы артефактов; правила
guard для `main`.
