# ТЗ: M1 — артефактный контур (прочтение Б₃ + ULID)

Первоисточник решений: docs/roadmap.md §3, блок «M1 «артефактный
контур»» — читать ЦЕЛИКОМ, все решения Оператора 31.08–01.09 там
консолидированы (Б₃, ULID, паспорт живой задачи, отказ push
снапшота, судьба нумерозависимого кода, «в пульте — кухня пульта,
в целевых — кухня целевых», порядок с A7 и Д1). Контекст принципов —
docs/multi-operator.md; аудитные обоснования — v6 BL-1/Q-1/Q-2,
v7 V7-3/V7-6/V7-Q1/V7-Q2 (docs/audits/).

Зоны работы (состав — из роадмап-блока, здесь только оглавление):

1. **Реестр точек чтения артефактов — ПЕРВЫМ разделом PLAN**
   (лечение BL-1): все места, читающие tasks/<id>/ из ветки
   (фиксации sha, лок acceptance_tests, ветко-чтения, брифы, guard
   в CI, coldstart), с планом перенаправления на артефактную ветку.
2. **ULID + id-агностика** первым шагом исполнения (строка P3
   «Id-агностика + префикс-резолвер» входит в объём: генератор —
   одна функция, CLI принимает уникальный префикс, CI-греп-линт
   на парсинги формата вне генератора; старые T-номера живут
   как есть). Судьба нумерозависимого кода — по роадмап-блоку:
   retention логов по времени, контур счётчика в legacy.
3. **Артефактная ветка задачи в пульте**: создаёт cmd_new,
   push best-effort; роли коммитят tasks/<id>/ туда; код-ветка
   целевого чиста от артефактов. Два sha в фиксациях гейтов.
   Паспорт живой задачи — статус-файл на переходах FSM.
4. **Снапшот при закрытии** (done И killed; канарейка — нет):
   артефакты + RETRO (поля operator/model/artel_sha; опция
   пошаговых метаданных — решить в SPEC) → refs/artifacts/<id>
   ЦЕЛЕВОГО, строго до удаления веток; отказ push — done не
   блокируется, ветки живут до подтверждённой вечности, дожим
   ретраем/doctor.
5. **Кэш ретро-корпуса** в .artel/ (расходный, пересборка fetch'ем
   refs); правило «refs/artifacts/* удаляет только Оператор».
6. **ADR-правка 0005** тем же заходом: пп.1/2/4/5 под новую
   топологию (пп.6/7 уже аннотированы 01.09); мандат на правку ADR —
   этого ТЗ, подтверждается Оператором на spec_gate.

Не входит: sync-транспорт (M2: pull на входе команд, автопуш шагов,
клейм мерж-окна, возраст политики); A7; уборочный коммит
исторических tasks/ (после M1+A7, операторский); Д1.

Догфуд-оговорка переходного периода: до A7 задачи самого пульта
могут продолжать текущий однобраншевый флоу — разводка на две ветки
для догфуда включается в A7; SPEC вправе выбрать иное, обосновав.

Если объём в один заход не помещается — предложи разбиение батчем
вопросов (варианты нарезки + дефолт), не ужимай молча.

Рамка: $40–50 задачным потолком (аудит v7: $25–40 занижено);
поднятие по эскалации — штатный режим.
