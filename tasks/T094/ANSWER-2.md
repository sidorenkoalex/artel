# Ответ Оператора: красный AC-15 после подтяжки main — диагноз и указание

## Диагноз (проверен живым прогоном)

Красный только `test_ac15_retried_by_doctor_after_origin_recovers`, и
причина НЕ в снапшотах. Тест зовёт полный `doctor.cmd_doctor()`, а в
main приехал новый чек `isolation-smoke` (orchestrator/doctor.py,
~строка 300): он собирает промпт роли и читает
`config.ROOT / "skills" / "<имя>.md"`. Песочница теста строит
временный корень БЕЗ каталога `skills/`, чек падает
(`No such file or directory: .../skills/conventions-core.md`),
доктор печатает «провалов 1» и делает `sys.exit(1)` — `SystemExit`
роняет тест как error. Дефект полноты фикстуры песочницы, столкновение
с новым чеком доктора; код M1 не виноват.

## Что сделать

Дополнить песочницу приёмочных тестов реальными файлами `skills/`
(и `templates/`, если чек их тоже потребует) — скопировать из корня
репозитория во временный корень, чтобы `isolation-smoke` проходил
честно. В `tests/sandbox.py` уже описан приём для тестов, которым
нужны `skills/`/`templates/` (см. докстринг) — используй его в
`_sandbox.py`/`ExternalTargetGitSandbox` или в setUp самого теста.

ЗАПРЕЩЕНО: глушить `SystemExit`, мокать/обходить `isolation-smoke`,
ослаблять сам чек — это гейт целостности, правится только фикстура.

Критерий готовности: полный приёмочный набор зелёный на текущем main
(28/28), доктор в песочнице печатает «DOCTOR: ок».
