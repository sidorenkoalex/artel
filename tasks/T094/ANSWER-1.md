## AC-16 — прочтение (а): кэш в M1, но по ЛОКАЛЬНЫМ refs

Противоречие реальное, слово «fetch'ем» в требовании 14 — неточность
формулировки, а не намерение. Разводка объёмов:

- В M1: локальный кэш ретро-корпуса в `.artel/` СУЩЕСТВУЕТ и
  пересобирается ПРОХОДОМ ПО ЛОКАЛЬНЫМ `refs/artifacts/*`
  (git for-each-ref + чтение RETRO из снапшотов) — без сети.
  Обоснование: с M1 RETRO уходит из docs/retro/ в снапшоты — если
  кэш отложить в M2, ретро-корпус остаётся без читателя (report,
  аналитика) — регресс наблюдаемости, недопустимый по духу решений
  31.08 («стоимость — публичные метаданные»).
- В M2 (как и записано в «Не входит»): СЕТЕВОЙ fetch чужих refs
  из origin'ов целевых как фоновая машинная обвязка.

AC-16 переформулировать соответственно: «кэш полностью
пересобирается из локально существующих refs/artifacts/*; сетевой
fetch — вне объёма (M2)». Тест пиши под локальную пересборку
(создание refs в песочнице + пересборка кэша с нуля).
