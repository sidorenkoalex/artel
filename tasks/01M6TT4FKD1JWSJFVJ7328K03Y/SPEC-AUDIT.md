## Пути обхода гейтов
- Ни одна ветвь не пропускает гейт: без годного отчёта базы — ожидание
  под потолком либо эскалация (требования 3, 7, 8; AC-7).
- Отправка в `ci_base_branch` — две линии: белый список по свежему sha
  `origin/<base>` (`--refmap=`), хук по локальной ссылке. Сдвиг ссылки
  ролью даёт отказ отправки → ожидание → эскалация по потолку
  (fail-closed, теперь закреплено AC-7 (а)).
- Через `ci_base_branch` нельзя отправить код задачи: годен только
  предок `origin/<base>`; обхода `max_in_flight` и правил веток задач нет.
- В1, В2 гейт не обходят: В1 — лишняя тихо принятая настройка без
  действия у `local`; В2 — неверный порядок очереди ведёт в худшем случае
  к отмене чужого конвейера и отказу «задание отменено» (риск принят
  решением 3 возврата 2).

Новых путей обхода нет.
