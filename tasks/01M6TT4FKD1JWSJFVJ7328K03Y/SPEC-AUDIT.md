## Пути обхода гейтов
- Гейт не пропускается ни в одной ветви. Все исходы без годного отчёта
  базы — ожидание под потолком либо эскалация (требования 3, 7, 8).
- Отправка в `ci_base_branch` ограничена двумя линиями:
  - белый список — по свежему sha `origin/<base>` (`--refmap=`, без
    записи в ссылку отслеживания);
  - хук — по локальной ссылке.

  Если роль сдвинет локальную ссылку, `diff_base` даст негодную базу.
  Тогда белый список откажет, а задача (по записке решения 4) будет
  ждать до потолка и эскалирует — fail-closed.
- Через `ci_base_branch` нельзя отправить код задачи: годен только
  предок `origin/<base>`. Поэтому обхода `max_in_flight` и правил веток
  задач нет.
- Через В1 гейт не обходится. Неопределённость там только в выборе
  между ожиданием и немедленной эскалацией, обе — fail-closed.

Новых путей обхода нет.
