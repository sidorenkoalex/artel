# ТЗ: посторонние файлы в каталоге планки не попадают в артефактную ветку

Источник: бэклог 05.09 (`docs/backlog.md`). Дважды за день автокоммит
шага роли утащил в артефактную ветку сгенерированную карту кодовой базы
внутри `tasks/<id>/acceptance_tests/docs/codebase-map.md` (test_author
критерия сироты, reviewer канарейки ч.2): после мержа `guard --all`
красил main около сорока минут, Оператор убирал файл руками. Источник —
генератор карты `scripts/codebase_map.py`, запущенный с рабочим
каталогом внутри каталога планки (пишет `docs/codebase-map.md`
относительно cwd).

Требуется:
1. Автокоммит артефактов шага (`orchestrator/checkpoint.py`) переносит
   в артефактную ветку из `tasks/<id>/acceptance_tests/` только
   разрешённые файлы: `test_*.py`, `_sandbox.py`, `markers.py`,
   `__init__.py` и `*.md`/`*.txt` первого уровня; вложенные каталоги
   (кроме `__pycache__`, который игнорируется) и прочие файлы не
   коммитятся, а журналируются одной записью «в каталоге планки
   посторонние файлы: <список>».
2. `scripts/guard.py` (режим `--all` и режим артефактной ветки) считает
   посторонний файл внутри `acceptance_tests/` нарушением структуры с
   именованной причиной («посторонний файл в каталоге планки»), а не
   пытается разобрать его как артефакт с frontmatter.
3. `scripts/codebase_map.py` пишет карту только в
   `<корень репозитория>/docs/codebase-map.md`, определяя корень по
   `git rev-parse --show-toplevel` от cwd, а не относительно cwd;
   запуск из подкаталога даёт тот же результат.
4. Тесты: автокоммит с посторонним файлом в планке — файл не в ветке,
   запись в журнале; guard на артефактной ветке с посторонним файлом —
   именованная ошибка; генератор из подкаталога пишет в корень;
   существующие тесты checkpoint/guard/карты зелёные без ослабления.

Зоны: orchestrator/checkpoint.py, scripts/guard.py,
scripts/codebase_map.py, tests/. Порядок: код после мержа задач «карта
не ломает подтяжку» (checkpoint.py) и «наблюдатель роста карты (а)»
(codebase_map.py); SPEC и планка сразу. Не входит: смена формата планки,
правки исторических артефактных веток.

Рамка: $15.
