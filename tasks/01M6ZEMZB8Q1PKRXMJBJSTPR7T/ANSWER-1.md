## Мандат

Ослабление тестов разрешено: tests/sandbox.py

Пояснение мандата: только добавление подмены места шаблонов байткода на каталог песочницы процесса тестов рядом с соседними подменами `config` (`tests/sandbox.py:437-451`), и та же подмена через переменную окружения процесса тестов, чтобы её унаследовали дочерние процессы `artel.py`, запущенные тестами. Прочие строки `tests/sandbox.py` не меняются, ни одна подмена не снимается.

## Ответы

1. A, с дополнением: место шаблонов задаётся константой `config` с переопределением переменной окружения (имя — по конвенциям проекта, без названия продукта); `tests/sandbox.py` выставляет и константу, и переменную окружения процесса на каталог песочницы. Тогда дочерние процессы `artel.py` из тестов `suite_run`/`mutation_run` тоже пишут шаблон в песочницу, а не в настоящий каталог машины; правило ТЗ «настоящие шаблоны машины не трогаются» выполняется для всего набора. Проверки варианта B (сборка без байткода `_pytest` — отказ, манифест хэшей) — в силе. Критерий: прогон набора тестов задачи не создаёт и не меняет каталог шаблонов по умолчанию (сверка до и после в песочнице с подменённым по умолчанию путём).
2. A — риск принят Оператором 09.11.2026: умышленная подмена байткода шаблона кодом того же пользователя ОС не закрывается; строка матрицы неослабления SPEC «не покрыто: умышленная подмена тем же uid — риск принят Оператором 09.11.2026». Защита обязательна: каталог шаблонов 0700, проверка владельца (текущий uid) и прав при наполнении, сверка хэша каждого копируемого файла с манифестом; расхождение — повреждение шаблона (пустой префикс, строка, пересборка).
3. A — без `run_dir` префикс пуст, как сейчас, строки о сбое нет; `orchestrator/advance_gates/two_sided.py` не правится. Критерий подключения «без `run_dir` — пусто».
4. A — `config.PYCACHE_TEMPLATE_RETRY_SEC` = 3600 с.
