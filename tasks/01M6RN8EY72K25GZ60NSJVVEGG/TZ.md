# ТЗ: Шаблон сообщения коммитов пульта в ветке задачи без сжатия: policy.commit_message_template

# Шаблон сообщения коммитов пульта в ветке задачи без сжатия: policy.commit_message_template

## Факты

1. Коммиты пульта в кодовой ветке задачи пишутся служебным текстом с id задачи: чекпоинт тестов `"{task_id}: долгоживущие тесты закоммичены пультом за роль test_author — шаг завершён"` и кода `"{task_id}: код закоммичен пультом за роль developer — шаг завершён с незакоммиченным кодом"` (`orchestrator/checkpoint.py` около `:925-934`), аварийный чекпоинт (`:776`), подтяжка `base` и прочие коммиты ветки (`orchestrator/pull.py:473`, `:556`), коммиты `amend-tests` (`orchestrator/amend.py:806`); подпись — `gitcmd.pult_message` (`orchestrator/gitcmd.py:585-593`).
2. Шаблон с ключом трекера уже есть только для сжатого коммита: `policy.commit_template` с подстановками `{id}`, `{ref}`, `{text}` (`orchestrator/targets.py:418-419`), исполняет `pull.commit_title` (`orchestrator/pull.py:925-939`) — и только при `policy.squash_before_mr: true` (`targets._check_delivery`, отказ `commit_template` без сжатия).
3. Соглашения проектов на хостинге часто требуют сообщение `<ключ задачи трекера>: <текст>` для каждого коммита ветки; без сжатия коммиты пульта несут id задачи пульта и служебный текст.

## Требуется

1. Новое необязательное поле `policy.commit_message_template` локального слоя: непустая строка с подстановками только из `{id}`, `{ref}`, `{title}`, `{text}`; `{ref}` — только при `policy.ref_required`. Иное — отказ загрузки записи с именем поля. Умолчание — `{id}: {text}` (прежнее сообщение побайтно).
2. Подстановки: `{id}` — id задачи; `{ref}` — ключ ссылки системы `ref_required` задачи (тем же правилом, что `pull.commit_title`); `{title}` — название задачи (пустое — id задачи); `{text}` — прежний служебный текст коммита без префикса `<id>: `.
3. Шаблон применяется к первой строке сообщения каждого коммита пульта **в кодовой ветке задачи** (места факта 1); подпись `pult_message` (соавтор, служебная строка) — без изменений. Коммиты артефактной ветки `refs/artifacts/*` и сжатый коммит (`commit_template`) — без изменений.
4. Шаблон с `{ref}`, а ссылки системы `ref_required` у задачи нет — коммит с сообщением по умолчанию и запись журнала с причиной; шаг не останавливается.
5. Поле пишется командой `target-set <проект> policy.commit_message_template <значение>`.

## Критерии приёмки

- Given вымышленная запись с `ref_required: tracker`, `commit_message_template: "{ref}: {title}"` и задача со ссылкой `tracker:ABC-12`, When пульт коммитит чекпоинт тестов и кода, Then первые строки сообщений — `ABC-12: <название задачи>`; подпись (соавтор, служебная строка) прежняя;
- Given шаблон `"{ref}: {text}"`, Then первая строка — `ABC-12: долгоживущие тесты закоммичены пультом за роль test_author — шаг завершён` (служебный текст без `<id>: `);
- Given запись без поля, Then сообщения прежние побайтно; коммиты артефактной ветки и сжатый коммит — прежние при любом значении поля;
- Given шаблон с `{foo}`, пустой или с `{ref}` без `ref_required`, When загрузка записи, Then отказ с именем поля;
- Given шаблон с `{ref}` и задача без ссылки, Then коммит с сообщением по умолчанию и запись журнала с причиной;
- существующие тесты — зелёные без правки.

Безопасность тестов: вымышленные проекты и репозитории во временной песочнице (`tests.sandbox`), без сети; никогда — настоящий `.artel/targets.yaml`.

Существующие тесты: правка не должна сделать красным ни один существующий тест; если краснеет — эскалация с именем теста, без правки.

Зоны: `orchestrator/checkpoint.py`, `orchestrator/pull.py`, `orchestrator/amend.py` (первая строка сообщений коммитов кодовой ветки), `orchestrator/targets.py` (поле и проверка), `docs/codebase-map.md` (только генерацией), `tests/` (долгоживущие файлы задачи).

Только чтение: `orchestrator/gitcmd.py`, `orchestrator/artifact_branch.py`, `orchestrator/snapshot.py`, `orchestrator/store.py`, `orchestrator/projects.py`, `tests/sandbox.py`.

Не входит:
- сообщения коммитов артефактной ветки;
- служебная строка (отдельная задача `policy.commit_trailer`);
- переписывание уже сделанных коммитов;
- правка настоящего локального слоя `.artel/targets.yaml` в тестах и при разработке.
