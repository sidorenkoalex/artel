## Замечания

- **major** — `orchestrator/advance_gates/review.py:143` (сравнение
  `subject == templated`), `orchestrator/advance_gates/review.py:110-123`
  (`_templated_pull_subject`), `orchestrator/targets.py:748-759`
  (проверка поля) — рубеж засчитывает подтяжку при допустимом шаблоне,
  если в шаблоне есть перевод строки или пробел в конце.
  `_latest_developer_commit_iso_date` сравнивает тему `git log --format=%s`
  с сырым результатом `pult_subject`. Git же при `commit -m` срезает
  пробелы в конце строк, а `%s` склеивает строки первого абзаца через
  пробел. Проверено исполнением во временном репозитории:
  - сообщение `"ABC-1: подтяжка main "` → `%s` = `ABC-1: подтяжка main`;
  - сообщение `"подтяжка main\n(ABC-1)\n\n…"` → `%s` = `подтяжка main (ABC-1)`.

  Оба шаблона, `"{ref}: {text} "` и `"{text}\n({ref})"` (а также
  `"{text}\n\nRefs: {ref}"`, частое соглашение «ключ в теле»),
  `_check_delivery` принимает: строка непустая, подстановки из перечня.
  Сценарий поломки: у такого проекта задача в `in_dev` с
  `changes_requested`, после вердикта только подтяжка. Тема не совпала
  с `templated`, подтяжка засчитана шагом developer, переход
  `in_dev → verifying` проходит без отработки замечаний. Это ровно тот
  обход, ради которого появилось требование 6 («для любого допустимого
  шаблона»). Многострочный шаблон к тому же нарушает требование 3
  («первая строка сообщения»): строки шаблона после первой попадают в
  тело, а не в первую строку. Название задачи с пробелом в конце даёт
  тот же класс при шаблоне, где `{title}` стоит последним, например
  `"{text} {title}"`.
  Предложение: (а) в `_check_delivery` отказывать шаблону с `\n`/`\r` —
  шаблон описывает первую строку; (б) в `_templated_pull_subject` либо
  при сравнении нормализовать ожидаемую тему так же, как git (склейка
  строк первого абзаца через пробел, срез пробелов в конце). Например,
  сравнивать `subject.strip()` с нормализованным `templated`, а не
  требовать побайтного равенства. Свойство нужно закрепить тестом в
  `tests/`: допустимый шаблон с пробелом в конце (и, если (а) не
  выбран, многострочный) → подтяжка по шаблону не засчитана.
