## Замечания

Замечаний уровня blocker/major/minor нет.

Наблюдение для Оператора, без записи в реестр. Проверено исполнением во
временном репозитории. `str.splitlines()` в `_git_subject` режет и по
символам, которые git переводом строки не считает: `\x0b`, `\x0c`,
`\x1c`, `\x85`, ` `, а также `\r`. В выводе `git log` они остаются,
и тогда ожидаемая тема расходится с `%s`. Расхождение возможно, только
если в шаблоне есть `{title}`, а в названии задачи — такой управляющий
символ. Сам гейт уже до задачи читает вывод `git log` через
`res.stdout.splitlines()` (`review.py:159`), так что этот класс шире
задачи. Если закрывать, то разбором `message.split("\n")` в `_git_subject`
или отказом таких символов в названии при заведении задачи.
