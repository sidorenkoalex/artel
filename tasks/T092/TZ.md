# ТЗ: П2′ — artel report: статический HTML из state.db + метрики гейтовой нагрузки

Источник: роадмап §3 «Панель», этап 1 (П2′, $15); плюс строка P3
«Метрики гейтовой нагрузки» (решения Оператора 31.08 по MJ-1/MJ-10
аудита v6) — носитель метрик живёт здесь, одной задачей.

Опора: утверждённый UX-макет tasks/T080/mockup.html (смерженный
артефакт П1) — раскладка борда, карточки задачи, блока алертов,
очереди гейтов. Report — статическая реализация того же вида
на живых данных.

Требуется:

1. Команда `report`: генерирует один самодостаточный HTML-файл
   (путь — решение исполнителя, разумный дефолт в `.artel/`,
   печать пути в консоль) из `state.db` и журнала. Без демона,
   HTTP, JS-фреймворков и сборки — как макет T080.
2. Содержимое: борд задач по состояниям FSM; карточки (статус,
   бюджет/расход, итерации ревью, эскалации); блок незакрытых
   алертов; очередь ожиданий Оператора (задачи на ручных гейтах).
3. Блок метрик (носитель контрольных точек 31.08):
   а) доля задач, прошедших acceptance автогейтом vs руками —
      из журнала (актор `autogate` vs `operator` на переходе),
      счёт и за всю историю, и за последние 10 задач;
   б) операторские действия в день — число журнальных записей
      актора operator по дням, последние 14 дней;
   в) базовая экономика: $/задачу по done-задачам, суммарный
      расход программы (отчётная веха ADR-0010).
4. Read-only: report не пишет в БД ничего, не двигает состояния,
   не зовёт git/сеть. Повторный запуск перегенерирует файл на месте
   (истории отчётов нет — docs/retention.md).
5. Жёсткая граница зоны (параллельная задача T091 режет диспетчеры):
   `orchestrator/fsm.py`, `orchestrator/runner.py`,
   `orchestrator/auto.py`, `orchestrator/doctor.py` НЕ ТРОГАТЬ
   вообще. Новый модуль (например `orchestrator/report.py`) +
   минимальная строка регистрации команды в `artel.py` + чтение
   `store`/журнала существующими функциями.

Не входит: демон/API (Г0, после go/no-go), панель этапа 2, новые
записи в БД/журнал, правки чужих модулей сверх строки в artel.py.

Рамка: $15–25.
