(ADR-0021, этап 1 (в1)) прошла три лишних шага developer и две

Факты (пин 9afc1792):
- Строка мандата «Ослабление тестов разрешено: …»
  (`orchestrator/advance_gates/mandate.py:37`,
  `TEST_WEAKENING_MANDATE_MARKER`), элементы через запятую.
- `orchestrator/advance_gates/test_integrity.py::Finding.mandate_elements`
  (стр. ~116-131): находку покрывает путь файла целиком либо элемент
  `путь::<имя>`, где имя — ровно квалифицированное имя находки
  (`Класс::метод` для исчезнувшего метода). Элемент `путь::Класс` не
  покрывает находки о методах класса — гейт отказывает по каждому методу.
  Случай 03.10 22:12Z: ANSWER-1 задачи 01M41VTQJ9DSX64NFMFAF9W53B с
  `tests/test_guard_artifact_branch_mode.py::IsDraftLenientTest` — отказ
  по 12 методам двух классов.
- `orchestrator/answer.py::_cmd_answer` (стр. ~160-171): в `in_dev` и
  `review` команда `answer` принимает файл только с маркером мандата
  расширения зон («Расширение зон разрешено:»); файл с мандатом тестов —
  отказ «answer доступна только для задачи в состоянии escalated».
  Уточнить мандат тестов можно только через новую эскалацию developer
  (полный шаг роли). Рубеж «вызов из окружения роли — отказ» уже стоит в
  этой ветке.

Требуется:
1. Элемент мандата `путь::Класс` покрывает находки о классе и о любых
   его методах (`путь::Класс::метод`); элемент `путь::Класс::метод` —
   только этот метод; путь файла — весь файл, как сейчас. Запись журнала
   «разрешено ANSWER-n» называет покрытые находки, как сейчас.
2. `answer <id> <файл>` в `in_dev`/`review` принимает файл, несущий
   строку мандата тестов (с тем же разбором и проверкой строки, что в
   `escalated`, и тем же рубежом окружения роли), — состояние задачи не
   меняется, журнал получает запись с элементами мандата; файл без
   маркеров мандата в этих состояниях — прежний отказ.
3. Подсказка гейта сохранности тестов при отказе (`_mandate_hint`)
   называет обе формы доставки мандата (`answer` в `in_dev` и в
   `escalated`).
4. Тесты в `tests/` с заявками «Ловит мутацию»: класс в мандате
   покрывает исчезнувшие методы класса и не покрывает методы другого
   класса того же файла; метод — только себя; `answer` с мандатом тестов
   в `in_dev` коммитит ANSWER и не меняет состояние; без маркера — отказ;
   из окружения роли — отказ.
