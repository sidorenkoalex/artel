## Пути обхода гейтов
1. **Псевдоним импорта и аннотированное присваивание.** `from tests.marks import requires_pg as needs_db` + `@needs_db`, а также `requires_pg: Any = pytest.mark.skip(...)` или `pytestmark: list = [pytest.mark.skip]` (`ast.AnnAssign`). Буквально треб. 1 называет `from <модуль> import name` и `name = …` (SPEC.md:39-41), треб. 4 — `pytestmark = …` (SPEC.md:68). Реализация только по `ast.Assign` и `alias.asname is None` выполнит SPEC буквально и пропустит эти формы. В «Не входит» их тоже нет (там цепочки, фабрики, `+=`/`.append`). Решать Оператору: включить или заявить пробел.
2. **Модульный вызов внутри `try/except`.** Обычная форма: `try: import psycopg` / `except ImportError: pytest.skip("…", allow_module_level=True)`. Треб. 4 говорит «на уровне модуля» и «условен только внутри `if`/`else`» (SPEC.md:70, 79). Не определено, считается ли вызов в `except`/`with` «на уровне модуля». Реализация, которая смотрит только операторы верхнего уровня и тела `if`, его не увидит. AC-6/AC-7 этот случай не проверяют.
3. **У артели — смена только `tests/marks.py`.** Поиск импортёров вне диффа можно реализовать только для `tests/sandbox.py`, и AC-8 пройдёт (см. таблицу).
