## Проверяемость критериев

| Критерий | Проверяем | Ловимая мутация |
|---|---|---|
| AC-1 | да | `_send` по-прежнему зовёт `_attempt_push` с проверкой `has_no_remote` — два вызова `git remote …` перед `push` |
| AC-2 | да | `_origin_configured` в `_send` заменён на `not has_no_remote` — при remote с другим именем идёт `push` |
| AC-3 | да | признак «origin проверен» передан и из `push(task_id)` либо проверка снята из `_attempt_push` целиком — `git push` без remote, причина не `PUSH_REASON_NO_ORIGIN` |
| AC-4 | да | `_send` в `origin_sync_refusal` остаётся безусловным — `push` при совпадении |
| AC-5 | да | нет повторной сверки после досылки — отказ «расходится» со старым sha origin |
| AC-6 | да | досылка до первой сверки (прежний порядок) — `push` при недоступном origin |
| AC-7 | да | после неудачной досылки отказ меняет текст/ветку сравнения (например, `None` при `not remote`) |
| AC-8 | да | после досылки результат второй сверки не сравнивается — `None` либо текст «нет в origin» |
| AC-9 | да | досылка только при непустом `remote` — ссылка, которой нет в origin, не досылается, отказ «нет в origin» |
| AC-10 | да (проверка PLAN глазами ревью) | счёт не снят или снят не на названном тесте |

Отклонение 1. Требование 2 SPEC: «если `local` пуст … — отправки нет». Ни
один AC не покрывает исход «локальной ссылки нет, в `origin` ссылка есть».
Правдоподобная реализация `if local != remote: _send(...)` (без `and local`)
проходит AC-1–AC-10: `git push` несуществующей ссылки падает, `_send`
журналирует «push артефактной ветки FAILED», повторная сверка даёт тот же
текст «расходится … локально (нет)» — текст отказа совпадает, лишние `push`,
`ls-remote` и запись журнала тестами не видны. Прежний код в этом исходе не
отправлял (`artifact_branch.py:492–493`), так что мутация — смена поведения
вне требований. Нужен критерий: «`local` пуст, в `origin` ссылка есть — без
`git push`, без новой записи журнала, отказ «отказ: <ветка> расходится с
origin — локально (нет), в origin <sha>»». В ТЗ п.3 такого случая нет —
решение за Оператором (добавить AC-11 либо принять пробел).
