# Скил: ui-standards (разработчик — UI-задачи пульта)

## Перед началом

Прочитай `docs/design-system.md` целиком, до правки любой
UI-поверхности пульта (доработки `orchestrator/report.py`, будущая
панель Г0+). Он систематизирует палитру, типографику, раскладку
борда/карточек/панелей и цветовое кодирование состояний FSM из реальных
источников (`tasks/T080/mockup.html`, `orchestrator/report.py`) —
токены и классы этого документа, не изобретённые заново, обязательны
для новой/правленой разметки.

## Самодостаточность — без исключений

- **Запрет CDN и внешних ресурсов.** Ни `<link>`/`<script src="https://…">`
  на внешний CDN, шрифт или библиотеку. Все стили — инлайн в `<style>`,
  все шрифты — системный стек из `docs/design-system.md` (раздел
  «Типографика»).
- **Запрет шага сборки.** Ни webpack/vite/esbuild/иного бандлера, ни
  транспиляции (JSX, TypeScript, SCSS) — только валидный HTML/CSS и, при
  необходимости, обычный `<script>` без зависимостей.
- **Запрет JS-фреймворков.** Ни React/Vue/Angular/иного фреймворка —
  интерактивность (если нужна) пишется без них, либо разметка остаётся
  визуальной без обработчиков (как кнопки `mockup.html`).
- **Запрет демонов на этапе 1.** Никаких HTTP-серверов, вебсокетов, БД-
  подключений «вживую» из страницы — только статический HTML-файл или
  read-only срез, сгенерированный заранее (как `orchestrator/report.py`
  сейчас). Демон и панель Г0+ — предмет отдельного этапа роадмапа, не
  этой обвязки.

## Чек перед сдачей

Открой готовую страницу двойным кликом (или `file://<путь>` в браузере)
**без сети** — ни один ресурс не должен запрашиваться извне: если
страница рендерится и работает так же, как при обычном открытии, чек
пройден. Страница, которая ломается или бледнеет без сети (пропавшие
шрифты/иконки/скрипты с CDN), нарушает самодостаточность — почини
источник до сдачи, а не отметь как «мелочь».

## Расхождения с design-system.md

Если правка UI-поверхности обнажает новое расхождение со стандартом
(либо стандарт неполон для твоей задачи) — не изобретай норму на
свой вкус: расширь `docs/design-system.md` тем же диффом (если это в
рамках твоей задачи) или эскалируй, если решение шире зоны задачи.
