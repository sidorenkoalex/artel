# Скил: escalation-rules (базовый слой — все роли)

## Когда остановиться
Эскалируй (не продолжай попытки), если:
- требование SPEC можно понять двумя существенно разными способами;
- для решения нужно право, которого у твоей роли нет;
- обнаружил проблему вне зоны задачи (уязвимость, сломанный main);
- третья попытка одного и того же подхода не удалась — подход неверен.

## Как эскалировать
1. Заверши текущий артефакт со `status: escalate`.
2. Добавь в конец артефакта раздел `## Эскалация`:
   - **Вопрос** — один, конкретный, с вариантами ответа если возможно.
   - **Контекст** — что успел сделать/выяснить, файлы и строки.
   - **Блокирует** — что именно не может продолжиться без ответа.
3. Останься в рамках сделанного — не откатывай работу.

## Чего не делать
- Не выбирать интерпретацию «на свой вкус» при неоднозначности SPEC.
- Не расширять объём задачи, чтобы «обойти» блокер.
- Не задавать больше одного вопроса за эскалацию — выбери блокирующий.
