# Скил: escalation-rules (базовый слой — все роли)

## Когда остановиться
Эскалируй (не продолжай попытки), если:
- требование SPEC можно понять двумя существенно разными способами;
- для решения нужно право, которого у твоей роли нет;
- обнаружил проблему вне зоны задачи (уязвимость, сломанный main);
- третья попытка одного и того же подхода не удалась — подход неверен.
- зафиксированный приёмочный тест навязывает коду внутреннее устройство
  (имя закрытой функции, порядок внутренних вызовов, форму данных,
  которую не требует SPEC), а не проверяет поведение. Разработчик НЕ
  подгоняет устройство кода под такой тест — эскалирует с кодом причины
  `тест-навязывает-устройство`, назвав файл, метод и навязанную деталь.
  Ответ Оператора — правка теста командой `amend-tests` (ADR-0012), не
  переписанный под тест код.

## Как эскалировать
1. Заверши текущий артефакт со `status: escalate`.
2. Добавь в конец артефакта раздел `## Эскалация`:
   - **Вопросы** — все разом, одним батчем: отсортированы по
     блокирующести (без чего нельзя продолжать — первым), у каждого
     варианты ответа и дефолт на случай молчания Оператора по пункту.
     Не дроби на переписку по одному вопросу за раз.
   - **Контекст** — что успел сделать/выяснить, файлы и строки.
   - **Блокирует** — что именно не может продолжиться без ответа.
   (У ролей со своим носителем батча — например QUESTIONS.md у
   analyst — действует механика их скила, правило то же: один батч.)
3. Останься в рамках сделанного — не откатывай работу.
4. Продолжая работу после ответа Оператора (ANSWER), сними
   `status: escalate` в своём артефакте (PLAN.md): сдай `ready` либо,
   если вопрос не снят, новую эскалацию с новым батчем. Оставленный
   прежний `status: escalate` пульт читает как новую эскалацию — задача
   снова встанет, не продвинувшись.

## Чего не делать
- Не выбирать интерпретацию «на свой вкус» при неоднозначности SPEC.
- Не расширять объём задачи, чтобы «обойти» блокер.
- Не устраивать переписку по одному вопросу за раз — все вопросы
  собираются в один батч; второй батч до ответа на первый не задаётся
  (задача в escalated, тебя и не запустят).
