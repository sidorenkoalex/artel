Требуется:
1. Вызовы git из узлов автокоммита и сверки .gitignore ограничены
   пределом (константа config, решение SPEC); вышел предел — запись
   журнала «автокоммит артефактов пропущен: git не ответил за N с» и
   алерт, а не молчаливый пропуск.
2. Дозор: стоимость шага записана, а события конца шага нет дольше M
   минут — отдельное предупреждение.
3. `doctor`: быстрая проверка, что git отвечает в главной копии и в
   рабочих копиях живых задач.
4. Тесты в `tests/` с заявками «Ловит мутацию»: зависший git не держит шаг
   дольше предела и оставляет запись журнала; предупреждение дозора;
   строка doctor. Существующие тесты не ослабляются.
