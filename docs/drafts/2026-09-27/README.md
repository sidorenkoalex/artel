## Что сессия вне этой машины может и чего не может

Состояние конвейера живёт на машине Оператора и в репозиторий не попадает: база
`.artel/state.db`, локальный слой моделей `.artel/models.yaml`, дом роли второго провайдера
`.artel/home/`, рабочие каталоги задач, процессы цикла `auto`.

| Действие | Облачная сессия |
|---|---|
| Читать документы, код, историю, снимки `refs/artifacts/<id>` | может |
| Готовить ТЗ, заготовки документов, разбор кода | может |
| Команды пульта `status`, `new`, `approve`, `auto`, `note`, `doc-commit`, `pin-update`, `canary` | не может: нет базы и пина |
| Коммит в `main` | не делает: `main` правится только командами пульта с машины Оператора |

Результат облачной сессии передаётся Оператору файлом либо веткой, не коммитом в `main`.
