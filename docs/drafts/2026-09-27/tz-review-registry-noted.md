# ТЗ: Реестр замечаний ревью: статус «принято к сведению» для мелких замечаний и перенос в бэклог на мерже

Источник: строки бэклога 26.09 «Minor при approved некуда деть» и
«Наблюдения ревью и Предложения системе в очередь на мерже»; решение
Оператора 27.09. Прецеденты: ревью задач 01M3F7BY, 01M3H1Z4, 01M3H3T8,
01M3H3K7, 01M3H3JR — пять ревьюверов за два дня вынесли мелкие
замечания вне реестра, потому что запись реестра блокирует одобрение.

Факты — уточняются аналитиком по коду на дату заведения; известное на
27.09: гейт реестра (`orchestrator/advance_gates/tests_writing.py::
_registry_gate`, `orchestrator/fsm_advance.py`) отклоняет `approved` при
любой записи реестра не в статусе `accepted`; перечень статусов —
`scripts/guard.py::REGISTRY_STATUSES`; форма REVIEW.md — `templates/`
(защищённый путь); правило «0 blocker/major → approved» —
`skills/review-checklist.md` (защищённый путь).

Требуется: статус записи реестра для мелкого замечания, который гейт
одобрения пропускает; перенос таких записей в бэклог командой пульта на
мерже задачи; правки шаблона REVIEW.md и скила ревьювера приложением.
Полный текст требований — при заведении, после мержа задачи о скилах
(общий файл skills/review-checklist.md) и задачи о командах note
(orchestrator/notes.py).
