## Уроки

1. Мандат на ослабление выдаётся только после чтения «Ловит мутацию»
   снимаемого теста и сверки утверждений ВСЕХ изменённых методов, а не
   только удалённых и переименованных.
2. Записанный в PLAN риск отказа ключевой функции — блокирующий для
   ревью.
3. Механизм, работающий с внешним состоянием (вход, связка ключей),
   принимается только живым прогоном, а не тестами с подменой.
4. Уведомление о завершении фонового `auto` означает отвязку цикла, не
   его остановку: остановки ловить дозором по журналу (02.10 пропущен
   красный CI на 25 минут). Хука фоновых запусков у Claude Code нет с
   13.09.
