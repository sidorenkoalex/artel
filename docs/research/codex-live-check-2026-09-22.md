## Живой запрос

--skip-git-repo-check для временного каталога. Промпт: «Reply exactly
READY. Do not use tools.» Таймаут 60 секунд. Один запуск до исправления
и один после; внутри CLI происходили собственные переподключения.

Первый запуск с OPENAI_API_KEY получил HTTP 401 Missing bearer or basic
authentication. Передача ключа исправлена: операторский источник
OPENAI_API_KEY/Keychain отображается в CODEX_API_KEY для codex exec.
Основание: https://learn.chatgpt.com/docs/non-interactive-mode .

Второй запуск с исправленной передачей получил HTTP 401 invalid_api_key.
CLI завершился с кодом 1 и turn.failed; usage не пришёл. Наличие ключа
в Keychain подтверждено, его действительность сервером отвергнута.
Утверждать нулевой расход либо успешную калибровку нельзя.

Дополнительно живой лог показал item.completed с item.type=error при
переключении транспорта. Разбор сохраняет его сообщение в логе;
регрессионный тест добавлен.

## Переход на подписку

Решение Оператора отменяет API-авторизацию ролей. Выбраны
forced_login_method=chatgpt и cli_auth_credentials_store=keyring.
Документированные выше пробы API — история диагностики, пополнение
баланса API больше не требуется.

Первый OAuth-вход не сохранился: изолированный HOME не знал default
keychain. В его Library/Preferences задан указатель на существующую
связку; личный default keychain проверен и остался прежним. Повторный
вход завершился успешно. Токены хранит и обновляет Codex, а не пульт.

## Выводы для задач линии

1. `codex exec` берёт ключ API из `CODEX_API_KEY`, не из `OPENAI_API_KEY`
   (важно, только если к ключу вернутся).
2. `GET /v1/models` не доказывает возможность генерации: проверять
   минимальной генерацией.
3. Вход ChatGPT в изолированном `HOME` роли на macOS требует указателя на
   связку ключей в `$HOME/Library/Preferences` (`security default-keychain
   -d user -s <путь>`), иначе `persist_failed`; повторять после
   пересоздания дома роли — кандидат в развёртывание дома пультом.
4. Вход и шаг должны задавать один способ хранения:
   `cli_auth_credentials_store=keyring`, `forced_login_method=chatgpt`.
   Из окружения шага исключаются `OPENAI_API_KEY`, `CODEX_API_KEY`,
   `CODEX_ACCESS_TOKEN`, переменные федеративного входа и секреты Claude.
5. Учёт токенов: `input_tokens` включает `cached_input_tokens`;
   `reasoning_output_tokens` входит в `output_tokens`; отсутствие
   `cache_write_input_tokens` — ноль; неполный usage — расход неизвестен.
6. События инструментов: `item.started`/`item.updated`/`item.completed`
   связываются по `item.id`; ошибка — `status: failed` даже при
   `error: null`; `item.type=error` при переключении транспорта — не
   провал шага.
7. На пине `fd83eb5d` красный `tests.test_models`
   (`test_three_models_with_status_and_price_date` ждёт три модели, в
   каталоге восемь после приложения части 1).
