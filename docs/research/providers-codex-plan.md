# План: провайдеры ролей, каталог моделей и учёт расхода (подключение Codex)

Дата: 20.09.2026. Статус: принят Оператором 20.09 (решения — раздел 6);
обновлён 26.09: авторизация Codex — подписка ChatGPT (раздел 6, п.1),
ход исполнения — раздел 7.1.
Источник: анализ кода пульта, строки бэклога и копилки (перечислены в
разделе 8), разбор учёта расхода 20.09.

## 1. Цель

Роль конвейера может исполняться не только Claude Code, но и Codex CLI
(OpenAI) в неинтерактивном режиме `codex exec`; выбор модели у роли
явный и переносимый между клонами пульта; расход считается одинаково
для любого провайдера, в том числе без цены в долларах от CLI.

## 2. Принципы учёта расхода

1. Первичный факт по каждому шагу — токены по четырём видам (вход,
   выход, запись кэша, чтение кэша), для любого провайдера.
2. Стоимость всегда считается по тарифу модели: «токены вида × цена
   вида». Факт CLI, где он есть (Claude), пишется рядом и служит
   контролем: расхождение выше порога — предупреждение сразу при
   записи шага, не только при вызове `report`.
3. Единица бюджетов, гейтов и калибровочной таблицы остаётся доллар.
   Для подписок без цены за токен доллар расчётный по публичному
   прейскуранту модели; отдельная «условная единица» не заводится
   (та же математика, но ломает накопленные пороги и бейзлайны).
4. Сырые токены как единица бюджета не годятся: виды различаются по
   цене в 50 раз, модели в 5 раз (пример 13.09: 182 млн токенов шага
   стоили $57, а 1 млн выходных стоит $15). Токены показываются рядом
   с долларами в `status`, `report`, RETRO.
5. Модель без тарифа, ярус без модели, роль без яруса — именованный
   отказ `run`/`auto` до запуска агента и красная строка `doctor`.
   Никаких молчаливых нулей и дефолтов CLI.
6. Курс задаётся по прейскуранту и подтверждается сверкой, а не
   подбирается по журналу: подгонка методом наименьших квадратов
   неустойчива (входных токенов почти нет — всё идёт через кэш).
   Проверка 20.09: прейскурант opus-5 сходится с фактом CLI по 93 шагам
   с коэффициентом 1.009; текущий курс в коде (цены Sonnet) даёт 1.68.
7. Лимит подписки на окне (Claude Max, ChatGPT) — отдельный ресурс,
   который ни доллары, ни токены не показывают; ведётся отдельной
   проверкой `doctor`.

## 3. Три слоя данных о моделях

### 3.1. Каталог поддерживаемых моделей — `models.yaml` в корне репозитория

Знание пульта о провайдерах, общее для всех клонов. Защищённый путь
(рядом с roles.yaml, gates.yaml, targets.yaml): правит только Оператор
командой `doc-commit` или приложением к PLAN. Заменяет таблицу
«модель → минимальная версия CLI» в `orchestrator/stack.py`.

```yaml
providers:
  claude:
    cli: claude
    min_cli_version: "2.1.0"
    cost_from_cli: true
    models:
      claude-opus-5:
        min_cli_version: "2.1.0"
        list_price_usd_per_mtok: {input: 5.00, output: 25.00, cache_write: 6.25, cache_read: 0.50}
        price_date: 2026-09-20
        status: supported
      claude-fable-5-1:
        min_cli_version: "2.1.251"
        list_price_usd_per_mtok: {…}
        status: supported
  codex:
    cli: codex
    min_cli_version: "0.40.0"       # уточнить по установленной версии
    cost_from_cli: false
    models:
      gpt-5.3-codex:
        list_price_usd_per_mtok: {input: 1.75, output: 14.00, cache_write: 1.75, cache_read: 0.175}
        price_date: 2026-09-20
        status: supported
      gpt-5.4-mini:
        status: experimental
```

Правила: у OpenAI запись кэша отдельно не тарифицируется — цена записи
равна цене входа, чтение кэша берётся из колонки «кэшированный вход»;
все четыре цены обязательны (явный ноль — ошибка конфигурации).
`status: experimental` — запуск только с явным подтверждением в
локальном слое.

### 3.2. Локальный слой Оператора — `.artel/models.yaml`, вне git

Выбор конкретного пульта: ярусы на модели и, при необходимости, свой
тариф поверх прейскуранта (прокси, скидка, Bedrock). Шаблон кладёт
`init`/`target-init`. Без локального тарифа берётся прейскурант из
каталога.

```yaml
tiers:
  strong: claude-opus-5
  standard: claude-opus-5
  cheap: gpt-5.4-mini
overrides:
  claude-opus-5:
    tariff_usd_per_mtok: {input: 5.00, output: 25.00, cache_write: 6.25, cache_read: 0.50}
    calibrated_at: 2026-09-20
    source: сверено с фактом CLI 20.09, коэффициент 1.009
```

Цепочка разрешения: роль (`model_tier` в roles.yaml) → ярус → модель
→ провайдер, тариф, минимальная версия CLI. Модель из локального файла
обязана быть в каталоге.

### 3.3. История тарифов — таблица `model_tariffs` в `state.db`

Поля: модель, четыре цены, действует с, источник. Пульт при чтении
файлов сравнивает применяемый тариф с последней записью и при отличии
добавляет строку. Строка стоимости шага ссылается на модель и момент;
RETRO и `report` считают по тарифу, действовавшему на момент шага.
Руками таблица не правится.

### 3.4. Проверки `doctor` и команда `models`

`doctor`: файлы разбираются; каждая модель ярусов есть в каталоге;
тариф полный; провайдер и версия CLI на месте; дата калибровки не
старше смены модели у роли и не старше заданного срока; для провайдера
с фактом CLI коэффициент сверки в норме; лимит подписки на окне.

`models` (только чтение): таблица «провайдер, модель, статус, версия
CLI, прейскурант, действующий тариф, кто использует по ярусам».

## 4. Что в пульте привязано к Claude Code (точки интерфейса провайдера)

1. Argv шага роли (`runner.role_cmd`): `claude -p --permission-mode
   acceptEdits --output-format stream-json --allowedTools … --setting-
   sources … --strict-mcp-config --model`; промпт файлом на stdin.
2. Окружение роли: HOME на курируемый слой `.artel/home`,
   `CLAUDE_CONFIG_DIR`, токен подписки из слота keychain, белый список
   переменных в манифесте стека.
3. Курируемый дом роли `docs/reference/role-home/claude/`: CLAUDE.md,
   settings.json с запретами, хук PreToolUse `bash_guard.py`; `doctor`
   сверяет развёрнутый слой с референсом.
4. Разбор вывода: события `stream-json` → лог, вызовы инструментов;
   событие `result` → `total_cost_usd` и четыре вида токенов
   (`spend.charge_step`, `TOKEN_RATES`, модель в RETRO, `report`).
5. Классификация провалов: сигнатуры текста Claude CLI («API Error:»,
   лимит сессии подписки, «does not support this model»).
6. Манифест стека и `doctor`: `REQUIRED_TOOLS`, таблица «модель →
   версия CLI», предполётные проверки, смоки изоляции, живой смок.
7. Правила для роли: скилы и CLAUDE.md в брифе; CLI ещё читает
   CLAUDE.md дома роли.

## 5. Особенности Codex CLI, определяющие дизайн

- `codex exec` с промптом на stdin, `--json` с событиями JSONL; флаги
  модели, рабочего каталога, песочницы (`read-only`, `workspace-write`,
  полный доступ) и политики подтверждений. Флаги и формат событий
  меняются между релизами — сверить с установленной версией на этапе ТЗ.
- Конфигурация и авторизация в `CODEX_HOME/config.toml`: ключ
  `OPENAI_API_KEY` или вход через ChatGPT. Правила из `AGENTS.md` по
  цепочке каталогов и из `CODEX_HOME`; `AGENTS.md` в репозитории есть и
  это защищённый путь (символьная ссылка на CLAUDE.md).
- Итоговое событие `turn.completed` несёт `usage`: `input_tokens`,
  `cached_input_tokens`, `output_tokens`, в части версий ещё
  `cache_write_input_tokens`, `reasoning_output_tokens`. Стоимости в
  долларах нет ни в одном событии. Проверить на живом запуске, входит
  ли кэшированный вход в `input_tokens`; если да — адаптер вычитает.
  Токены рассуждений входят в выход и тарифицируются как выход.
- Хуков на вызовы инструментов нет: рубеж безопасности роли — песочница
  (запись только в рабочий каталог, сеть выключена) и проверки пульта
  после шага (гейт зон, защищённые пути, посторонние файлы, утечка пула).

## 6. Решения Оператора (приняты 20.09.2026)

1. **Пересмотрено 22.09.2026:** авторизация Codex у ролей — **вход по
   подписке ChatGPT**, а не ключ API. Вход хранит и продлевает сам Codex
   в системном Keychain (`cli_auth_credentials_store=keyring`,
   `forced_login_method=chatgpt`) для `CODEX_HOME` дома роли; ключи API и
   чужие секреты из окружения шага исключаются; `doctor` проверяет
   `login status` дома роли. Основание: отдельный платный API Оператору
   не нужен; факты живых запусков —
   `docs/research/codex-live-check-2026-09-22.md`. Следствие: лимит окна
   подписки ChatGPT у Codex-ролей есть, и проверка `doctor` лимита
   подписки (задача 6) нужна для обоих провайдеров.
   Исходное решение 20.09 (оставлено для истории): авторизация Codex у ролей — **ключ API** (`OPENAI_API_KEY`).
   Следствия: отдельный слот keychain для ключа, выдаётся роли через
   окружение процесса, как токен Claude; лимитов окна подписки у
   Codex-ролей нет — расход ограничен только бюджетом задачи и
   стоп-лоссом; проверка `doctor` лимита подписки (задача 6) — только
   для Claude.
2. Сеть роли под Codex — **запрещена**: песочница `workspace-write`
   с выключенной сетью; push и MR делает пульт.
3. Смешанные ярусы — **разрешены**: ярус роли разрешается в модель
   любого провайдера каталога; одна задача может идти на двух
   провайдерах.
4. Тариф для ролей без цены от CLI — **публичный прейскурант**
   модели из каталога `models.yaml`; локальное переопределение — по
   желанию Оператора.
5. Единица бюджетов и гейтов — **доллар**; токены показываются рядом
   и в единицу гейтов не превращаются.

## 9. Риски

- Формат событий Codex меняется между версиями — минимальная версия CLI
  у провайдера обязательна с первого дня.
- Стоимость без тарифа не считается — запуск без записи тарифа отказывает,
  а не считает ноль.
- `AGENTS.md` в корне — защищённый путь; любая правка под Codex идёт
  приложением.
- Смена модели у роли без смены тарифа сегодня невидима; после задачи 2
  тариф следует за моделью, после задачи 0 расхождение видно на каждом
  шаге.
- Цены с сайта OpenAI сняты 20.09 с независимой сводки (сайт закрыт от
  автоматических запросов) — сверить глазами перед записью в каталог.
