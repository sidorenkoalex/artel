# Роадмап Артели

Нормативный план работ. Решения и их обоснования зафиксированы в ADR
(ADR-0001 — рамка Фазы 0; ADR-0002 — принцип целостности; ADR-0003 —
целевые проекты, якоря п.1–18 и 3а–3к; ADR-0004 — пульт и ассистент,
якоря п.1–9) — здесь они не пересказываются, только применяются.
Отложенные механизмы — `docs/deferred/` (publication, spaces,
prod-loop, executors); триггеры их возврата — `docs/triggers.md`;
история аудитов — `docs/audits/README.md`.

**Многооператорный контур** (решения Оператора 31.08; правила
и принципы — docs/multi-operator.md). Досерверная эпоха: N операторов

смертная ветка `task/*`, артефакты + RETRO — вечный несмерживаемый
`refs/artifacts/<id>` того же репо (паттерн refs/pull; main везде чист).
Задачи, по порядку после мержа волны T079–T084:
- **M1 «артефактный контур»** ($25–40; прочтение Б₃ — решение

  жизнь — где механика (пульт), вечность — где принадлежность
  (целевой). При жизни задачи артефакты (`tasks/<id>/`) живут
