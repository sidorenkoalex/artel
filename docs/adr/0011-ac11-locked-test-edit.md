# ADR-0011: правка зафиксированного приёмочного теста ac11 задачи «Наблюдаемость сессий»

Статус: принят. Дата: 02.09.2026. Решение Оператора.

## Контекст

Приёмочный тест `test_ac11_status_shows_holder.py` задачи
01M1GCHKG8DDK4DCZWCE3DYKWC был написан и зафиксирован (инвариант 27)
с дефектом: регулярное выражение, проверяющее строку вывода `status`,
требовало, чтобы идентификатор задачи имел вид «буква T и три цифры».
Это нарушает правило T094 (формат идентификатора знает только
`orchestrator/idgen.py`; остальной код и тесты обращаются с
идентификатором как с непрозрачной строкой) — CI-проверка формата
не пропускает такой код в main, мерж задачи невозможен.

Роль исправить зафиксированный тест не может (инвариант 27), путь
назад в состояние написания тестов у конвейера отсутствует.
Две операторские правки без документа-основания были законно
отменены ролями: их чек-лист признаёт основанием изменения
зафиксированных тестов только ссылку на ADR Оператора.

## Решение

1. В тесте ac11 место идентификатора в регулярном выражении
   заменяется с «T и три цифры» на «любая непустая
   последовательность символов» — тест перестаёт предполагать
   формат идентификатора и продолжает проверять то, для чего
   написан: состав и порядок колонок строки `status`.
2. Зафиксированный ориентир каталога тестов (`tests_locked_sha`)
   обновлён на коммит с этой правкой (19a4031). Обновление выполнено
   прямой записью в БД с записью в журнал задачи — штатной команды
   для этого нет (пробел зафиксирован в очереди работ).
3. Правка не является ослаблением защиты: проверяемое свойство и
   чувствительность теста к поломкам сохранены полностью; меняется
   только предположение о виде идентификатора, которое тест не имел
   права делать.

## Следствия

- Восстановление содержимого каталога тестов к состоянию 19a4031 —
  исполнение этого решения; роли (developer, reviewer) признают его
  по ссылке на настоящий ADR и не отменяют.
- Системные выводы уже поставлены в работу отдельно: проверка
  формата идентификатора на выходе этапа написания тестов, до
  фиксации (задача 01M1H186VEVG6NF40YKH1338MD), и принцип минимума
  операторских правок (docs/operator-session.md).
