# ADR-0010: Программный стоп-лосс — отчётная веха, не предохранитель

Дата: 2026-08-31. Статус: принят (решение Оператора).

## Контекст
Аудит v6 (MJ-2): условие автогейта acceptance «пороги программы не
пробиты» реализовано проверкой абсолютной суммы — при $1400 (70%
стоп-лосса $2000) автогейт отключается навсегда, потому что
накопленный расход не убывает. Учтено $1107.66 — до тихого
необратимого отключения оставались дни.

Разбор в упор показал более глубокое: сама привязка автогейта
к программным деньгам полудекоративна. Прохождение приёмки денег
не жжёт — расходы сдерживает потолок задачи (инвариант 5);
сигнальную функцию несут алерты порогов, которые конфиг сам
описывает как «повод для пересмотра, не для остановки». А значение
$2000 взято с потолка для обкатки механики порогов (решение
Оператора 31.08): в целевых проектах понятия общего бюджета
программы, вероятно, не будет вовсе; на пульт тратится сколько
нужно — при полном учёте цифры.

## Решение
1. **Программный стоп-лосс и его пороги 70/90% — отчётные вехи.**
   Они не блокируют ничего и не входят ни в какие автоматические
   условия (автогейт, переходы FSM). Условие «пороги программы
   не пробиты» из состава автогейта acceptance (ADR-0007 п.3)
   удаляется.
2. **Учёт полный и обязательный, как был**: `total_spent`, стоимости
   в RETRO, пересев холодного старта — цифра общих трат собирается
   для ретро и отчётности. Алерты порогов деградируют
   в информационные отметки (строка doctor/report, событие журнала;
   без ack-обязательств и без участия в решениях).
3. **Потолки задач не затронуты**: бюджет задачи, эскалация
   по пробою, право Оператора поднимать — действуют как прежде.
   Инвариант 5 не ослабляется — он и есть настоящая финансовая
   защита.

## Последствия
- Тесты условий автогейта (SPEC T066) правятся конвейерной задачей
  с мандатом этого ADR — изменение состава условий гейта санкционировано
  Оператором, ревью не трактует его как ослабление.
- Каскад на многооператорный контур: глобальная сумма расходов
  перестаёт быть входом автоматических решений — best-effort-доезд
  чужих паспортов (принцип эфемерности) порогам больше не лжёт
  (закрывает MJ-6 аудита v6 и денежную часть Q-3).
- ADR-0007 действует в остальном без изменений; kill-switch
  автогейта одной строкой gates.yaml сохраняется.
