# ADR-0012: правка зафиксированной планки приёмки Оператором — механизм и границы

Статус: принят. Дата: 02.09.2026. Решение Оператора.
Заменяет разовые решения класса ADR-0011: новые документы на каждый
случай не заводятся.

## Контекст

Приёмочные тесты фиксируются до кода (инвариант 27) и неприкасаемы —
код подгоняют под тесты. Когда дефектна сама планка, чинить её некому:
роли запрещено защитой, а операторскую правку без признаваемого
основания роли законно откатывают (их чек-лист различает только ADR).
02.09 это дало три инцидента, войну правок и холостые циклы.

## Решение

Оператор вправе править зафиксированные приёмочные тесты задачи.
До появления штатной команды — вручную: коммит со ссылкой на этот
ADR, обновление фиксации лока, запись в журнал задачи. Штатная
команда (задача заводится этим же решением) делает то же одним
вызовом; её журнальное событие — равносильное основание, ссылка
на ADR в коммите после её появления не требуется.

## Ограничители (неотъемлемая часть решения)

1. **Основание — не спор о существе.** Правка легальна только при:
   (а) механическом конфликте теста с другой защитой системы (линт,
   guard, формат), воспроизведённом исполнением; либо (б) дефекте
   формы, зафиксированном замечанием ревьювера и не меняющем
   проверяемых свойств (докстринги, маркеры, способ записи литерала).
   «Тест слишком строгий», «критерий неудобен», «так не реализовать» —
   не основания: спор о существе планки идёт полным циклом пересмотра
   (эскалация → решение Оператора → test_author заново), не правкой.
2. **Инициатива — диагноз Оператора.** Эскалация роли — повод
   посмотреть, но не основание; правка исполняется по воспроизведённому
   Оператором (или по его команде ассистентом) диагнозу. Запрос роли
   сам по себе ничего не запускает.
3. **Счётчик с порогом.** Каждая правка планки — журнальное событие;
   метрика в отчётности; больше одной правки на пять задач — алерт
   «планка девальвируется» и пересмотр механики (родственный
   предохранитель — живой хвост A4 роадмапа).
4. **Неослабление проверяется как раньше.** ADR легализует канал,
   не отменяя проверку ревьювера: правка, ослабившая тест
   (проверяемое свойство, чувствительность к поломкам), — блокер.

## Следствия

- skills/review-checklist.md признаёт основанием правки планки ссылку
  на этот ADR либо журнальное событие штатной команды; проверка
  неослабления сохраняется без изменений.
- Задача «штатная команда правки планки с обновлением лока» заведена
  02.09 этим решением.
- ADR-0011 остаётся историческим прецедентом частного случая (ac11).
