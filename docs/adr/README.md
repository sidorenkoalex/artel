# Решения об архитектуре (ADR) — оглавление

Сводка статусов и связей. Нормативен текст самих ADR; здесь — только
навигация. Правила ведения:

- Принятое решение не переписывается. Изменение — новым ADR или
  датированной пометкой в тексте прежнего: «Пересмотрено ADR-00xx, п.N
  (дата): …», «Дополнено …», «Исполнено: …».
- Строка статуса — первым абзацем после заголовка: «Статус: …. Дата:
  ДД.ММ.ГГГГ. Решение Оператора …».
- Решение, исполняемое этапами (ADR-0021), до исполнения этапа
  помечается в прежних ADR словами «с этапа N».
- Каталог `docs/adr/` — защищённый путь: правит только Оператор
  (`doc-commit`).
- Оглавление обновляется тем же коммитом, что меняет статус ADR.
